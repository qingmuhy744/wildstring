# .wildstring 便携元数据

便携侧车格式已接入音乐和书籍扫描、手动导出、曲目整理、废纸篓操作以及存储模式迁移。

## 布局与内容

专辑和书籍在各自托管目录中维护一个 `.wildstring/`。音乐 manifest 的 `schema` 为 `wildstring.sidecar.music.v1`，包含专辑覆写、锁定字段、外部作品 ID、封面引用与哈希，以及按媒体 SHA-256 绑定的歌曲条目。曲目条目可记录标题、艺人与专辑艺人、碟号与曲号、制作名单、外部作品 ID、锁定字段和歌词引用。歌词位于 `lyrics/<sha256>.lrc`，使用 UTF-8。

书籍 manifest 的 `schema` 为 `wildstring.sidecar.book.v1`，包含公共书目字段、锁定字段、封面引用与哈希、按 SHA-256 绑定的电子书和有声书文件，以及校订章节。封面统一保存为解码后重新编码的 `cover.jpg`。

## 导入与优先级

分享来源中的侧车可读。仅允许白名单字段、规范路径以及经过体积限制的 JSON、合法 LRC 歌词和经 Pillow 解码校验重编码的封面，目录和文件不得经符号链接打开。媒体哈希与条目匹配后才应用该条目和对应配件；还原音乐封面时同步维护 `tracks.has_cover=1`。扫描器跳过侧车目录中的文件计数，侧车只在当前专辑或书籍目录明确读取。

优先级从高到低为本实例锁定覆写、哈希匹配的便携侧车、传统旁路文件、内嵌标签；侧车还原只将显式存在覆写语义的字段记入 `overrides`，不把普通扫描观测值写入锁定/覆写层。未知或不合规字段不写入库。导入和导出都仅包含公共作品信息，账号、收藏、播放计数、进度、书签、批注、认证、插件配置和服务器物理路径均排除。

## 导出与清理

音乐歌词沿用 `track_lyrics.text` 中的 UTF-8 LRC 原文和行级时间。在线候选的来源记录、翻译和逐字时间仍在实例的候选数据中。

数据库内元数据、歌词、封面、章节、配对或托管路径变化后刷新对应侧车，并按需清理不再引用的过期 `lyrics/<sha256>.lrc`、过期 `cover.jpg` 及已无有效媒体的 `.wildstring/` 目录（包括曲目整理迁走最后曲目、专辑移入废纸篓及书目并入配对目录）。单次和批量资料覆写、外部候选采用及封面选择、歌词编辑和批扫撤回、审核后的 Agent 草案、导入覆写以及书籍章节标题校对均在数据提交后刷新；管理员也可按库手动导出或由迁移前导出快照触发。写入与清理均限定在托管目录内，使用临时文件、同步落盘和原子替换；扫描来源保持只读，媒体原件保持原有字节。
