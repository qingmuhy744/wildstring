# .wildstring 便携元数据

便携侧车格式已接入音乐和书籍扫描、手动导出、曲目整理、废纸篓操作以及存储模式迁移。

## 布局与内容

专辑和书籍在各自托管目录中维护一个 `.wildstring/`。音乐 manifest 的 `schema` 为 `wildstring.sidecar.music.v1`，包含专辑覆写、锁定字段、外部作品 ID、专辑封面引用与哈希，以及按媒体 SHA-256 绑定的歌曲条目。曲目条目可记录标题、艺人与专辑艺人、碟号与曲号、制作名单、外部作品 ID、锁定字段、可选的独立分曲封面引用（`covers/<sha256>.jpg` 与 `cover_sha256`），以及歌词引用。标准 LRC 歌词位于 `lyrics/<sha256>.lrc`（UTF-8）；当曲目选用多层翻译/音译或逐字时间歌词时，同时保存 `lyrics/<sha256>.json`（`schema = "wildstring.sidecar.lyrics.v1"`，并在单曲 `lyric_bundle_file` 引用），用于在删库重建时无损还原多层与逐字歌词。

书籍 manifest 的 `schema` 为 `wildstring.sidecar.book.v1`，包含公共书目字段、锁定字段、封面引用与哈希、按 SHA-256 绑定的电子书和有声书文件，以及校订章节。封面统一保存为解码验证后的 `cover.jpg`（或按曲 `covers/<sha256>.jpg`）；运行时直接从 `.wildstring/` 读取原图生成缩略图，不在运行目录冗余留存全量封面原图。

## 导入与优先级

分享来源中的侧车可读。仅允许白名单字段、规范路径以及经过体积限制的 JSON、合法 LRC 与结构化歌词 JSON、以及经 Pillow 解码校验的封面，目录和文件不得经符号链接打开。媒体哈希与条目匹配后才应用该条目和对应配件；还原音乐封面时同步维护 `tracks.has_cover=1`。扫描器跳过侧车目录中的音频文件计数，并维护目录级 `.wildstring/manifest.json` 校验状态，使增量扫库在音频本体未变时也能识别外部 `.wildstring/` 的新增、变更与移除。

优先级从高到低为本实例锁定覆写、哈希匹配的便携侧车、传统旁路文件、内嵌标签；侧车还原只将显式存在覆写语义的字段记入 `overrides`，不把普通扫描观测值写入锁定/覆写层；已启用歌词锁（`lyric_locks`）或非侧车来源覆写的曲目在增量同步时保留本实例选择。未知或不合规字段不写入库。导入和导出都仅包含公共作品信息，账号、收藏、播放计数、进度、书签、批注、认证、插件配置和服务器物理路径均排除。

## 导出与清理

FLAC 音频等价重链前从磁盘读取两侧标签。能完整转存的有效字段差异进入数据库覆写，已有应用内覆写优先。标准 ReplayGain 标签可随同音频一致的源文件更新。可完整转存的单段内嵌歌词经确认写入数据库，并导出到 `lyrics/<整文件 SHA-256>.lrc`。托管副本已删除歌词而来源仍带歌词，或标签、封面、歌词、章节差异无法转存时，保留独立副本。重链后按新文件的 SHA-256 刷新曲目、歌词和封面引用，音频匹配用的解码摘要仅保存在实例内。

音乐侧车除导出 UTF-8 LRC 原文与行级时间外，保留已选候选或便携包（`portable_bundle`）中的多层翻译、音译与逐字时间及生效偏移；在线搜刮历史候选池本身仍仅留在实例数据库内。

数据库内元数据、歌词、封面、章节、配对或托管路径变化后刷新对应侧车，并按需清理不再引用的过期 `lyrics/<sha256>.lrc`、`lyrics/<sha256>.json`、过期 `cover.jpg` / `covers/<sha256>.jpg` 及已无有效媒体的 `.wildstring/` 目录（包括曲目整理迁走最后曲目、专辑移入废纸篓及书目并入配对目录）。单次和批量资料覆写、外部候选采用及封面选择、歌词编辑和批扫撤回、审核后的 Agent 草案、导入覆写以及书籍章节标题校对均在数据提交后刷新；`tracks` 表持久化与 `(size_bytes, mtime_ns)` 绑定的音频 SHA-256 缓存以避免未改文件反复全量计算；管理员也可按库手动导出或由迁移前导出快照触发。写入与清理均限定在托管目录内，使用临时文件、同步落盘和原子替换；扫描来源保持只读，媒体原件保持原有字节。
