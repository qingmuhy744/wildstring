# 服务器身份、线路和连接安全

2026-11-05，已确认契约；各端实现和验证单独记录。

## 服务端

`GET /api/v1/server` 匿名返回 `instance_id`、`name`、`connection_policy`。
实例 ID 是持久 UUID，仅用于识别，不是服务器可信性的证明。客户端不得凭公开 ID
转发现有凭据；新增线路由用户单独登录后核对实例和账号。

所有者 `GET /api/v1/manage/server` 读取设置及每字段 `sources`（database/environment/default），
`PATCH /api/v1/manage/server` 修改 `name` / `connection_policy`；省略字段保持原值，
显式 null 清除该字段覆盖、恢复环境配置。名称 1–80 字，去除首尾空白。
页面数据库设置 > ENV > 默认值，不能通过真值判断配置是否存在。读取失败不回退 ENV。
默认创建的记录不算用户设置。部署参数（路径、端口、可信代理）仍由环境配置管理。

`connection_policy` 为 `mixed` 或 `https_only`。未设置新策略时继续沿用旧
`WILDSTRING_COOKIE_SECURE` 行为，返回 `legacy`；只有显式选择新策略后启用以下规则：

- mixed：HTTP 与 HTTPS 使用独立会话和 Cookie 名称，HTTPS 自动 Secure。
- https_only：HTTP 的 API 与 MCP 返回 403 `https_required`；健康和实例信息保留。
- 新会话绑定登录时的 scheme，禁止改 Cookie 名称后跨协议复用。
- 切换策略使旧策略下的会话失效，HTTPS 会话可在新策略间保留。
  切回 mixed 不恢复已注销的 HTTP 会话。
- 转发协议仅采信部署配置明确指定的代理。应用入口关闭 Uvicorn 隐式代理信任，
  统一由应用按 `WILDSTRING_TRUSTED_PROXIES` 处理。默认不信任代理。

## 原生客户端目标

服务器统一名称 + 可选本机别名；显示优先级：别名 > 服务器名称 > 地址。
同一逻辑服务器保存多个具名地址，线路顺序/别名/选择模式保存在设备。
Fallback 按优先级选择可用线路，连接成功后保持，故障后再选路；手动模式固定线路。
每线路分别登录、分别保存凭据。HTTP 逐线路显式允许；保留 TLS 校验，不自动降级 URL。
切换线路保留逻辑服务器的库、队列、缓存及播放位置，尝试缓冲后续播。
只自动重试可安全重放的读取，不盲目重放写入、助手消息或已开始的下载。
旧记录迁移为单线路，旧服务端保留单地址支持。

## 配置优先级范围

上述新设置采用显式覆盖；现有每种设置分别核对迁移，不能把自动创建默认行当页面设置。
AI 私有 .env 配置、已有 provider 环境代理继承不能在迁移时丢失。

## 当前实现的切换规则

- 保存单地址连接即建立默认线路，维持原来的存储键；添加线路不迁移或清空旧队列。
- Fallback 连续两次探测失败后按顺序尝试其他已登录线路；探测间隔 10 秒。
  音频连接错误可更早触发选路。一次播放失败不会反复在失败线路之间循环。
- 连接成功后保持当前线路；显式重新选择 Fallback 才重新从最高优先级尝试。
- 手动选线失败时保留原连接和原模式并显示错误；成功选择后不自动切换。
- 401 / 无效会话要求重新登录，不把权限错误当网络故障；`https_required` 可触发
  Fallback 选择其他预设线路。新增或重新登录线路始终由用户明确输入密码。
- 切线重建媒体请求并保留队列、位置和播放模式。下载会暂停，之后由用户续传；
  不自动重放写入。真实设备与 SD-WAN 切换、音频续播另行验收。
