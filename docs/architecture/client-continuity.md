# 手机操作、自动离线与跨设备接续

当前开发分支的实现说明，合并、版本发布与 home 部署分别核验。

## 歌单操作与刷新

Android「我的」长按歌单打开操作面板，提供打开、自动下载、编辑、普通歌单曲目排序和移除、删除。规则歌单编辑规则，♥ 我喜欢由收藏动作维护，均不提供手工改动规则结果的入口。网页支持歌单右击菜单、键盘菜单导航及独立的更多按钮。

歌单删除需要确认，只删除歌单，不删除托管音乐或已下载文件；相关自动下载订阅关闭。编辑、删除和排序仍使用版本校验，失败保留原状态并显示反馈。

Android 曲库列表与发现页使用下拉刷新，指示器为野弦三条弦的波纹。动画依照实际请求状态结束，不添加假等待时间。原有横向加载栏移除；页面中的操作失败仍可重试。

网页播放器只通过「词」按钮开关歌词；点击空白或普通点击播放动画不再切换歌词。歌词行的桌面跳转、触屏确认以及长按预览大封面保留。键盘聚焦封面按回车或空格也能预览。播放模式改用统一 SVG 图标，并扩大点击范围；收藏和音质选择使用与封面背景协调的样式。

## 下载设置

默认原音，用户可选择原音或 AAC 128／192／256／320 kbps，与在线播放音质独立。音质在入队时固定，只影响新下载；已完成文件不因改设置而重新下载。服务端已有规则继续生效：无损音频可以转 AAC，有损音频保持原格式，不将低码率音频升码率。

Android 提供仅 Wi-Fi 开关，默认打开；关闭后允许移动数据。网页默认仅在浏览器明确报告 Wi-Fi／有线连接时自动下载，用户也可允许移动数据或无法识别的网络；浏览器无法判断网络时不会假定为 Wi-Fi。网页的显式手动保存继续可用。下载期间网络变化会暂停不符合策略的自动任务。

在离线下载设置中选择需要自动下载的歌单，也可从歌单菜单开关。订阅按当前服务端和账号的本机存储隔离，适用于普通、规则与收藏歌单。打开、返回前台时，以及前台定期检查完整歌单分页，新增歌曲加入下载队列，已有文件去重保留。取消订阅、从歌单移除歌曲或删除歌单均不自动删除离线文件。手动暂停和下载失败保留，避免每轮自动重试；因网络策略暂停的任务在允许的网络恢复后可继续。

Android 已入队任务使用现有 dataSync 前台服务，切到后台后继续运行，受 Android 的服务时限约束。本次不增加系统后台定时唤醒任务；应用完全退出时不承诺发现歌单变化。网页同样需要页面打开，浏览器关闭后不承诺下载。两端的现有容量限制、权限和源文件身份校验继续生效。

AAC 初次生成可能没有 Content-Length。下载只在流正常结束且非空后标记完成，仍逐块执行容量检查；中断的未完成编码不能当作完整离线音频。AAC 续传仅使用对应资源的 ETag，不能把不同码率或不同源版本的字节拼接。在线校验仍比较原音的身份，避免将 AAC 缓存的 ETag 错当作原音身份。

## 跨设备接续

每个客户端可选择关闭、轻提示（默认）、自动恢复三种模式。默认提示是底部小卡片，不阻挡搜索或浏览。

| 模式 | 保存进度 | 其他设备最近暂停 |
| --- | --- | --- |
| 关闭 | 保留本机记录，仍可手工共享 | 不提示、不恢复 |
| 轻提示 | 开始播放、定期播放进度、暂停时保存状态 | 最近 30 分钟的暂停只提示一次，确认载入后保持暂停 |
| 自动恢复 | 同上 | 只在本机空闲且远端最近暂停时载入，保持暂停 |

服务端记录 `playback_state=playing|paused|ended|unknown`，并在设备从其他状态进入暂停时生成 `paused_at`。暂停后的定位或重复保存保留同一个暂停时间，不延长 30 分钟有效期。`handoff_eligible` 根据服务器时间和可用队列计算；当前正在播放、已结束、状态不明、过期以及空队列均不具备自动接续资格。

Web 和 Android 按账号、当前设备持久记住已提示的暂停事件（来源设备与暂停时间），刷新网页、重开应用或返回前台不会重复询问同一次暂停。其他设备真正恢复播放后再次暂停才产生新事件。提示出现后仍会重新检查；远端恢复播放、记录过期或队列不可用时撤回提示。点击载入和读取完整曲目后均复核远端状态、版本以及本机是否开始播放，避免过时操作替换本机队列。

同一账号、同一服务端共享队列、当前曲目、位置和播放模式。已开始本机播放时不在后台替换队列；加载远端曲目期间发生本机操作时放弃此次恢复。恢复先读取完整有效曲目，再更新队列；歌曲不可用或网络失败保留本机播放。

启动恢复本机旧队列不会自动覆盖远端记录；只有开始本机播放后才启用自动上传。收到版本冲突时停止覆盖，直到用户明确再次开始本机播放。远端记录被载入后不立刻回写成“新进度”，避免两个空闲设备互相触发。此功能是进度接续，不向另一台设备发送播放或暂停命令。

schema 23 在原快照表增加状态和暂停时间，原队列、位置、版本、账号数据保留。已有记录迁移为 unknown，不将更新时间误当成暂停时间。旧客户端可继续读写快照，其状态默认为 unknown；新版客户端遇到旧服务端不发送新增字段，也不将旧快照当作近期暂停。所有非空有效快照仍可在「其他设备继续」页面手动载入，不受自动提示的时间范围限制。
