# 联网检索、协议兼容与助手记忆

0.5.0 使用现有业务服务与持久任务，增加小型协议适配层；不引入通用出站 MCP 客户端。原有 MCP 继续提供曲库业务工具，联网检索先由内置助手直接执行 HTTP API（L1）。

## 模型连接

模型连接可选择 Chat Completions 或 Responses，及 generic / OpenAI / DeepSeek / 千问 / Gemini 兼容档案。档案负责请求参数，不能替代实际模型能力验证。已有连接、原实例 AI 的地址、密钥、权限与预算保留；旧客户端编辑新连接时，未提交的协议选项保留。

适配层保留 Chat 的 reasoning_content、extra_content 及工具调用内部字段；Responses 原样续接当前轮的 output items，包括推理与搜索状态。OpenAI 无状态请求显式索取加密推理内容和已启用原生搜索的来源。续接状态只在当前模型执行中使用，不展示为证据、不跨供应商转交。跨轮历史保留可见文本与来源；未持久化供应商原始推理状态，进程中断不承诺原生研究断点续接。截断响应不会当作完整回答执行。

推理强度和 Token 上限由用户配置；auto 沿用模型默认。DeepSeek 不接受 medium/xhigh；千问映射到 enable_thinking，其具体强度仍由模型决定。Gemini 此批只实现其官方 Chat 兼容协议，原生 Google Search 与 Claude Messages 尚未增加。

Responses 可显式启用 OpenAI / DeepSeek Pro / 千问原生 web_search，具体可用性仍按模型、地域与账号验证。搜索事件及引用归一为来源。原生搜索可能在一次模型请求里执行多次，不受独立搜索请求上限约束；默认关闭，能力检测不宣称已验证原生搜索。后台巡检及推荐、摘要请求不额外开启原生搜索。

## 独立检索

每用户配置 DeepSeek 官方 Search / Fetch 或 Tavily Search / Extract，密钥仅存服务端，默认关闭。独立搜索与主模型供应商无绑定，也不会自动选择其他连接或备用引擎。模型可重写查询、发起多次搜索、按需要读取正文；每轮最多四次，搜索最多五个结果，正文最多16000字符。

read_webpage 只接受本轮搜索返回的 source_id。服务端只请求固定的官方搜索/读取 API，不从服务器直接打开模型提供的网页 URL。来源只允许公共 HTTPS 格式，不含用户名、密码或控制字符；保留定位资料所需的查询参数。网页内容进入 tool 数据，不获得工具执行或草案批准权限。

搜索和读取分别预留每日请求额度，超时等结果不确定情况不自动重试。15分钟结果缓存按用户、供应商、配置版本、操作和参数隔离；缓存命中不再次扣请求额度。配置修改或撤销后旧执行会停止，不复用另一用户的凭据或结果。独立请求预算属于应用请求上限，不等同供应商信用积分或货币费用。

聊天结果保存来源标题、URL、摘要、来源日期（未知保持空）和读取时间，两端显示可点击来源。库外查询结果不自动变为可播放曲目，也不证明发行全集。首发、重录、再版、精选集和检索日期须分别判断，资料冲突保留未知。已存在的 MusicBrainz / Last.fm / AcoustID / CAA 候选流程继续复用。

## 上下文摘要与长期记忆

保留用户最后19条可见消息；未摘要消息达到20条且本轮预算至少两次时，用一次模型调用压缩较早内容，并为最终回复保留预算。摘要生成失败仍可继续有限上下文聊天，不将失败结果记为摘要。摘要保存到当前对话，能够查看及清除；属于有损压缩，不保证精确回忆全部原文。更早历史的单次摘要输入最多40条、单条3000字符，超长旧历史仍有上下文限制。

长期记忆仅通过已登录用户的管理界面明确保存、编辑和删除，每用户最多50条、单条1000字符；模型不自动提取、写入或推断记忆。聊天最多使用12000字符的已保存偏好。偏好只是上下文，不提供权限，用户本次指令优先。关闭记忆使用后不发送给模型；删除记忆会清除本人摘要，以减少旧摘要携带过时偏好。删除对话不会删除独立记忆。

摘要和记忆按用户隔离；普通 API/MCP 工具无法代用户保存长期记忆。两项开关可在 Web/Android“联网与记忆”中管理，历史保留设置继续生效。

## 升级与验证边界

schema 18 → 19 为新增表及连接 options 列，保留曲库、账号、歌单、连接与凭据；升级前备份 SQLite 和 agent-secrets。测试会从旧结构验证迁移，不能只修改 user_version 来模拟旧库。回滚镜像需要配套恢复数据库。

协议、检索、权限、预算、来源、缓存、摘要和记忆以合成响应与真实本地 HTTP 夹具验证；真实供应商账号可用性、中文覆盖率、费用及原生搜索模型矩阵需用用户自己的连接单独检测。未进行真实账号测试时不宣称已通过。
