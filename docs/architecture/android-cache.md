# Android 本机缓存（未发布批次）

本策略由用户在 0.1.0 后的改进批次明确启用。服务端仍是事实来源；不会改动 Web 的 `private, no-store` 策略，也不会启用通用 OkHttp 或 Coil 磁盘响应缓存。仅显式保留下列白名单内容。

| 内容 | 默认上限 | 设置选项 | 更新方式 |
| --- | --- | --- | --- |
| 已浏览的曲库页、单曲和歌词 | 32 MB | 关闭 / 8 / 32 / 64 MB | 页面或歌词先读缓存，再请求服务器；收藏 / 歌单写入后使列表失效 |
| 已显示的封面 | 64 MB | 关闭 / 32 / 64 / 128 MB | 24 小时内复用，之后联网更新；网络不可用时可读取旧缓存 |
| 最近播放音频片段 | 256 MB | 关闭 / 128 / 256 / 512 / 1024 MB | Media3 随实际播放写入，按最近使用淘汰；已验证内容 6 小时后尝试 HEAD / ETag 校验，网络不可用时继续使用已有片段 |

设置调整后在后台执行容量收缩；关闭会清理对应磁盘缓存。容量统计指内容缓存，不包含 Room 索引、文件系统开销、内存解码图片或播放器缓冲。缓存位于应用私有 `cacheDir`，系统存储不足时可回收。清理不删除服务端曲库、收藏或歌单；清理时仍在进行的播放 / 请求可能继续产生新缓存。

## 会话与失效

- 有效登录 Cookie 对应一个随机、本机保存的缓存身份。Cookie 刷新沿用该身份；退出、401、Cookie 过期和切换地址使旧身份失效。0.1.0 的已有会话首次使用时补建缓存身份。
- 文件键、图片内存键和音频键都按缓存身份隔离；读取前检查有效本机会话。服务器地址仍严格限制 origin 和 base path，拒绝跨源重定向及 TLS 降级。
- 退出、失效和切换地址后清理旧文件及播放器队列，拒绝旧请求晚到的写入；旧请求的 401 不得注销后来建立的新登录。
- 音频缓存位于单例 SimpleCache；活动读取仍检查会话，旧身份晚到的音频片段立即移除。只缓存正常资源，不缓存登录、密码、Cookie、认证状态或错误响应。
- 401 / 403 / 404 / 409 不能伪装为网络中断并返回音频；证书错误也不能被缓存兜底掩盖。离线无法即时得知服务器撤销会话，待联网请求检查，这是短时断网播放的边界。

## 播放与交互

- 只缓存播放过程中请求到的片段，没有预下载整首或预取下一首，也不承诺所有最近曲目完整可离线播放。未缓存片段仍需网络；完整下载管理另行设计。
- 列表请求带序号，旧请求取消或晚到不能覆盖新页面、错误和加载状态。标签页及返回路径保留浏览状态；加载提示延迟显示并预留固定高度。
- 进度单独更新；曲库不会因每 500 毫秒的播放位置变化重新提交状态，队列仅在实际变化时重建。缓存读写和容量收缩放在 IO 线程。
- 播放、切歌、收藏和队列操作使用轻量系统触感反馈，支持本机独立开关；不请求额外震动权限或覆盖系统触感偏好，参考 [Android 触感反馈](https://developer.android.com/develop/ui/views/haptics/haptic-feedback)。
- 经典主题保留原暖橙 / 深绿深色配色，新增浅色以及跟随系统日夜配置的自动切换；切换保留播放状态。红布是独立固定配色彩蛋，不随系统深浅变化。
- 播放背景从真实封面取色，并在 Default 线程对 64 × 64 图像做三遍可分离模糊；不占用播放线程，不依赖 Android 12 的 RenderEffect。无封面时使用当前主题背景，加载失败不阻断播放。红布保留正红织物底、叠加低透明度封面氛围。
- 红布背景使用静态矢量层次，避免持续的装饰动画竞争播放资源。Compose 过渡遵循系统动画时长设置。

## 验证

新增磁盘缓存容量 / 淘汰 / 重启恢复 / 损坏恢复、认证请求代际隔离的 JVM 测试；设备测试覆盖真实认证音频、断网缓存重播、设置调整、两种主题和手机 / 平板截图、退出和服务器切换后的缓存不可读。具体执行结果写入 CHANGELOG；模拟器检查不能代替用户真机的蓝牙、后台及瞬时音频卡顿验收。
