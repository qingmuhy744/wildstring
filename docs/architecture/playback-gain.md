# 响度均衡与手动调整

Web 播放条「响度」及 Android 歌曲菜单「响度均衡与手动调整」提供三种独立设置：自动均衡（关闭／单曲／专辑）、整张专辑增减、当前单曲额外微调。设置按账号保存；切换设备后在线读取，Android 缓存已读取的值供离线播放。增益在客户端输出 PCM 上应用，不修改音频文件和导入源。

总增益为 `自动均衡值 + 自动前级 + 专辑手动值 + 单曲手动值`。关闭自动均衡后，手动值仍生效，自动前级不生效。每项手动值和前级允许±12 dB，专辑和单曲可各自归零。保存携带版本号，避免其他设备的更新被覆盖。

优先读取标准 `REPLAYGAIN_TRACK_GAIN`／`REPLAYGAIN_ALBUM_GAIN` 及相应峰值，支持 FLAC、ID3 TXXX、MP4 iTunes 自定义字段的大小写形式。专辑模式使用已有专辑 ReplayGain；没有时使用单曲值。首版没有计算整张专辑的响度聚合，不能把单曲分析标成专辑分析。

管理员可以明确点击「分析本曲响度与峰值」，由 FFmpeg `loudnorm` 读取音频得到 integrated loudness 和 true peak，按 -18 LUFS 计算单曲增益并保存数据库。分析不输出重编码音频。这是参考 ReplayGain 的无损播放调整，不承诺与 foobar2000 不同扫描器的数值完全相同。长文件任务最多10分钟，重启后可恢复队列，文件版本变化时旧结果失效。静音／异常输入有明确失败状态。

默认开启防削波：有峰值时限制放大到 `1 / peak`，未知峰值时只允许衰减。先分析可获得峰值，或由用户明确关闭保护后自行调整。客户端总倍率限制0.001–32，并显示请求值、实际值及是否受峰值限制。Web 使用 Web Audio GainNode，Android 使用 Media3 PCM AudioProcessor，两者均独立于日常音量控制；不支持 Web Audio 的浏览器只做可用的衰减降级。两端继续共用原音与 AAC 播放路径。

验证包括真实标签、账号隔离、版本冲突、叠加与归零、源文件摘要不变、FFmpeg 实际分析、Web 表单与音频播放、Android PCM 数值与 UI。实际设备声音和系统输出还受设备音量及系统音效影响。
