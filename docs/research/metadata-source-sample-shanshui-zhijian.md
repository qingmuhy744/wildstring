核对日期：2026-10-16。方式：公开网页与官方元数据接口的只读查询，未使用用户音频，未执行音频指纹识别或导入。本次只核对一个样本，不代表完整中文曲库覆盖率，也不代表已经完成来源接入。

## 结论

MusicBrainz 能找到这首歌的基础信息，但本次返回的录音没有贡献关系；CAA 的数字发行版缺封面，CD 版及专辑组有封面。酷狗和 Shazam 页面可读到更完整的创作署名。因此，不能仅凭“能检索到曲目”认定 MusicBrainz、CAA、AcoustID 的组合已经足以完成中文歌曲整理。

下一阶段应重点验证中文音乐平台及商业发行资料的字段覆盖；MusicBrainz 用于辅助身份和发行版本关联，CAA 用于补充匹配封面，AcoustID 用于录音识别。来源选择同时考察字段覆盖、版本准确性和实际接入稳定性。

## 对方案的修正

1. 保留已确认的第一批本地整理、第二批联网，以及联网建议确认后应用的策略。
2. 第二批先比较中文平台和商业发行资料，MusicBrainz 不预设为唯一或优先主数据源；不同字段可以来自不同来源。
3. 每个字段保留来源、原文、匹配实体、采集方式和采集时间。歌词头部署名属于一种独立证据；不能仅因多个页面转载同一份内容就算多个独立确认。
4. 将“检索到曲目”“字段齐全”“录音/发行版本正确”“封面可取得”“能够稳定接入”分别验收。
5. 再选 20–30 首有已知答案的中文样本，包括合作曲、翻唱、现场、同名歌及不同发行版，比较各来源的准确率与缺失率。QQ 音乐、网易云等作为待实测候选，不能把搜索引擎未返回页面当成平台没有资料。

以上是本次证据支持的方案调整，尚未实现任何平台适配器，也未验证正式批量接口或全库识别效果。

## 补充核对：网页资料与官方接口

2026-10-16 核对公开开发者资料后，不能将酷狗和 Shazam 确定为首期联网接口来源：

- 酷狗[开放平台](https://open.kugou.com/)公开小程序、识曲等能力，[曲库开放组件](https://open.kugou.com/docs/open-player/)是客户端在线播放 SDK；本次未找到可供 Python 后端查询完整词曲编的官方公开接口。
- [ShazamKit](https://developer.apple.com/shazamkit/)提供识曲 SDK；[SHMediaItem](https://developer.apple.com/documentation/shazamkit/shmediaitem)的公开属性包括曲名、艺人、图片、ISRC 等基础信息，但未列出网页展示的完整词曲编、演奏及制作署名。本次未验证完整署名的服务端查询接口。
- 上述结果不等于断言平台没有合作接口，也不否定网页中已核对的署名；它说明这些页面只能证明资料存在，不能证明本项目已有稳定接入方式。

因此，来源筛选须先验证实际调用能力，再比较覆盖率。此前讨论中“酷狗＋Shazam”的首期接入安排撤回，二者保留为研究候选；第一批本地整理与联网结果确认后应用的既定选择保持有效。
