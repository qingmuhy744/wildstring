# 播客收音机与广播报试用版

2026-10-25，本地 Web 实现。

界面采用猫王式复古便携收音机：奶油与酒红机身、黄铜饰边、烟熏显示窗、
双波段刻度、机械按键、音量旋钮。FM 刻度映射播放进度，按键支持
后退 15 秒、播放暂停、前进 30 秒，旋钮同步真实音量。
移除天线与提手，控制键与下方的后退、播放／暂停、前进标注逐个居中对齐；状态灯与悬停反馈使用暖色。
电平条为播放状态装饰动画，不表示经过测量的音频响度。

右侧广播报保留报头、日期和页脚，长标题与正文在阅读区滚动；简介中
已有的方括号时间码可跳转播放。桌面两栏顶边及底边对齐，窄屏纵向滚动。
移除节目档案侧栏，所有屏幕宽度下正文均铺满报纸内宽，与标题左右对齐，
保留纸张两侧留白。接下来播放的标题、数量和顺序提示同排。
浅色采用米色桌面、象牙纸与深色油墨，深色采用橄榄灰桌面与暖色文字。
右上角复用浅色、深色、跟随系统偏好，减少动态效果时关闭电平动画。

## 续播规则

- 以同一节目 ID 为边界，不把同作者不同节目自动合并。
- 默认跟随播放时列表的时间／期号方向；其他列表排序默认从新到旧。
- 可选择从旧到新、从新到旧或关闭自动续播；默认跳过已听完。
- 手动队列在前，自动尾部最多预排三集，随切集补充；本次主动移除项不重新插入。
- 关闭自动续播只移除自动尾部，保留用户手动条目。
- 每个账号、每个节目的顺序偏好保存在当前浏览器，不跨设备同步。
- 断点进度通过既有播客进度接口保存；只有自然播完才自动标记完成。
- 续播属于播放器逻辑，关闭全屏界面仍有效；不沿用音乐的随机或循环模式。
- 自动续播与服务端下载策略独立，本次未改变既有预缓存接口。
- 播客支持 0.5×、0.75×、1×、1.25×、1.5×、1.75×、2×，保持音调；
  倍速按账号保存在本机浏览器，切集和刷新后恢复。切回音乐使用正常速度，
  再播放播客时恢复播客倍速。全屏与桌面底栏共用同一设置。

## 验证入口

`make test-podcast-web` 使用独立数据库、本地合成音频与内嵌封面验证队列、
断点、昼夜主题和手机布局，无需外部播客服务。
`make ci` 仍用于完整项目检查。

本次交付为本地试用，发布和部署需单独核验。
