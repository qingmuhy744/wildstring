# 播放器设计核对（2026-11-07）

以 `DESIGN.md` 和 `docs/product/scope.md` 为准。用户提供的 `vinyl-player-redesign.kui.fig` 缩略图仅作为视觉参考：它强调平静底色、唱片、封面与主播放按钮；不是实现指令。

## 本次范围

- Android 音乐播放页：黑胶样式使用主题画布，保留唱片、中心封面、唱臂和真实播放状态驱动的运动；减淡唱纹、调整封面与唱臂比例。歌曲标题采用衬线字，播放时间和音质信息采用等宽字且音质字号达到最小要求；关闭系统动画时唱臂和样式切换即时完成。封面和磁带样式仍可使用封面氛围背景，播客播放器也保留这一效果。
- Web 播客收音机：去除非 `transform` / `opacity` 的过渡；电平灯用透明度变化，保留原刻度纹理及减少动态效果设置。
- 静态抽查 Android 播放组件、Web 播客播放器、Web 聚焦样式及 Apple 播放背景；不代表四端每个页面已逐一验收。Android 播放时间和音质信息、Web 收音机时间均使用等宽字体。其他页面的主题令牌、边界态和辅助功能未全面审计。

## 补充：四端默认唱片与收音机按键音效（2026-11-08）

- Web、macOS、iOS、Android 四处播放器样式缺省从未设置统一为唱片；已显式选择封面或磁带的偏好保留。Web 与 macOS 的唱片视觉改为主题画布（不再铺全屏封面氛围层），iOS 接入默认唱片与主题底色，Android 黑胶页减淡唱纹、细化唱臂、衬线标题、等宽数字，宽屏播放视觉与控制上限放宽到 480dp。DESIGN.md §6.7 记录规则。
- Web 播客收音机播放键新增可开关的合成咔嗒声（≤120ms，Web Audio 合成，无音频资产；默认关闭，按账号存浏览器，仅播客播放键触发）。规则记入 DESIGN.md §2「Honest Analog Tactility」。
- 验证：Web 定向套件（playback-styles、personal-settings、podcast-player、bilingual-lyrics）通过；radio-click.spec.ts 覆盖默认关闭、开关持久化、仅播客触发。macOS/iOS 真机视觉仍未覆盖。

## 补充：收音机 VU 表接入真实音频电平（2026-11-08）

- 播客收音机 L/R 电平表从纯 CSS 装饰动画改为真实输出电平：在 `playback-gain` 已有播放图上挂 `AnalyserNode` 分支（`MediaElementSource` 每元素只能建一次的约束决定 tap 必须在建图处）。RMS 换算 −60 dBFS..0 dBFS 到 0..1，VU 弹道快攻慢放，单声道源经 `channelCount=2` 上混后 L/R 等值；暂停/缓冲/出错与减少动态效果时归零或冻结。样式用 `transform: translateX` 滑轨揭示电平（替代原 clip-path 动画，符合动效约束），`receiver-level` 关键帧移除。
- Web 端实现；DESIGN.md §2 已补规则。radio-click 的 AudioContext stub 需同步支持 analyser 建图分支（try/catch 兜底，缺失时无声不影响播放）。

## 补充：macOS 全屏播放器重排（2026-11-08）

- 队列开关从顶部胶囊移至底部传输条（右侧与歌词、定时、桌面歌词同组，对齐 Web 与 Apple Music 惯例）；队列改为底右锚定浮层（≤360×520pt、18pt 圆角、主题面板底+描边+柔和投影，距右边 36pt、距底 126pt），不再推移舞台与传输条，Esc 或点击画布空白关闭。
- 舞台加宽：居中唱片上限 500pt、带面板 400pt（33% 舞台宽、窗口高−150 上限），曲目标题 26pt 衬线显示字；传输条最大宽度 980pt。
- 唱片质感：盘面叠加固定房间光泽（AngularGradient，不随盘转）、唱臂改为金属胶囊臂+深色唱头壳+珊瑚色针尖、枢轴径向渐变。规则记入 DESIGN.md §6.7 与新增 §6.8。
- 验证：新增 `MacFullscreenRenderingTests` 渲染四态（宽/窄×浅/深+队列展开）写 PNG 逐张查看；`make macos-test` 37 项通过。真机与正式签名包未验收。
