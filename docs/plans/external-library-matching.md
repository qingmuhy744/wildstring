# 库外推荐匹配与 Android 收听统计

- 库外推荐先判断作品是否已收录。搜索与比对使用同一曲库范围，按可用歌曲的标题、署名艺人和来源明确给出的专辑匹配。已收录条目退出新推荐，已收藏的线索留在想听，多个匹配版本由用户按专辑选择。
- 读取已缓存的推荐时按当前曲库重查。新批次缓存候选来源索引，状态和来源统计可以在本地更新。每日推荐继续只关联可确定的录音。
- 安卓听众打开收听统计时，先看到累计收听时长和三项计数，再从带封面的常听歌曲开启播放。参照 Apple Music Replay 的累计数据与 Spotify 的可播放榜单，使用现有统计与排行接口。累计数据为主，初始加载、零数据、权限及获取失败保留各自反馈。延用现有色板、数字与封面样式。
- L3 验收。更新推荐接口、Android、Web 的旧断言，覆盖同名录音、其他库与没有权限的库、旧批次、想听、版本选择和统计点播。检查桌面与窄屏、浅色与深色的实际截图，运行受影响测试与远端 CI。
