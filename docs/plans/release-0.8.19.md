# 0.8.19 补丁发布

## 目标

按用户本次授权，将 PR #160 合入 main，并发布下一补丁版本 0.8.19。发布范围包含 main 上已合入的 Android 曲库浏览调整、播客回归测试迁移及播客点播缓存性能修复。

## 不碰的边界

不修改真实曲库、部署实例、账号或签名密钥；不绕过保护规则或失败检查，不移动已有标签，不启用自动合并。使用现有发布工作流和 CI secrets 构建签名包。

## 方案

1. 解决 PR #160 与最新 main 的更新记录冲突，保留双方改动并重新检查后合并。
2. 同步 Python / Web / Android / Apple 版本至 0.8.19；Android versionCode 55，Apple 构建号 54，数据库 schema 保持 54。更新锁文件、README、版本台账、范围记录和发布说明。
3. 通过发布准备 PR 合入 main，核对最终提交的 CI、Android APK、Apple 检查，并手动运行 run_emulator=true 的完整 Android 设备回归。
4. 全部门禁通过后创建 v0.8.19 标签，等待 Release 工作流生成固定签名 APK、Web ZIP、Mac DMG、校验和与双架构容器镜像，再核对公开发布状态。

## 验收（按 AGENTS.md §3 定级）

L3。本地执行版本一致性与锁文件检查、make check、make test-affected 和 make ci；Android 构建、单元测试和设备编译使用 Android CI，完整设备回归以最终 main 提交的手动工作流为准。Apple、容器及正式包安装检查由对应远程工作流验证。逐项区分已完成、运行中、失败及未覆盖，保留首轮设备用例不稳定记录；模拟器不代表真机双设备或真实网络验收。

## 风险与回滚

发布前不创建标签；失败时先排查再重试原提交的工作流。已推送的发布标签不移动。版本与应用签名保持连续，用户音乐和数据库不迁移；出现问题时通过后续补丁处理，不覆盖既有正式附件的版本身份。
