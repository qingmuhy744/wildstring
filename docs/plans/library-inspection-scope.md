# 曲库检查范围与进度

- 「检查最近入库」按入库时间倒序选取当前曲库的可用歌曲，用户可调整首数。「检查整库」检查提交时当前曲库的全部可用歌曲。显式指定歌曲 ID 的 API 请求沿用原有范围校验。
- 整库沿用现有后台任务、授权与恢复机制，按批次写入进度。任务固定曲目范围，显示已检查首数与总首数。结果分页，任务列表读取摘要。
- 使用现有本地规则；AI 仍由用户选择，读取同一检查结果中的有界证据。现有任务用已保存的范围恢复。
- 按 L2 验收。用不同入库时间、超过默认上限的曲库、任务恢复和多曲库授权检查范围。Web 验证两种范围、进度、结果分页及浅深主题下的桌面和窄屏视图。
