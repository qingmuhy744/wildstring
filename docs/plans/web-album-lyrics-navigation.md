# Web 专辑歌词与播放器跳转

- 专辑更多菜单提供歌词查询。弹窗先显示专辑和开始查询，扫描目标、限速和强制重扫放进查询选项。使用现有预检、后台任务与候选应用流程，最近任务可以从同一入口回看。
- 桌面专辑更多菜单从按钮下方向右展开，所有集合的菜单受工具栏边界约束。歌词查询选项中的强制重扫使用整行宽度。
- 扫描结果中的歌词候选展开在歌曲下面，使用「批量更新时跳过此曲」显示保护状态。时间偏移输入与单位一组排版，浏览器回归测量同行和菜单边界。
- 底栏曲目信息显示可点击的艺人和专辑。复用曲库导航，验证从管理中心、个人设置和音乐页面跳转与返回，以及播放和队列保持。
- 资料核对弹窗在专辑标题旁显示待核对数，在歌名旁标明正在查看的位置。候选确认或拒绝后使用最新的待核对数，跳过仅移动查看位置。
- 应用字段或拒绝该曲所有建议后，跳到本页下一首仍有可核对资料的歌曲。没有可核对资料时显示空状态，歌曲没有候选时不能重复拒绝。
- 从「待确认」或专辑查询结果打开同一套资料核对。只滚动长弹窗的正文，保存与关闭随时可达。更新元数据的按钮与正文共用内边距。关闭有未保存改动的歌曲或专辑编辑器时询问是否放弃。
- L2 验收。核对底栏在桌面与 390px 的浅深色布局，覆盖未播放、失败、权限不足与长文案。更新专辑歌词和歌曲所属专辑的浏览器回归。
