# Android 离线批量操作

## 目标

消除批量入队的主线程 Keystore 放大和批量权限清理的逐首写盘。音乐批量下载实际新增或恢复超过 100 首时先确认。

## 方案

- 入队按批次读取音质，在后台合并提交队列。下载过程中复用账号偏好句柄，容量修改即时生效。自动歌单走同一入队路径。
- 权限收回按批次撤销离线项并清理文件。AAC 校验失败结束当前任务并继续队列。
- 在歌曲行复用多选面板，长按预选单曲并在单曲菜单提供同一入口。曲库歌曲页撤下列表级低频菜单。
- 使用共享确认状态覆盖主动离线入口。自动同步沿用既有授权。

## 验收

L2。反查歌曲列表工具栏、多选和离线测试，覆盖 100／101、已存在和暂停任务、取消、批量入队、AAC 失败以及权限撤回。在模拟器核对浅深主题和布局。
