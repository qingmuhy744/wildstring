# Web 待播弹窗跟随保存结果刷新

## 目标

## 不碰的边界

- 按用户要求加入 Android 修复 PR #165，独立提交 Web 修复；不扩展到全端续听统一，也不更改服务端队列协议。

- 浏览器只用临时合成曲库，不访问真实运行数据。

## 方案

- 反查 `wildstring:podcast-queue-saved` 的生产与消费；弹窗消费完整的已保存队列，重新解析条目并同时更新版本、顺序和满额提示。

- 沿用弹窗既有读取／解析边界，不增加全局状态层、轮询或等待时间。
