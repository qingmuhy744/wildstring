# Android 曲库浏览减噪

## 目标

让专辑适合快速浏览，释放艺人角色筛选空间，降低歌曲菜单与字母栏的视觉竞争。

## 不碰的边界

不改配色、接口、排序语义、播放队列、曲库数据或发布版本。独立于 Android JVM 测试迁移 PR，以远程 main 为基线。

## 方案

- 按 `DESIGN.md` §5.3 调整手机专辑网格，平板保留自适应布局；加载骨架采用同样网格。
- 默认艺人／专辑页不显示总数，搜索时保留结果数量；角色筛选使用释放的横向空间。
- 专辑排序入口与歌曲行菜单使用现有次级文字色。歌曲行保留尾部独立操作区、文字截断与触控目标。
- 已有字母栏独立布局和闲置淡化效果保持现状，通过相关设备用例确认。

## 验收（按 AGENTS.md §3 定级）

L2：`make check`、`make test-affected`、`make android-test`，实际设备渲染手机与平板、浅深主题的歌曲／专辑／艺人页。检查菜单对齐与触控目标、索引间距、专辑列数及长文案，走通排序、角色筛选、菜单、播放、切页和返回；保留并核对空、加载、错误与权限不足状态。修改共享组件后用 `git grep` 反查全部使用处。

## 风险与回滚

修改前检查相关测试与计数文案引用，保留搜索反馈。网格变化不得替换已有滚动状态或服务器绝对索引。没有新增动画；字母栏现有效果由已有设备测试验证。设计规范与实现分别提交，必要时一起撤销。
