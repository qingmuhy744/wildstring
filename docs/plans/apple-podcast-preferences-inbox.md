# Apple 播客续播、通知和助手音乐偏好

## 目标

- 节目续播设置在 iPhone、iPad 上选择后立即用于切集和自然接播。保存失败时保留该节目的选择，重试保存同一节目。
- 通知页在无未读时隐藏批量已读操作。加载、空列表和读取失败分别呈现，读取失败可原地重试。
- 在 iPhone、iPad 的助手中提供按账号管理音乐偏好和启用开关。编辑使用服务端版本，保存失败保留输入。

## 实现与范围

- 播客复用 Apple 共用的按账号队列模型、节目偏好接口和串行保存路径。按节目保留尚未确认的选择，保存成功后更新服务端快照。节目设置与手动待播保持各自的播放顺序。
- 通知沿用原有列表、筛选、下拉刷新和已读接口。首次读取失败显示错误与重试，刷新失败时保留已显示的通知。
- 音乐偏好沿用助手已有的本人列表、新增、修改、删除与偏好接口。
- 以主线为基线，在独立工作树验证。对 Apple 共用播客核心补模拟慢响应和 503 回归，并核对 macOS 调用。通知页走通加载、空、正常、错误及重试，查看手机和平板浅深主题截图。
- 音乐偏好验收新增、编辑、删除、开关、跨端读取和版本冲突。使用合成账号测试中英文长文和键盘下的文本可见性。
