# 0.9.0a1 Android / Web UI 审计修复

## 目标

按用户确认，将首轮审计的三个 P1 纳入 0.9.0a1，依次处理共享进度条语义、手机听书控制入口、Web 阅读错误恢复。用户已授权开始实施，并授权使用 GPT-6.2 Sol 子代理协作。随后处理新标准复核确认的两端字号与文字对比度；修复阅读器时一并处理关闭后重开与面板退出，固定底栏一并修复焦点滚动避让。实现与验收证据分别记录于下文。

## 不碰的边界

- 本批仅覆盖 Android 与 Web；不新增 macOS / iOS 书架。
- 保留现有工作区的书架、听书和侧车实现，不改同步协议、曲库数据或存储行为。
- 字号规范已由用户确认并更新于 [DESIGN.md](../../DESIGN.md) §4、§5.2；实现整改单独核对，不将规范更新写成代码已完成。
- 两端字号与文字对比度已获本次实施授权：共享组件使用现有文字强调令牌，保留主色的填充用途；中文状态、操作、元数据与功能数字分别按 DESIGN.md §4、§5.2 核对。
- 阅读器关闭后重开与 Web 固定底栏遮挡焦点纳入关联修复，单独记录，不混入原三个 P1 的完成统计。
- Android / iOS 外接键盘适配按 DESIGN.md §5.2、§5.3 的既定范围处理，不因审计建议扩展产品目标。

## 方案

### 1. Android 共享进度条语义

在 [PlaybackSlider.kt](../../frontend/android/app/src/main/java/com/wildstring/app/ui/PlaybackSlider.kt) 集中补齐进度范围、调节动作、禁用状态和已播/总时长描述。保持点击、拖动与无障碍调节使用同一进度提交行为。

调用方核对使用 `git grep`，并用 `rg` 补查当前未跟踪的新增实现；范围包含音乐、播客和有声书，不能漏掉新建的 BookAudioPlayerScreen。核对各调用方的时间单位和提交回调，避免将不同时基的值直接格式化为时间。

### 2. 手机 Web 听书入口

为纯有声书底栏提供可达的更多/展开控制入口，承载倍速与睡眠定时，复用现有 BookAudioSession 状态。播放、暂停与进度保持可达；章节在展开区或现有书籍详情中保持清晰入口。按 DESIGN.md §5.3 重排，避免把桌面控制直接全部塞进窄屏底栏。

### 3. Web 阅读错误恢复

区分正文加载失败、首次进度读取失败和同步冲突：可恢复加载失败提供原位重试；冲突允许显式重新读取服务端进度并恢复保存能力，保持已加载正文可用。恢复沿用 [书架个人状态契约](../../contracts/bookshelf.md)，不增加静默抢占或覆盖其他设备进度的规则。

### 4. 两端字号与配色

Android 核对共享 TextButton、强调文字、labelSmall 中文调用、阅读页码透明度、曲目数量与听书倒退标识；保留表头与纯数字所允许的字号，按角色选用现有字体样式。Web 核对导航、曲库、底栏、书架、手机控件与拟物收音机的功能文字，并修正当前播放行和播客状态的强调色。纯装饰刻字保持例外；字号变化后核对窄屏换行及大字体布局。

### 5. 关联交互修复

阅读器退出后丢弃旧路由加载结果，先关闭顶层面板并恢复适当焦点。固定播放器根据实际高度提供浏览器焦点滚动的避让空间，核对管理表单的 Tab / Shift+Tab 与页面末尾可见性。

### 协作与变更隔离

- Android 子代理负责 Android 源码与测试；Web 交互子代理负责阅读器、听书入口及关联测试；Web 样式子代理负责共享 CSS 字号与配色；主代理负责协调、计划更新和跨端验收。
- 子代理统一使用用户指定的 GPT-6.2 Sol。以执行前工作区为基线叠加本批修改；按用户确认，将设计规范、必要的书架/听书/侧车前置实现、UI 整改分批提交。本地 AI 测试工具保持独立，不回滚其他工作。
- 完整工作区基线已保存在 /tmp/wildstring-ui-implementation-baseline，供审查本批增量；不将该本机路径作为产品接口。

## 实施记录

- Android 在共享 PlaybackSlider 提供毫秒范围、时间描述和调节动作；音乐、播客、听书走真实播放实例验证。共享 TextButton 默认采用现有文字强调色，危险操作保留独立语义；中文功能文字、页码与曲目数量按现行规范修正。
- Web 手机听书提供更多控制面板；目录、正文和首次阅读进度分别可重试，进度冲突显式重读后恢复保存。临时保存失败会在下一次保存成功后清除提示，正常退出仍保存最后位置。
- Web 修复阅读面板关闭层级、退出回焦、过期路由请求重开、滚动模式的章节导航标签及固定播放栏焦点滚动避让。长章节列表使用可收缩的单列网格；短视口收音机与播放操作各占完整一行，避免真实浏览器放大后裁切。
- Android 的倒退/快进数字采用真实等宽文字并随系统字号缩放，与箭头分开排布；章节序号列按字宽测量，分页底部预留空间按实际分项像素取整。
- 两端共用既有文字/表面令牌，不整体替换填充主色。Web 补查修复了选中目录按钮悬停时的浅色前景错误，以及收音机真实阴影背景上的队列文字对比度。
- 原审计的听书缓冲动效、空状态/权限文案细分、系统栏主题时序与助手降噪属于剩余范围，不能因本批实施视为已关闭。原生外接键盘适配继续在本批范围外。

## 风险与回滚

- 共享进度条影响三类播放器，重点核对时间单位、拖动结束和无障碍提交是否重复或遗漏。
- 移动展开面板不得遮挡主要播放操作，需核对打开、关闭及窄屏长文案。
- 进度恢复必须先读取服务端基准，再建立可保存会话，保持现有冲突保护。
- 按三项独立形成可审查改动；规范修改与功能修改分开提交，回滚时保留用户原有工作区内容。
