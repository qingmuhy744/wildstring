# 音乐来源重绑与硬链接迁移

## 目标

保留曲目 ID、收藏、歌单和播放记录，为已有曲目重新选择来源。在同一期交付单曲重绑和按库预览、迁移。

## 边界

- 只处理同库已注册的只读来源及 FLAC、MP3、M4A。三种格式均可仅绑定，字节相同的文件均可重链。音频等价重链首版只做 FLAC，核对采样参数并逐采样比较完整音频。
- 只在已批准且能完整保存差异的曲目上替换托管目录项。现有文件和元数据变化后，重新生成预览。
- 保留现有库级精确迁移及书库接口。批量审核使用同一入口，也支持在已为硬链接模式的曲库中复查独立文件。

## 方案

- 已注册来源选择文件，预览返回字节相同、音频等价、仅绑定或保留独立。应用时校验预览对应的源文件、托管文件和资料版本。复用按文件验证的迁移任务保存批量确认状态。
- 文件内文本与库内有效资料按现有覆写优先级合并。将可完整表示的差异自动保存，保留不适合自动转存的副本。字节改变时同步更新扫描观测、文件 SHA-256、来源映射及便携侧车引用。
- 原地任务逐曲保存阶段状态，复用已校验的文件身份，并在同一专辑的选中曲目提交后刷新侧车。单曲状态单独落库，完成的条目只保留恢复或统计所需字段。
- FLAC 音频一致时允许标准 ReplayGain 标签变化。受支持的单段内嵌歌词通过文本校验后按歌词版本确认转存。已有应用歌词优先，无法完整保留时保留独立副本。
- 单曲在文件信息中处理。管理页从现有存储迁移表单预览汇总，允许按曲排除或展开差异。

## 界面

1. 曲库所有者在桌面或手机上为现有歌曲找回正确来源。
2. 单曲优先选来源再预览。批量先看结果数量与可处理曲目，再确认应用。
3. 复用文件信息对话框、来源目录和存储管理。逐项审核留在结果区。
4. 来源、结果和应用顺序保持清晰，列表可以展开当前曲目的差异。
5. 复用现有表单字体、表面、强调色和焦点样式。选择与诊断依靠文字和控件。
6. 沿用现有对话框动效，覆盖初始、加载、无可用来源、过期、失败和完成状态。

## 验收

- 后端覆盖绑定、同字节重链、FLAC 等价、音频变化、资料及侧车恢复、过期预览、批量跳过和失败重试。
- Web 按 L1 检查两条路径，使用隔离曲库走通预览和应用，查看桌面及 390px 窄屏的浅、深主题。

定向回归覆盖音乐重绑、导入、歌词侧车、书库及目录迁移，并在 Linux 禁用 `/proc/self/fd` 快速路径后验证通过目录描述符发布链接。macOS 与 Windows 实机未覆盖。

原地重链用例验证每首独立副本的全文件哈希读取为源和托管副本各一次，正常任务每专辑只刷新一次侧车。恢复用例覆盖文件发布后未落库、专辑部分提交和旧任务状态迁移。歌词用例覆盖预览差异、应用覆写优先、确认前和排队后的并发编辑、无效歌词与新摘要下的侧车导出。
