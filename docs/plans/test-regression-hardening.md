# 测试与路径边界防回归

## 方案

- Playwright 路由拦截用例统一使用共享夹具清理页面路由。明确需要等延迟请求完成的用例继续自行等待。
- 核对 Web 组件和实际覆盖用例，补齐受影响测试映射及播客数据集配置。收音机音效用例等待音频进入播放状态。
- 书库和音乐库复用绝对路径规范化、登记来源匹配和目录设备号读取逻辑，维持原有路径边界。
- Android APK 与 Kotlin CodeQL 构建共用 Maven 429 有限重试脚本。

## 验收

- 按 L0 执行 `make check`，并运行受影响后端与桌面 Web 回归。
- 用边界用例检查目录别名和循环符号链接。对比 CodeQL 路径告警，验证重构未引入新的告警。
- 检查重试脚本的语法、限流恢复、重试耗尽和普通失败退出码。
