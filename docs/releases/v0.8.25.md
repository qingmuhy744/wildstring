# WildString / 野弦 0.8.25

本版缩短在线歌词查询的请求链，并让不同来源同时工作。插件升级至 API v2。

## 已实现

- 歌词查询优先用搜索结果识别录音版本。字段不足或版本有歧义时批量补查详情。热缓存可直接返回，元数据建议继续补齐发行信息。
- 手动查询可同时访问 QQ 音乐、网易云音乐和酷狗。批扫允许不同来源处理不同歌曲。同一来源仍串行限速，收到 HTTP 429 后按冷却时间恢复。批扫达标即停。
- Android 移除已退役的插件和候选管理面板。单曲在线歌词查询、预览和应用仍在歌词编辑页提供。

## 版本与升级

- 后端、Web、Android、macOS 和 iOS 均为 `0.8.25`。Android versionCode 为 `61`，Apple 构建号为 `60`。数据库 schema 为 `55`。
- **升级后首次启动会清理旧 v1 插件包、插件配置和专用 Cookie。** 从 Release 下载所需的 2.0.0 ZIP，在 Web 管理中心重新导入、配置并启用。曲库、已应用歌词、任务历史和其他服务凭据保留。[插件安装与升级](../architecture/source-plugins.md)
- v2 插件包分别为 `wildstring-qqmusic-2.0.0.zip`、`wildstring-netease-2.0.0.zip` 和 `wildstring-kugou-2.0.0.zip`。

## 验证

- 插件回归使用合成曲库和本地模拟上游验证批量详情、来源冷却、旧插件清理和同曲目手动任务。真实后端浏览器回归覆盖批扫持锁 10 秒时发起手动查询。PR 的后端、容器、Web 分片与 Android APK 检查通过。[插件优化 PR](https://github.com/qingmuhy744/wildstring/pull/185)
- QQ v2 对《稻香》的单次实查返回 48 行逐字歌词。全新 SDK 状态下共 4 次外部请求，含会话初始化。
- 正式包的构建、签名安装冒烟和发布渠道状态见 GitHub Release 工作流。
