WildString / 野弦 0.2.1 发布说明

后端、Web 与 Android 版本统一为 0.2.1，Android versionCode 升为 4。正式包名沿用 `com.wildstring.app`，使用既有固定发布签名，可覆盖升级 0.2.0 正式版。

- Android 手机采用「发现 / 音乐 / 我的」底部导航，平板采用侧边导航；发现页提供搜索、横向专辑与真实最近收听，曲库使用专辑 / 歌曲 / 艺人标签。
- 设置改为独立页面：固定返回栏，按账号、播放、外观与触感、缓存、关于分组。单一滚动容器关闭边界拉伸，处理轻下拉时的抖动；保留经典日夜模式、红布彩蛋、图标、音质与缓存选项。
- 圆形封面悬浮播放条叠加封面取色和模糊氛围，独立控制播放与队列，在设置中也可使用。展开播放器后返回保留原页面位置、队列和播放状态。
- 关键播放、收藏、队列及手动定位操作增加适度轻触反馈，队列拖动区分开始与有效落位；取消、普通浏览和自动更新不额外震动。合并密集触发，开关即时生效，遵循系统触感设置。
- 后端及 Web 本轮同步版本号，继续提供 0.2.0 的 AAC、歌词编辑和多用户功能。

本批本地验证：Android 20 项 JVM 测试、9 项 Android 15 ARM64 模拟器回归、Debug / Release Lint 与 R8 构建通过；播放交互检查无新增重缓冲或 AudioTrack underrun。发布流水线对同一标签重新运行完整 CI、Android 设备回归、固定签名校验，以及正式 R8 APK 安装和启动检查；报告与结果见对应 Actions。

下载 `wildstring-0.2.1-release.apk` 可直接安装，无需解压。Web ZIP 配合后端使用；容器镜像提供 linux/amd64 与 linux/arm64。部署前备份 SQLite 与配置，保留数据卷和托管曲库。

完整离线下载、Android 管理员歌词打点和用户管理继续按后续范围交付。真机后台、蓝牙、功耗和震动手感仍待设备回测。
