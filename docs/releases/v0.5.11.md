# WildString / 野弦 0.5.11

本版集中改善 Android 曲库页面，解决曲数挤压换行，并整理排序、更多操作与刷新方式。

- 播放全部、曲数和排序按实际文字宽度与字体大小自适应；空间足够时单行，窄屏或大字体时分行，曲数保持横向显示。
- 升序、降序收进排序菜单，标记当前方向；重复选择当前方向不会反向切换。
- 首页更多菜单提供播放队列、最近听过、离线音乐；歌曲列表和专辑／歌单详情只保留列表旁的操作菜单，按页面提供批量操作及歌单管理。
- 管理员的专辑元数据更新、歌词补全入口移至列表操作菜单，保留原有权限和确认流程。
- 刷新改用下拉手势与弦线反馈，同时提供“刷新当前页面”无障碍操作；发现页可从快捷卡片区域开始下拉。

数据库保持 schema23，无迁移。Web 和服务端业务行为不变，版本号统一为 0.5.11；更新 home 时只备份 API 配置、数据库、运行资料和回滚镜像，音乐库与导入源不纳入备份。

## 验证

本地 17 项 Android 模拟器场景、60 项单元测试，以及 Debug／Release 构建与 Lint 已通过，覆盖窄屏／大字体曲数、排序方向、菜单导航、下拉刷新、连续浏览与播放队列。正式发布还需主分支完整流水线、签名 APK 安装检查及多架构镜像构建通过；发布产物和 home 更新分别核验。界面规则见 [曲库排序与多碟专辑](../product/catalog-sorting-and-discs.md)。
