# 野弦 0.4.0

本版加入可由 Codex 使用的 MCP、内置音乐助手、草案与巡检、通知及日志诊断，同时整合歌单离线、跨设备接续和播放器改进。

## 助手、工具和草案

- Web 与 Android 提供多轮助手、本地找歌、模型连接选择、真实曲目候选和草案入口。默认本地模式，不自动选择付费连接；模型不可用不影响播放。
- 管理员可共享实例 AI，用户可配置个人连接；密钥只保存在服务端。已有实例配置保留原共享语义；发现、每日推荐、库外 AI 筛选与助手共用连接权限和调用额度，个人偏好及推荐批次按账号隔离。
- MCP 使用官方 Python SDK 的 stdio 桥接和独立、可撤销的 scope 凭据。提供歌曲／专辑／艺人查询、个人资料、缺项检查、受控来源查询、草案和任务、通知及管理员诊断工具。
- 修改先展示真实对象、差异、证据和版本。站内批准后才应用；草案变化使旧批准失效。重复应用使用幂等键，修改、审计和通知同事务提交。共享元数据仍需管理员。
- 巡检支持手动、定时、取消、恢复、预算和连接授权检查，先报告可验证缺项；显式选择 AI 才调用模型。取消后不启动后续模型或工具调用，保留已完成结果。

## 推荐与发现新音乐

- 每日推荐结合个人收藏／收听／反馈、本服用户热度、尚未听过与久未重听的本地歌曲，按账号稳定保存并允许换批。共享 API 不共享个人推荐结果。
- Web 与 Android 可查看个人或本服汇总排行，选择近 7／30／90 天或累计、播放次数或收听时长。近期使用实际服务端收听记录，汇总不暴露其他账号的记录。
- 可选 Last.fm 公共热门、标签榜、艺人作品和歌曲相似关系。外部事实先形成候选，再按有限偏好与来源混合；AI 只筛选真实候选，不能编造歌曲、专辑、听感或链接。
- 独立的“发现新音乐”提供库外清单、来源与理由，支持复制查询文字、查看来源、想听和忽略，供用户手动下载收藏；它不表示刚发行，也不提供自动下载或资源抓取。
- 库外清单默认关闭，启用后默认七天有效，可选其他频率或仅手动；到期后下次访问更新。公开资料有查询预算、缓存与超时，来源失败保留旧结果并标降级。想听跨批保留，导入后重新匹配本地可播曲目。

## 通知与诊断

- 默认站内通知由网页和手机在登录、回前台、恢复联网或手动刷新时补拉；支持未读、分页、跨设备已读和快照范围内全部已读。退出期间的结果留在服务端，不依赖系统推送。
- 导入／扫描及显式元数据查询批次的共享结果向管理员汇总通知；元数据建议仍待确认，不把查询完成称为修复完成。
- Telegram 为可选外部渠道，需显式配置并验证目标，支持事件订阅、静默时段、独立投递状态和有界重试。未知投递结果需明确确认后重试；不会因外部通知失败改变任务结果。
- AI 连接测试、实际选歌、助手、资料来源和 Telegram 复用外部传输与代理策略。来源检测区分 API、凭据和图片下载／解码，保留未配置与未验证状态。
- Web 与 MCP 可检索脱敏日志、按诊断编号查询请求／任务及批次事件，导出有界诊断包。日志容量、轮转、短效 DEBUG、丢弃计数和写盘降级独立于播放及业务事务。

## 离线、接续和播放器

- 歌单可选择自动下载，下载默认音质与网络策略由用户设置；原音或 AAC 128／192／256／320 kbps 与在线播放独立，有损原音不升码率。自动检查需要客户端处于可执行状态，完全退出后不承诺发现新曲。
- 手机长按、网页右击歌单提供编辑、删除和自动下载等操作。Android 使用野弦波纹下拉刷新，动画随实际请求结束。
- 跨设备接续提供关闭、弹窗询问（默认）、自动恢复三种模式；暂停时保存，恢复时保持暂停。本机播放期间不被后台记录抢走队列，不远程控制另一台设备。
- 元数据任务完成后自动进入历史，待确认建议与需要处理的问题保留；支持查看、重试和清理历史。
- 网页全屏播放器统一收藏与音质控件、扩大播放模式图标及点击范围；歌词只通过开关切换，取消空白点击切换，减少误触。
- Android 补齐标准媒体元数据时长及有限 AAC 时间线，增加真实系统媒体会话回归；设置和播放菜单可复制脱敏播放诊断，无需 USB 或通知读取权限。

## 升级与验证

三端版本为 0.4.0，Android versionCode 为 12，沿用既有正式签名。服务端需要从 schema 15 经 16／17 升级至 18；新功能需要新版服务端，旧客户端的播放、收藏及旧接口继续保留。新客户端连接旧服务端时明确提示新增功能不可用。

升级前备份数据库、已有私有配置及新的 `agent-secrets/`；先在副本演练，停止服务时保留持久卷。降级旧镜像需要恢复相应数据库备份。发布与 home 部署分别执行，远程升级需要明确授权；均不自动导入、扫描、移动音乐或写回标签。

专项验证包括真实多账号与共享额度、失效连接本地降级、来源混合、想听跨批与缓存更新；官方 MCP SDK 的真实 stdio 查询／草案批准／幂等应用／通知／撤销流程，以及真实 Codex CLI 查询均已通过。迁移包含真实旧结构、故障回滚和重放；代理使用真实本机 HTTP 夹具。MusicBrainz 公共查询、CAA 图片下载／解码、Last.fm 公共热门及许嵩作品查询已真实连通，未查询私人收听历史或调用付费模型。

Android 55 项单元与 Android 15 模拟器 54 项设备测试全部通过，Debug／Release Lint 与 R8 构建通过；固定签名 APK 已实际安装并打开连接页，包名、0.4.0／versionCode 12、ZIP 和与 0.3.4 相同的签名已核对。Web 新增推荐集成 20 项、手机／桌面排行布局 4 项通过，另有真实后端与明暗主题截图核对。元数据编辑保存按钮固定在键盘上方，并保留实际保存请求断言。

完整后端、浏览器、真实 AAC、容器和正式签名包的标签检查由 Release 工作流强制执行，全部成功后才发布 APK、Web ZIP 和镜像；下载校验与远程升级分别验证。
边界：

- 规则巡检报告缺失信息；来源候选需显式查询并有依据地生成草案，不凭空推断专辑、听感或歌词。无人值守应用、标签写回与文件移动继续后置。
- 内置 AI 首版采用 Chat Completions 有界工具循环，未引入 Pydantic AI、SIWC 或 ChatGPT 订阅授权。
- 新模型连接和 Telegram 的功能验收使用可控 HTTP 夹具，不代表用户自选供应商或私人 Bot 已真实联调。
- 标准系统媒体会话通过不等于已验证 ColorOS 流体云的视觉表现；ColorOS 16 真机仍需结合新增播放诊断核对。
- 发布产物为签名 APK、Web ZIP、SHA-256 校验、公开签名指纹和 amd64／arm64 GHCR 镜像。实际发布与服务器部署分别记录。
