# 野弦 0.3.4

本版修复 Android 中文搜索输入，改进字母定位与桌面图标。

## Android

- 搜索框独立于结果页保存输入、光标与中文组合状态；拼音候选尚未确认时不发起搜索，选字后沿用 300 ms 防抖。清空搜索、发现页与结果页切换时保持输入框和焦点，键盘搜索键可提交当前输入。
- 字母栏从松手后定位改为拖动时实时定位。大字母气泡跟随手指，松手或取消后消失；列表正常滚动时同步高亮所在分组。输入法展开时暂时收起字母栏，避免字母挤压裁切，关闭输入法后恢复。
- 进入新的有效字母时产生轻触反馈，同一分组不重复触发，空分组保持灰显且不跳转、不震动。反馈沿用「轻触反馈」开关及系统设置，并复用现有节流保护。
- 经典桌面图标采用已确认的 B 方案：图形居中、缩小并增加留白，保留珊瑚橙与深色底。自适应图标使用透明前景，应用内经典标识同步调整位置与比例。

## 升级与验证

Android versionCode 递增到 11，正式签名沿用既有证书，可覆盖安装 0.3.3。可在 App 设置中检查 GitHub Release 更新，或下载本页的签名 APK 确认安装。

字母索引仍依赖服务端 0.3.3 新增的接口；服务端已是 0.3.3 时，本次 Android 修复无需再升级服务器。后端、Web 的对外版本同步为 0.3.4，未改变数据格式与接口，数据库仍为 schema 15。

字母栏定位当前曲库中已有的歌曲，不会下载或补入库外音乐；本版不自动导入、修改音乐文件或写回标签。

验证要求包括 Android Debug／Release Lint、构建和 JVM 测试，以及组合输入、光标插入、清空、发现／搜索结果切换、字母实时定位和触感去重的设备回归。正式发布流水线另执行后端／Web／容器回归，以及签名 APK 的安装与启动检查；实际通过状态以对应工作流和本页发布产物为准。模拟器不能代替国产输入法真机测试和震动手感核对。

正式产物包括签名 APK、Web ZIP、SHA-256 校验文件、公开签名指纹，以及 `linux/amd64`／`linux/arm64` GHCR 镜像。不自动升级远程服务器。
