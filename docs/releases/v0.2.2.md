# 野弦 0.2.2

收藏先响应，保存异步完成；曲库新增多创作人、联网资料建议与 Last.fm 同步。

- Web / Android 收藏即时反馈、保存状态与失败恢复，防止同曲重复提交和旧账号回复污染新状态。网页普通歌单排序与移除先反馈，失败恢复。
- 读取 Mp3tag / Picard 风格的多值标签和创作角色，网页可编辑及按角色查找；曲目 ID、个人收藏、歌单和人工编辑保留。现有曲库需完整重扫才能读取新增文件字段。
- MusicBrainz、Last.fm 曲目资料及 CAA 封面候选先生成建议，管理员确认字段后应用；新导入自动排队、旧库手动批量查询。来源和版本保留，不自动写音频标签或移动文件。
- 独立歌曲封面优先，缺失时继承专辑。CAA 封面确认后持久保存。
- 每用户连接 Last.fm，独立选择已听记录和正在播放；符合实际收听阈值才同步，后台持久队列重试。Web 账号设置、Android 设置均可连接与解绑。
- 服务端联网代理可在网页选择跟随环境、手动指定或直连；Docker 注入 HTTP_PROXY / HTTPS_PROXY / ALL_PROXY / NO_PROXY。支持 HTTP 代理访问 HTTPS，凭据不会返回客户端。

MusicBrainz 与 CAA 已使用隔离数据库真实查询《山水之间》。Last.fm 尚无真实应用密钥和测试账号，授权、拒绝、忽略响应及同步队列目前通过模拟验证；不将此等同于真实账号联调完成。中文词曲编覆盖取决于来源实际数据。

正式发布由 Actions 再执行后端、Web、容器、Android 单元/设备回归和固定签名 APK 安装检查；全部通过才上传 APK、Web ZIP、校验和及双架构 GHCR 镜像。真机后台、功耗、触感和 Last.fm 真实授权仍需实际设备/账号核对。

0.2.2 客户端与服务端请一并升级：新客户端新增 `started_at` / `state` 收听字段，0.2.1 服务端会拒绝此类上报；0.2.2 服务端仍接受旧客户端的基础累计上报。

本次数据库升级到 schema 12。升级前保留持久卷备份；旧版程序不能直接打开升级后的数据库。联网默认关闭，Last.fm 连接后同步开关也默认关闭。SOCKS、标签写回、自动重排已有文件、稳定专辑实体及历史回滚界面后续推进。

代理与 API 的操作说明见仓库 `docs/architecture/metadata-providers-and-lastfm.md` 和 `contracts/metadata-providers.md`。
