# 0.5.4

本版处理依赖安全告警，并补齐助手回答排版和逐步输出。数据库继续使用 schema21。

- Android 工具链升级至 Gradle 9.5.0、AGP 9.3.3、Kotlin 2.4.21、KSP 2.3.12、Hilt 2.60.1，迁移至 AGP 内置 Kotlin。Compose、Media3、Room 和协程同步升级；编译 SDK 升至 37，最低系统 26、目标系统 36。
- 为构建和测试工具的 Netty、Bouncy Castle、Protobuf、Commons Compress、jose4j、JDOM、OpenTelemetry 和 Tink 传递依赖固定经过验证的安全版本，覆盖构建类路径和内部测试平台配置。更新锁文件、官方分发校验和及构件 SHA-256。
- 酷狗、网易云插件改用可复现的最小元数据工作区，保留上游提交、归档哈希、文件校验及 MIT 许可证。RSA 公钥加密使用 Node/OpenSSL；移除 Forge、PAC/FTP 和无关服务器依赖。平台适配继续属于插件自身。三个参考插件版本均为 1.1.1。
- 修复插件门控子进程耗时变化导致实际请求起点略早的问题；实际发送前再次使用单调时钟确认间隔，继续遵守共享来源额度和串行限制。
- Python 运行及开发依赖更新补丁版本，uv 升至 0.13.1，CI 和发布 Action 更新固定提交。`make ci` 增加两处完整 npm 锁文件审计。
- Android／Web 助手支持标题、段落、粗体、列表、代码、引用、表格和可点击网页链接；不执行回答中的 HTML，不自动加载外部图片。
- 聊天采用供应商真实流式正文，并将预览限频保存；两端约每 650ms 同步生成中的回答和检索／工具／生成状态，重新进入对话可读取已保存的部分。检索和思考阶段尚无正文时显示状态，不模拟文字生成。
- 支持 Chat Completions 与 Responses；保留工具参数、供应商续接状态、终止原因、来源和使用量。连接设置可关闭逐步输出，兼容不支持流式的服务。流式错误不自动重发模型请求，失败时保留已取得的正文并标明未完成。
- Android 自动响度模式改为选择后立即保存，并显示结果；首次加载时禁用选择，响度分析刷新及手动调整不会覆盖正在编辑的均衡设置。前级与防削波仍显式保存。

协议依据：[OpenAI 流式响应](https://developers.openai.com/api/docs/guides/streaming-responses)、[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。历史草案、权限、确认应用和模型调用预算沿用原有约束。

源码实现、测试、GitHub 告警复扫、Release 下载校验和备份后的 home 部署分别验收；以实际检查结果为准。
