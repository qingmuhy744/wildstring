# WildString / 野弦 0.6.2

本版重点优化了 Android 原生端与 Web 端的交互跟手度与视觉细节，提升了播放页、歌词展示及曲库浏览的流畅度，并修复了 Android CI 打包校验流程。服务端、Web、Android 与 iOS 统一升级至 0.6.2。

## 主要变化

- **Android 播放与歌词体验优化**：
  - 短歌词（单双行提示词或纯音乐标注，如“纯音乐，请欣赏”）自动垂直居中展示，避免置顶偏斜。
  - 全屏播放页支持平滑下滑连续跟手收起，降低手势触发阈值并消除状态栏接缝闪烁。
  - 播放队列支持连续上滑跟手展开与收起，消除底栏弹窗重复升起的断层感。
  - 优化封面与歌词切换交互，移除多余水波纹动效与延迟。
- **曲库与导航细节打磨**：
  - 艺人列表默认以「专辑艺人」维度进行浏览与聚合，并将对应角色筛选标签置顶（单曲点击具体艺人仍可精确直达歌曲艺人）。
  - 设置页面滚动状态持久化保存，收起播放器返回设置页时保留精确浏览进度。
  - 歌曲操作底栏移除「播放诊断」低频操作，保持列表操作整洁（诊断入口收敛至设置页）。
- **Web 界面视觉对齐**：
  - 曲库艺人分类角色下拉选择框将「专辑艺人」置顶并设为默认选项。
  - 元数据核对界面中的操作按钮、下拉选择框与复选框进行垂直对齐优化，统一视觉基线。
- **CI 与工程稳定性**：
  - 修复 `scripts/package_android.py` 对 Debug 包后缀（`applicationIdSuffix = ".dev"`）的校验逻辑，使 Android CI 流程稳定通过。
  - 放宽 Android 模拟器低配虚拟环境下的歌词手势等待超时阈值，消除偶发超时断言失败。
- **版本对齐**：
  - 后端、Web、Android 与 iOS 版本统一提升为 0.6.2，Android versionCode 升级为 32。

## 升级说明

- 无数据库迁移（保持 schema 31），向后兼容。
- home 升级将更新 Web、API 镜像与 Android 安装包。
