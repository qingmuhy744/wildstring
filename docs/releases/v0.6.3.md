# WildString / 野弦 0.6.3

本版重点优化了歌词核对与试听流程、播放页视觉排版、音质偏好切换与有损音源直通机制，并落地了元数据候选中心的失效数据清理能力。服务端、Web、Android 与 iOS 统一升级至 0.6.3。

## 主要变化

- **歌词核对与编辑体验优化**：
  - 网页版歌词全屏播放页采用现代流媒体高级并列排版（`歌手 · 专辑`），移除冗余唱片图标与箭头，同时保留歌手与专辑的独立导航点击能力。
  - 修复桌面 Web 端歌词点击交互：键鼠模式下点击歌词行直接执行精确音频进度跳转（Seek），不与触控单手模式的“切换封面”混淆；移除背景留白误退出全屏的捕获逻辑。
  - 去除歌词编辑顶部容易误触清空逐字候选的常驻保存按钮；放宽服务端的版本冲突检查，使历史查询出的候选可以随时试听与重新应用；明确展示当前生效版本状态。
  - 联网歌词查询增加异步流光进度条，明确反馈多源抓取状态。
- **音质偏好与有损直通（Lossy Passthrough）交互打磨**：
  - Android 播放页音质 Badge 支持点击交互，弹出 Material 3 单选面板快速切换期望目标音质（原音、AAC 128k/192k/256k/320k）。
  - 清晰呈现「有损直通」机制：当源音频已是有损格式（MP3/AAC）时，系统自动直出原音并附带明确说明，防止用户因“设置了 AAC 但看到原音直放”产生困惑。
  - Web 端同步在音质控制栏增加有损源直通反馈标签（`MP3直通` / `有损直通`），并在底栏对齐状态提示。
- **元数据候选中心（P0 减负落地）**：
  - 后端新增 `/api/v1/agent/metadata-review/stale/purge` 接口，一键清理歌曲元数据版本已变更或查询依据失效的废弃候选。
  - Web 与 Android 端元数据核对界面均增加「清理失效候选」操作入口，有效消除千条失效待办积压。
- **CI 与构建环境健壮性**：
  - 优化 GitHub Actions 缓存 key 避免跨版本偶发命中旧锁文件；在 Android 打包流程中更健壮地处理 NDK 缺失与环境变量降级。
  - 修复 Web 底部控制栏中重复浮动的播放状态文字对齐问题。
- **版本对齐**：
  - 后端、Web、Android 与 iOS 版本统一提升为 0.6.3，Android versionCode 升级为 33。
