WildString / 野弦 0.2.0 发布说明

后端、Web 与 Android versionName 统一为 0.2.0，Android versionCode 3。正式 Android 包名沿用 `com.wildstring.app`，使用既有固定发布签名，可覆盖升级 0.1.0 正式版。

- 服务端 / Web：AAC 播放决策与缓存、无损转码和偏移跳转；歌词覆盖编辑、逐行打点及 LRC 导出；多用户与个人数据隔离、改密、管理员账号与 Host 访问设置；网页日夜外观。
- Android：原音及 AAC 128 / 192 / 256 / 320 kbps 偏好和实际输出标识、整曲进度及跳转；账号角色与改密、人工歌词刷新；本机私有缓存与短时断网片段重播、自然过渡、轻触反馈、封面毛玻璃、经典日夜外观和红布彩蛋；手机和平板三横杠拖动队列。

验证：后端及容器内各 144 项测试，Web 常规 54 项与 FFmpeg 专项 4 项，Android 17 项 JVM 测试、Debug / Release Lint 和 R8 构建通过；ARM64 本地与 x86_64 云端模拟器各通过 5 项设备回归。正式发布流水线另行核验签名并安装、启动 R8 正式 APK；完整产物及结果见本次 Release 和对应 Actions。

下载 `wildstring-0.2.0-release.apk` 可直接安装，无需解压。Web ZIP 需要配合后端运行；容器镜像提供 linux/amd64 和 linux/arm64。部署前备份 SQLite 与配置，保留数据卷和托管曲库；新账号、人工歌词及 AAC 接口需要更新服务端。

完整离线下载、Android 管理员打点与用户管理尚未交付。真机后台、蓝牙、功耗与震动手感仍需回测。
