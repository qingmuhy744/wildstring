WildString / 野弦 0.1.0 是首个同时提供自托管服务、React Web 和 Android 原生客户端的版本。

## 本版内容

- Python 后端与 React 曲库：管理员登录，歌曲、专辑、艺人、搜索、本地封面与歌词，原音串流、收藏、歌单与收听记录。
- 只读源导入到托管曲库，持久扫描和任务记录，单曲元数据数据库覆盖；默认关闭的定期发现、稳定期观察、预检与待整理流程。
- WAV 16/24 位整数 PCM 及单镜像 WAV/FLAC CUE 转逐曲 FLAC，发布前核对完整 PCM。
- Kotlin / Compose / Media3 Android：连接自托管服务、后台媒体播放、系统控制、队列、循环/随机、收藏与基础歌单操作。
- 手机点开全屏逐行歌词；平板双栏播放与歌词，兼容窄分屏。曲库、歌词与封面均来自实际服务，APK 不包含演示曲目。

## 安装

Android 8.0 起，直接下载 `wildstring-0.1.0-release.apk`。显示名称「野弦」，包名 `com.wildstring.app`，版本 0.1.0（versionCode 2）。正式包使用固定签名；发布附件包含公开证书 SHA-256 指纹与文件校验和。

此前 `dev.wildstring.app.debug` 测试版与正式包并存，无法直接覆盖；首次安装正式版需要重新输入服务端地址并登录。服务端曲库、歌单与收藏保留。

服务端使用下方容器镜像或源码部署，配置持久数据卷、只读导入源，并设置管理员。Android 正式版要求可达且证书受系统信任的 HTTPS 地址。Web ZIP 需要后端配合使用，容器已内置 Web。

## 验证与当前边界

发布流程要求 Python/Web 检查与测试、容器检查、Android Lint/JVM 测试、模拟器登录/认证音频播放/歌词与平板布局，以及实际安装 R8 正式包并检查连接页全部成功，才创建 Release。测试接口及音频夹具只用于独立测试包。

AI 模型连接配置已提供，自然语言找歌与 AI 歌单业务尚未交付。离线下载、Android Auto、完整 Android 歌单编辑/排序、全格式转码、复杂多镜像 CUE/DSD、外部自动匹配、已有文件自动写回和跨设备同步留待后续版本。真机后台与厂商省电兼容、真实服务端部署和所有编码覆盖仍需进一步验收。
