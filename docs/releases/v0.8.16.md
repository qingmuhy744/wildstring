# WildString / 野弦 0.8.16

本版是面向 0.8.15 的小版本，集中修复 Android 连接流程的键盘遮挡，补充逐条服务器线路测试，并按 DESIGN.md 收敛 Android 视觉与交互细节。正式版发布可同步更新个人 Homebrew Tap。

本版不修改服务端 API 或数据库；schema 仍为 52。**0.8.12 及更早的客户端依然无法正确对接 0.8.13 及更新的服务器**（`/podcasts/inbox` 已在 0.8.13 移除），须使用 0.8.13 或更新的客户端。

## 相对 0.8.15

### Android 连接与线路管理
- 连接页底部协议提示不再横向溢出；键盘弹出时连接页和「服务器线路」对话框可滚动到底部，账号／密码、保存按钮和协议提示仍可见。
- 已保存的每条线路可单独发起只读连通性测试，行内显示延迟、可达状态或会话失效提示；测试不改变当前选线、配置或会话。
### Android 设计对齐
- 发现页「每日推荐」入口恢复中性样式，并添加 sage 色「AI 整理」徽章。
- 修正设计令牌映射、播放中行状态色、强调文字、详情页主要／次要操作层级、播客剧集状态和加载骨架；触控目标及时间／计数排版同步收敛到项目规范。
- Android 音乐与播客播放队列删除只在手指松开并完成滑动后提交；撤销按原队列索引恢复，并在队列更新尚未显示时也能重置已滑动行的偏移。
- 「我的」页在 Pad 宽度使用双栏布局。

### Homebrew Tap
- 稳定版 Release 在配置 `HOMEBREW_TAP_TOKEN` 时自动更新 `qingmuhy744/homebrew-tap` 的 `Casks/wildstring.rb`；预发布版跳过，未配置 token 时静默跳过。
- Cask postflight 会递归移除应用的 `com.apple.quarantine` 属性。此行为会绕过 Gatekeeper 下载隔离；Developer ID 签名与公证仍取决于 Apple secrets。安装者应仅在信任发布来源时使用此 Cask；不接受该取舍时，请从 GitHub Release 下载并按 macOS 提示验证应用。

## 验证
- Android `:app:lintDebug`：通过（修复分享菜单 chooser 标题的 Compose lint 后）。
- 使用隔离 Android API 35 模拟器验证队列滑动：按住、返回原位、松手删除、撤销及队列更新前快速撤销的 3 项定向测试通过。同一测试类的既有边缘自动滚动用例在本机一次运行超时，未将该类测试记为全通过。
- Pad 与 Phone 的主要 Android 页面已在浅色／深色模式做过视觉检查；完整发布模拟器回归仍须在合并后的 main 提交上手动运行 `Android APK` 并启用 `run_emulator`。
- PR 工作流与 Release 工作流状态将在合并和发版后补记；目前不将仍在运行或被取消的 CI 当作通过。
