# WildString / 野弦 0.6.1

本版优化了移动端连接策略与播放交互，并为账号与推荐系统补充了自托管场景下高频诉求的能力。服务端、Web、Android 与 iOS 统一升级至 0.6.1。

## 主要变化

- **自托管 HTTP 策略放行**：
  - Android 与 iOS 原生端解除强制 HTTPS 限制，采用“按服务器单点授权 + 强风险告警”策略。
  - 用户连接自托管 HTTP（局域网 NAS、FRP 穿透、Tailscale 等）时，客户端弹出未加密明文风险确认弹窗，确认后按服务器放行。
- **播放交互收敛与体验优化**：
  - 全屏播放页的封面与歌词切换优化为即时直接挂载，移除冗余淡入淡出动效。
  - 歌词行点击统一为切换面板，歌词进度定位改为滑动后显示中央时间指示线与显式确认跳转按钮，杜绝误触。
  - 修复多艺人名称拆分点击跳转。
- **账号个人资料管理**：
  - 支持用户在 Web 与 Android 端修改登录 ID（`username`）、显示昵称（`display_name`）与联系邮箱（`email`，暂不提供找回密码，仅作为资料存档）。
  - 数据库升级到 schema 31。
- **每日推荐定时生成**：
  - 推荐偏好设置新增“每日定时生成”开关与时间选择（格式如 `00:00`）。
  - 后台巡检任务按设定时间自动触发生成当天的每日推荐。
- **版本对齐**：
  - 后端、Web、Android 与 iOS 版本统一提升为 0.6.1，Android versionCode 升级为 31。

## 升级说明

- 数据库升级至 schema 31，自动在 `users` 表补充 `display_name` 与 `email` 字段，并在 `recommendation_preferences` 补充 `daily_enabled` 与 `daily_time` 字段。
- 邮箱仅作资料保存，不具备找回密码或接收验证码功能。
- 移动端连接明文 HTTP 时会记录单服务器的授权状态，更换服务器或新添加服务器仍需用户主动风险确认。
