# WildString / 野弦 0.8.17

本版是面向 0.8.16 的稳定与体验收敛版本，涵盖 macOS／iOS 播客跨设备续播与远程 Range 快速拖动、Android 播客节目页与 Pad 布局及播放器连续动画优化、四端节目页与黑胶视觉细节统一，以及后端并发、请求与存储安全性加固、已鉴权封面／头像条件缓存和曲目宿主机物理路径权限收口。

本版保留既有数据库结构；schema 仍为 52（升级仅追加投递表索引，无破坏性表结构变更）。**0.8.12 及更早的客户端依然无法正确对接 0.8.13 及更新的服务器**（`/podcasts/inbox` 已在 0.8.13 移除），须使用 0.8.13 或更新的客户端。

## 相对 0.8.16

### macOS 与 iOS 播客体验及播放
- macOS 底部播栏与全屏播放页的「播放队列」统一收敛为右下角悬浮面板，右侧检查栏仅保留音乐歌词；修复全屏切换电台节目时封面未居中的问题。
- 底部播栏、全屏页、电台迷你播放器与单集行在 `isBuffering` 状态显示明确缓冲加载态；电台订阅栏移除「我的订阅」旁的重复刷新转圈，并隔离订阅列表与节目详情的加载状态。
- 修复远程播客断点续播与拖动进度时因精确帧计时及首部预取导致的扫描卡顿，加快分片定位速度。
- 修复跨设备续播及自动连播下一集（含 iOS「继续收听」）时传入本地旧进度而覆盖服务端新进度的问题，并在起播拉取远端进度期间优先保留用户的手动拖动定位。

### Android 与跨端交互统合
- 播客节目详情将「继续收听／播放最新一集」与自适应宽度的「已关注 ⌄」（或「关注节目」）胶囊合并为单行，同时将「⋮」菜单移至详情顶栏右侧并改为锚定按钮自身，避免弹层漂移。
- 播客播放器在「封面」与「文章」视图切换时统一由同一 240ms 动画曲线驱动按钮显隐、间距与宽度变化，顶栏改为居中切换条配右置收藏与睡眠定时；新增覆盖位移、按钮位置与落位零二次跳动的逐帧动画回归测试。
- 统一 Android Pad 内容区双栏（760dp）与目录最大宽度（1180dp）规则，1100dp 起在播放页右侧常驻 360dp 待播面板；修复全屏播放器副标题横向滚动硬切、单集进度条挤压标题、发现页「每日推荐」AI 徽章截断与 Last.fm 读取失败误显「连接」等问题。
- Web、macOS、iOS 与 Android 播客节目详情页均移除全局「播放待播 (N)」，待播列表播放入口仅保留在电台首页与待播面板；Android 与 Web 黑胶播放器去掉中心黑点。

### 后端并发、性能与安全策略
- 修复转码流重复打开 SQLite 连接风暴，在无作用域只读拦截链上复用请求级只读连接，隔离后台写任务并补齐专辑与投递索引；巡检曲目改为批量查询。
- 加固请求边界、XML／ZIP 解析与代理 SSRF 校验，修复专辑发行锁拆分、多曲库回收站／扫描／上传、附属歌词重排、播客合并迁移及停机保留排队下载状态等边界问题；支持同一节目单集按节目级别切换降速下载（`slow_download`），下载队列分离 2 条快速通道与 1 条降速通道。
- 为曲目封面、播客封面、目录封面与用户头像 4 个已鉴权图片接口启用强内容哈希 `ETag`、`Cache-Control: private, no-cache`、`Vary: Cookie, Authorization, X-Wildstring-Library` 及 `If-None-Match` → `304 Not Modified`；REST JSON、音频流、歌词及候选封面预览仍保持 `private, no-store`。
- 补齐 `file-info` 返回的 `absolute_path` 字段，并将宿主机物理路径（`absolute_path`、`full_path`、`library_root`、`source_path`）严格收口为仅 `owner` 可见；非 `owner` 统一返回 `null`，Web「歌曲文件与属性」弹窗同步隐藏宿主机物理路径区块。
