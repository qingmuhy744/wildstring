# 0.5.3

歌词补全与洗版、双语显示和Android歌词跟随修复，数据库升级至schema21。

- Web／Android支持专辑及全库歌词补全与洗版，选择静态、逐行、逐字及双语目标，并可切换逐字／双语优先。
- 后台任务可暂停、继续、取消和仅重试失败，重启恢复；保留长期已扫记录，普通扫描复用，强制重扫重新请求。
- 低频／中频／高频／自定义频率，初始间隔10／5／2秒，后台默认低频。各档间隔及默认档位均可设置，单次自定义1–120秒。新版参考插件逐请求限速，旧插件调用级限速；单来源串行、429冷却和有限重试。
- 扫描只保存候选，支持预览、批量确认、锁定和恢复原歌词。版本变化或损失已有能力的候选不直接升级，音乐文件不改写。
- Android切行改为一次居中动画，保持高亮前后文字度量，避免两段动画及换行造成抖动。
- Android／Web补齐译文与音译显示及开关，默认译文开启、音译收起。服务端按时间配对，偏移作用于各语言时间轴；网页确认歌词后立即刷新播放器。
- QQ、酷狗、网易云参考ZIP更新为插件1.1.0，加入请求级门控并修复Node适配自定义代理的传递；平台适配仍由各插件维护。

使用方式、匹配边界及上游限速核对见[歌词补全与洗版](../product/lyric-scans.md)，双语及滚动验证见[歌词跟随与双语显示](../product/lyric-follow-and-languages.md)。

《Welcome to New York》只取公开歌词进行临时显示测试，未下载音频或加入home曲库，样本及调试包已清理；未进行真实录音同步听测。歌词候选仍需核对具体版本与同步效果。

APK、镜像、Release下载校验及备份后的home部署分别验证；不能以本地构建或CI状态代替运行验收。
