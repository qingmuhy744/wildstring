# WildString / 野弦 0.8.1

本版聚焦 0.8.0 发布后的关键安全加固、数据一致性维护、移动/平板端界面排版调优及 AI 对话体验增强。

## 核心修复与改进

### 1. 播客音频流代理与缓存安全加固 (防护同源 XSS)
- **Content-Type 校验与过滤**：在播客音频远程流式代理中增加 MIME 类型白名单，非 `audio/*`（防止上游或被劫持返回恶意 `text/html`）统一安全回退为 `application/octet-stream`。
- **安全响应头**：在远程音频流代理及本地缓存音频响应头中，补齐 `X-Content-Type-Options: nosniff` 与 `Content-Security-Policy: sandbox; default-src 'none'`，阻断浏览器将响应内容嗅探或解析为 HTML 执行恶意脚本。

### 2. 曲库收藏「我喜欢」歌单去重
- 修复历史跨库授权与迁移可能在数据库残留多条 `kind='favorites'`（❤️ 我喜欢）歌单的缺陷，在 `PlaylistStore.ensure_default()` 中自动合并重复记录，确保每个用户始终仅有一份全局「我喜欢」歌单。

### 3. 移动端与平板端界面及交互调优
- **网页移动端长标题布局修复**：为 `.track-title strong` 补充 `display: block; min-width: 0`，修复 412px 手机屏幕下超长歌曲标题撑宽页面、引发非预期横向滚动的视觉 Bug。
- **Android 播客详情页与返回路径**：
  - 从播客详情页进入出品方页面后，点击返回键（顶栏返回或系统手势返回）可精准回到对应播客详情页，不再丢失上下文退回节目列表。
  - 避免首次加载播客详情时误弹出波浪刷新动画遮挡标题。
  - 重构详情头部为三层平衡布局（封面+标题/作者/出品方+单集徽标；通栏水平操作栏；通栏圆角简介卡片）。
- **Android 平板全屏播放器比例调优**：
  - 平板宽屏模式下放宽封面与黑胶尺寸上限，调优黑胶唱臂角度，统一底栏 MiniPlayer 规范。
  - 整合「音乐跨设备接续」与「播客播放缓存」设置分组；平板端设置页大屏空白区域支持任意滑动，内层卡片严格居中并限制在 720dp 规范。
- **网页端播客详情对齐**：重构元信息卡片与底部操作按钮的视觉对齐，移除详情页顶栏多余的添加/刷新按钮。

### 4. AI 助手对话体验升级
- **首轮对话自动归纳标题**：根据首轮用户对话意图智能提炼并更新会话标题，取代默认的“新对话”；后续对话不再自动覆盖，支持用户手动随时修改。
- **单次对话调用步数上限可配置**：在网页端「助手设置 → 对话历史」中新增「单次对话最大调用轮数」偏好设置（`chat_max_calls`，范围 1–20 步，默认 4 步），满足深度多步调研与外部批量补标签场景。

### 5. 错误提示中文化与离线网络弹性
- 补充播客相关错误码的中文友好映射；定义继承自 `TypeError` 的 `NetworkError`，在网络超时或断网时提供中文指引，并保证前端离线静态壳与 `OfflinePanel` 能够无缝识别并自动唤醒。
