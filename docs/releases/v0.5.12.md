# WildString / 野弦 0.5.12

**状态：已合并 main、打标签、发布并部署到 home。**

本版完善 Web 与 Android 的元数据核对，补齐拒绝操作，并让多来源候选和 Web 滚动更清楚。

- 核对页新增“拒绝当前建议”，归档这份候选及其旧的相同记录；保留现有资料，其他候选和后续查询不受影响。拒绝无须勾选字段，失败可安全重试。
- 相同查询内容合并展示，保留最近记录及重复数量；不同来源、专辑、发行版本和封面分别保留，候选标注专辑、日期和匹配程度。
- 待核对专辑只统计适用于当前资料版本的建议，过期资料不再占据待处理数量。
- Web 核对弹窗固定标题和操作区，左右分别滚动，阻止背景页面跟着滑动；歌曲选择列表默认折叠，并压缩顶部工具占用。

- Web 数据源插件改为独立导入区和单层来源卡片，统一 ZIP 选取／拖放、文件大小校验、处理中反馈及失败重试；升级改为选包后明确确认，版本维护默认折叠，反馈留在对应插件内。
- Web 左栏在播放队列与管理／账号区域间增加细分隔线；浅色／深色保持一致。
- Web 桌面端统一参数、状态和图标帮助：悬停约 400 毫秒显示，支持键盘聚焦、Esc、弹窗与视口避让；手机不显示新增提示。覆盖及维护规则见 [桌面端就地帮助](../product/desktop-help.md)。
- 增加专辑级发行版本锁定（管理接口、MCP 与 Web 核对页），联网候选若跨越已锁定发行只保留为冲突预警，不会进入自动应用；巡检增加相近专辑拆分预警，自动整理与单候选应用共用这条校验链。
- 通知中的元数据和歌词扫描结果带有批次定位操作；Web 与 Android 都可从通知进入统一候选中心或对应扫描批次，候选中心支持按批次查看、筛选、历史和批量核对。

数据库升级到 schema25，通知事件保留结构化操作入口。候选历史保留，不删除音乐或改写音频标签。
