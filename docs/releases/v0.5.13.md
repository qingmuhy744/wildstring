# WildString / 野弦 0.5.13

本版将 iOS 原生客户端接入主线，并补齐播放界面与队列恢复体验。0.5.12 的元数据候选中心、发行版本锁定、通知批次定位和 Web／Android 核对改进继续保留。

- iOS 迷你播放器增加圆角封面、播放进度、缓冲状态、播放/下一首和展开入口。
- iOS 全屏播放页支持长按封面打开大图预览，播放队列入口显示当前队列数量。
- iOS 锁屏播放信息补充专辑和鉴权封面；切歌时取消旧的封面请求，避免封面错位或残留。
- iOS 队列持久化保存封面标记，已有旧队列按无封面安全迁移，不影响继续播放。
- 后端、Web、Android 与 iOS 版本统一为 0.5.13，Android versionCode 从 26 增至 27。

## 验证

- Swift 核心测试：44 项播放／缓存／队列测试、77 项网络与业务测试通过，集成测试按环境跳过。
- iOS 模拟器完整构建通过（XcodeGen + Xcode，iOS 17 目标）。
- PR #50 的 CI、iOS 构建、Android、容器、CodeQL 与依赖检查需在合并前全部通过。

正式 iOS 真机安装仍需要开发者签名、Ad Hoc、TestFlight 或 App Store 分发；未签名 IPA 不作为可安装 Release 资产，模拟器验证使用 `.app` 构建产物。
