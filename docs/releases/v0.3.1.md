# 野弦 0.3.1

本版改善联网资料更新的排查体验，并为 Android 增加多个服务端与 GitHub Release 更新入口。

## 联网资料

- 网页代理设置旁新增服务端网络检测，逐项检查 MusicBrainz、Last.fm、Cover Art Archive、AcoustID，显示耗时、代理路径及安全错误说明。可以先测试代理草稿，再决定是否保存；不会上传私人曲库。
- 元数据更新弹窗持续显示本批进度和逐曲结果，区分排队、查询、建议已生成、无新增资料及失败。关闭弹窗后任务继续；读取进度失败只重试查询，不重复提交。
- Last.fm 明确返回歌曲未收录时显示无匹配，不再当作网络失败；真正的参数错误和连接错误仍分别反馈。
- 修复 Last.fm 会话密钥被错误地限定为十六进制、导致有效授权可能被拒绝的问题。换取会话失败保留安全错误码，区分网络和 API 错误；Docker 启动方式也会对回调访问日志脱敏，失败页面与重定向使用禁止缓存和禁止引用来源的响应头。

## Android

- 保存多个服务端，独立保留登录状态和本地数据；切换停止当前播放，不把队列带到另一台服务端。旧单服务端配置自动迁移。
- 「切换服务器」与「退出登录」分开。退出仅注销当前服务端，其余保存的服务端继续保留。
- 从官方 GitHub Release 检查稳定版更新，设置中提供手动检查和仓库链接；下载后验证校验和、包名、版本与签名，再交给系统安装器确认安装。

## 升级说明

服务端数据库从 schema 14 升级到 15，新增持久化的元数据刷新批次。升级前备份 SQLite 数据库及私有设置；旧版本不能直接打开升级后的数据库。音乐文件和人工修改保留，导入源不变。

客户端功能使用现有服务端 API，多服务端不需要服务端合并账号。Android 正式 APK 使用既有签名，versionCode 为 8；调试包与正式包包名／签名不同，需安装正式版才能接受后续正式版覆盖更新。首次从 0.3.0 升级仍需手动安装本次 APK，之后可使用应用内检查更新。

网络连通不等于资料完整，也不代表 Last.fm 用户授权成功；实际来源覆盖和用户授权需要按配置核对。自动更新需要设备可访问 GitHub，安装由 Android 系统确认，不静默替换应用。

## 验证

测试与构建状态以本次 PR、发布工作流及交付记录为准。联网诊断使用合成响应；真实 Last.fm 账号已在自托管实例经用户全新授权验证成功，回调及绑定状态通过核对，未用模拟结果代替。收听投递与来源资料覆盖仍按实际使用核验。

接口与诊断边界见 [联网诊断与任务反馈](https://github.com/qingmuhy744/wildstring/blob/v0.3.1/docs/architecture/provider-network-diagnostics.md)。
