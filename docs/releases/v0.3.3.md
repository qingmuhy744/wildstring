# 野弦 0.3.3

本版改进 Android 与 Web 曲库浏览，连续向下加载歌曲，并提供字母定位和可选的列表大小。

## 曲库与列表

- Android 与 Web 的歌曲、专辑、艺人及歌单内容连续加载，去掉曲库翻页按钮。名称排序提供固定 `0–9 / A–Z / #` 索引；中文按拼音分组，空分组灰显，支持点击与拖动定位尚未加载的内容。统计排序时隐藏字母索引。
- 专辑默认保留碟号／曲号顺序，手工歌单保留自定义顺序；播放读取完整集合，不将当前已加载的几十首当成全部歌曲。加载失败保留现有内容并可重试。
- 专辑曲目用曲号代替重复封面，歌曲以歌名、艺人两行显示，统计信息按排序需要展示；排序与管理入口收进紧凑工具栏，底部播放器减少留白。
- Android「设置 → 外观与触感 → 歌曲列表大小」、Web「账号设置 → 歌曲列表大小」提供小、中（推荐）、大，默认中档。行高、封面与字号同步调整，偏好在本机保存，切换保持浏览位置、播放进度及队列。

## 返回与排序修复

- 播放页的所属专辑入口移到歌曲信息区；从播放页进入专辑后返回，恢复播放页及原有歌词／播放样式，不再意外跳回首页。
- 修复专辑／艺人歌曲统计排序参数未生效、最近播放切换名称排序仍按时间排列，以及歌名与专辑名不同造成字母定位与专辑列表不一致的问题。
- Web 字母索引跟随深浅色主题；列表大小可跨标签页同步，停留在专辑网格时也能接收其他标签页的修改。

## 升级与验证

数据库保持 schema 15，无新增迁移；现有歌曲、收藏、歌单和 Last.fm 配置继续使用。导入源保持只读，本版不移动音乐文件或写回标签。客户端与服务端建议一起更新，以使用拼音定位和新增的排序能力。

Android versionCode 递增到 10，正式包沿用既有发布签名，可覆盖 0.3.2。可在应用设置里检查 GitHub Release 更新，或从本页下载正式 APK 后确认安装。

本地已完成统一 CI、容器构建与启动检查、Android Debug／Release Lint 和构建，以及列表大小、连续浏览、专辑返回相关设备测试；详细记录见 [连续浏览与专辑布局](../product/library-browsing.md)。PR 与 Release 流水线继续执行完整后端／Web／容器回归、Android 模拟器功能测试及签名正式包安装检查。模拟器验证不代表所有真机、系统大字号或长时后台场景均已覆盖。

正式产物包括固定签名 APK、Web 构建包、SHA-256 校验文件，以及包含后端和网页的 `linux/amd64`／`linux/arm64` GHCR 镜像。发布完成以本页实际附件、镜像摘要及工作流结果为准；不自动升级远程服务器。
