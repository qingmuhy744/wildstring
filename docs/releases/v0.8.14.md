# WildString / 野弦 0.8.14

本版是面向 0.8.13 的小版本，合入 PR #113：Android 按节目保存的本机播客增益，以及 macOS 播放器与资料库界面打磨（含共用线路诊断和高级歌单创建）。

本版不增加新的服务端不兼容。数据库 schema 仍为 52。**0.8.12 及更早的客户端依然无法正确对接 0.8.13／0.8.14 服务器**（`/podcasts/inbox` 已在 0.8.13 移除），须使用 0.8.13 或更新的客户端。

## 相对 0.8.13

### Android 播客节目增益
- 播客播放器「更多 → 节目增益」提供本机手动补偿：默认 0 dB，允许 0～+12 dB，每档 1 dB，调整立即生效并保存，可还原为零。封面和文稿模式均可打开。
- 同一节目的单集共用设置，切换节目读取各自数值；切回音乐使用原有音乐响度设置，不请求音乐的播放增益接口。
- 设置保存在本机，按服务器、账号和节目 ID 隔离；不上传服务器、不跨设备同步。MediaItem 携带节目 ID，队列恢复时保留增益；缺少节目 ID 时使用 0 dB。
- 复用现有 PCM `GainAudioProcessor`，不改音频文件或系统音量。这是手动增益，不做播客响度扫描或动态压缩；过高增益可能削波失真，界面会提示降低增益。

### macOS 播放器与资料库打磨
- 播客待播改为单面板：自绘行（封面、日期／时长、收听标记、逐行播放与移除）、播放全部、骨架屏与空状态；左侧栏保留最多 3 集预览。
- 曲目列表改为符合 DESIGN.md §6.1 的卡片行（圆角、细边框、悬停／选中底）。
- 资料库搜索使用列表标题中的搜索框，底栏用通栏「加载更多」；工具栏去掉玻璃气泡，改为安静的图标或文字操作，并在 macOS 26+ 隐藏系统共享工具栏背景。
- 侧栏底部增加外观切换（跟随系统／浅色／深色）；唱臂在静止与落下之间使用弹簧过渡，并尊重减少动态效果。
- 若干主要操作按钮补上 `accentDeep` 着色，与房屋珊瑚色一致。

### 线路诊断与高级歌单
- macOS 与 iOS 共用的线路编辑器为每条线路增加听诊器按钮：在不改变当前选线、不触碰资料或回退循环的前提下，探测该线路是否可达及会话是否仍有效（已连接并显示耗时／可达但会话已过期／无法连接）。手动选线仍在「线路模式」中完成。
- macOS 艺人页在「专辑艺人」角色下点开艺人后进入该艺人的专辑网格，再进入专辑详情；其他角色仍打开曲目列表。
- 新建歌单改为表单：可选普通歌单或高级歌单。高级模式支持满足全部／任一条件、规则编辑（12 个字段及对应运算符、数值区间、日期天数、喜欢与否）、排序与 1～5000 条上限，校验通过后才可创建。保存走现有 `POST /api/v1/playlists`（`kind=smart` 与规则定义），由服务端筛选曲目，无需后端变更。iOS 仍可创建普通歌单；本版未提供高级歌单界面。

## 已知限制
- 0.8.12 及更早客户端仍不能对接本版服务器，须使用 0.8.13 或更新的客户端。
- Android 节目增益只保存在本机，不会同步到其他设备或账号。
- 过高的节目增益可能造成削波失真，需手动降低；不做自动响度对齐。
- Android 播客播放页「AI 导读」标签仍为即将推出占位。
