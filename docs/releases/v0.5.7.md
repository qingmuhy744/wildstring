# 0.5.7：MCP 整理与下载导入

本版从 main `f57fa2e` 的独立 worktree 开发，不包含主工作目录的 iOS 规划。以下记录本地验收结果，GitHub 检查见 [PR #49](https://github.com/qingmuhy744/wildstring/pull/49)，发布产物与 home 部署另行核验。

## MCP

保留原有 stdio 桥接，增加本站 `/mcp` Streamable HTTP。使用站内创建的受限 `ws_` Bearer 凭据；每次请求检查身份、权限、撤销和同源 Origin，不继承网页登录会话作为 MCP 授权。反向代理需转发 Authorization、Accept、Content-Type 和 MCP 协议头，不应移除 `/mcp` 路径。原生 HTTP 面向支持自定义 Bearer 头的客户端；本版没有新增 OAuth 授权发现或动态注册，依赖这些流程的客户端尚未适配。

工具从 20 个扩展到 48 个，Schema 包含枚举、边界、分页、版本、证据和分类型草案：

| 范围 | 能力与边界 |
| --- | --- |
| 查询与巡检 | 原有曲库检索、个人歌单／历史、诊断、通知；增加草案／任务分页和巡检恢复 |
| 导入 | 分页观察只读导入源、查看等待／待整理项、读取／保存策略、提交导入／扫描、查看进度计数；MCP 导入遵守稳定期 |
| 导入提案 | `create_draft(kind="intake")` 包含真实 item_id、当前版本和元数据差异；站内批准、显式应用后安排入库 |
| 歌词 | 读取实际逐字／双语质量与版本、查询候选、单曲查询、专辑／全库补全洗版、频率设置与暂停／恢复／取消／重试 |
| 歌词提案 | `create_draft(kind="lyrics")` 绑定具体候选、歌词版本、文件版本和偏移；两端展示质量、匹配与内容预览，站内批准后应用，保留逐字和翻译时间轴 |
| 响度 | 查看 ReplayGain／分析状态，管理员排队分析最多 100 首；显式修改本人全局模式和专辑／单曲增益，不改音源 |
| 联网 | 复用本人已启用的搜索服务、每日预算、缓存与出站网络策略；搜索最多 5 个来源，仅能按本人最近 24 小时发现的 source_id 读取正文 |

新增 `library:manage`（管理员导入、歌词与分析）、`personal:write`（本人响度）、`web:search`（本人检索预算，同时需要 `library:read`）权限。旧凭据保持原范围，按需重新授权。新增草案类型请使用 0.5.7 或更新的 Web／Android 客户端核对。MCP 没有批准工具，也不能传入 approval 标志自行获得批准；草案改变后原批准失效，应用时再次校验版本与幂等键。

联网内容标为不可信资料，不是执行指令；不会开放任意 URL、Shell、SQL 或读取密钥。MCP 不隐式调用 WildString 的模型，显式 AI 巡检仍须原有连接授权和预算。歌词和元数据后台任务只产生候选；导入任务使用确定性本地规则。导入／扫描目前没有新增强制中断功能，歌词批次和巡检分别使用各自的安全控制接口。

## 下载完成策略

默认识别 `.part`、`.partial`、`.!qb`、`.aria2`、`.tmp` 后缀，大小写不敏感；文件和目录均跳过。可在两端设置识别后缀及“同专辑等待”。

同专辑仍有标记时先等待，多碟 `CD01`／`Disc 1` 等目录合并观察；标记变化或消失后重新计算自动导入稳定期。已确认的待整理项也不能绕过未完成标记。标记观察独立存储，不改变原有音频签名、曲目 ID、人工覆盖或托管副本。

建议 Transmission 使用独立的未完成目录，完成后移入导入源，继续保留原件做种。稳定期和标记观察不能证明下载器没有在未来补充更多文件，也不代替下载器的完成状态；本版没有增加 Transmission RPC、完成回调或多导入源。参考 [Transmission 配置](https://github.com/transmission/transmission/blob/main/docs/Editing-Configuration-Files.md)。

手动网页“导入音乐”仍表示用户声明音频已就绪，可跳过普通稳定等待，但仍检查未完成标记。自动导入与 MCP 提交的导入不会跳过稳定期。已有人工修正、源文件变更冲突及重复检测规则保留。

## 升级和验证

数据库 schema21 → schema22，增加下载策略和目录状态表。旧客户端不传新策略时保留已保存值；升级前仍需备份 SQLite、配置和托管曲库，回退使用升级前的完整备份。

本地验证结果：

- `make check`：Ruff、Bandit、格式、私钥检查与 Web 类型检查通过；Web 与插件依赖审计无漏洞，插件重新打包通过。
- 容器后端 **462 项全部通过，无跳过**；包含迁移、只读源、下载改名、多碟等待、CUE／WAV 转换、真实响度与 AAC、权限、撤销和草案幂等。歌词共享事务最后收尾另有 25 项容器定向回归通过。
- Web 桌面／手机 **224 项通过**；主套件条件跳过的分页用例通过独立配置补跑：大专辑 2 项、连续浏览 12 项。新增歌词长句排版失败已修复，并重新跑完整 Web 套件。
- Android **58 项单元测试通过**，Debug／Release Lint、R8 和构建通过，版本 0.5.7 / code21；模拟器 71 项界面／播放用例通过，4 项需临时真实后端的集成用例分别补跑通过，合计覆盖 75 项。包含新下载策略设置和歌词草案预览。
- 官方 SDK 的 stdio 与 HTTP 协议测试通过；真实本地容器 HTTP 联调确认 48 工具、schema22、个人设置持久化、未批准应用拦截与凭据撤销。临时凭据均已撤销。
- 干净容器构建与冒烟通过：0.5.7、非 root、导入源只读、FFmpeg／Chromaprint 与 Web 资源就绪。

本机未安装 FFmpeg，专门的 AAC 浏览器用例未运行；容器中的真实音频转换和跳转测试已通过。云端模型／搜索服务使用合成协议夹具核验，没有用个人账号发起计费测试；OAuth 客户端、下载器完成回调和国产真机回归没有新增验收结论。

本地验收不代表已创建 tag／正式 Release 或更新 home；本地 Debug APK 不等同于官方签名发布。发布与升级继续单独核验。
