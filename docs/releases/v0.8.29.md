# WildString / 野弦 0.8.29

本版承接 [0.8.28](v0.8.28.md) 的功能并完成发布，修复 Compose Foundation `1.13.0` 文本框尺寸修饰符节点在页面迁移销毁时的异常与冷启动模拟器桌面无响应弹窗对窗口焦点的抢占；`0.8.28` 的发布被 Android 设备回归阻断。[0.8.28 发布检查](https://github.com/qingmuhy744/wildstring/actions/runs/45342826293)

## 已实现

- **在线检索提速与子进程减负**：单曲交互式查询采用独立的 `0.8s` 最小物理间隔，不被后台批扫排期阻塞；搜索关键词自动剥离 `[FLAC]`、`(Explicit)` 等封装噪声并保留版本词；手动查词命中高分双语逐字候选后提前结束；内置元数据源（MusicBrainz/CAA、Last.fm）与数据源插件并行查询并透传强制刷新；Web 端改用渐进轮询。
- **按次选择来源与单曲匹配修复**：Web 端单曲在线歌词、单曲／专辑／曲库资料刷新、单曲在线匹配与歌词批扫支持在多源时按次勾选目标来源，缩窄重查仅更新对应来源并保留其余来源已有候选；修复单曲在线匹配未提交自定义标题／艺人、匹配度百分比显示与窄屏排版问题。
- **参考插件 `2.0.1` 与安全依赖更新**：参考数据源插件（QQ 音乐、网易云音乐、酷狗）版本升至 `2.0.1`（保持 API v2），首跳在 Python worker 侧直接门控并合并酷狗查词与解码进程，插件运行时锁定 `axios 1.21.1`。
- **Android 平板体验与 Compose 1.13 适配**：平板加载骨架屏匹配探索页、目录页、个人页与多列曲目表格实际布局；宽屏全屏播放器统一采用右下角悬浮播放队列（移除 `>=1100dp` 侧边停靠模式，打开与收起队列时封面和歌词位置不动）；Android 升级至 Gradle `9.9.2`、AGP `9.5.2`、`compileSdk 37.2`、Compose BOM `2026.11.01`（移除 Foundation `1.13.0` 已退场的 `isPausableCompositionInPrefetchEnabled` 标志，并关闭 `isBasicTextFieldSizeOptimizationEnabled`、`isBasicTextFieldHeightInLinesOptimizationEnabled` 与 `isBasicTextFieldMinSizeOptimizationEnabled`，避免未挂载文本框节点在 `movableContentOf` / `SubcomposeLayout` 迁移与销毁时触发异常）、KSP `2.3.14`、CommonMark `0.33.0` 与 Robolectric `4.18.1`；同时在模拟器启动与测试前清理阻塞焦点的冷启动系统无响应弹窗。

## 版本与升级

- 后端、Web、Android、macOS 和 iOS 均为 `0.8.29`。Android versionCode 为 `65`，Apple 构建号为 `64`。
- 数据库 schema 为 `56`（由 0.8.28 合入，为 `lyric_lookup_jobs`、`provider_jobs` 与 `provider_refresh_intents` 增加可空列 `options`，保留已有任务）。
- 数据源插件继续使用 API v2。已配置的 `2.0.0` 插件可继续使用，也可从 Release 下载 `wildstring-qqmusic-2.0.1.zip`、`wildstring-netease-2.0.1.zip`、`wildstring-kugou-2.0.1.zip` 在 Web 管理中心升级；从 `0.8.24` 或更早版本升级并曾使用 v1 插件的用户请先阅读升级说明。[0.8.25 升级说明](v0.8.25.md#版本与升级)
