# WildString / 野弦 0.5.10

本版改善曲库浏览与多碟专辑，修复 Android 查看歌词草案闪退，并减少已处理任务和旧设备播放记录的干扰。

- Web、Android 增加专辑和歌曲排序、升降序及页面偏好保存；播放队列遵循当前排序。
- 多碟专辑使用轻量 DISC 小标题和曲数；碟内独立曲号，整张专辑连续播放。其他排序显示歌曲所属碟号。
- 修复 Android 打开 result 为 null 的待确认逐字歌词草案时闪退。
- 草案默认待处理优先；通知默认未读，已处理／已读记录可在历史查看。
- 跨设备接续仅提示其他设备最近 30 分钟内主动暂停的播放，同一次暂停只提示一次；其他设备恢复播放后撤回提示。

数据库升级 schema22 → 23，保存明确的播放状态和服务端暂停时间；历史快照不自动触发接续，仍可手动加载。升级前备份 API 配置、数据库及回滚镜像；音乐库和导入源无迁移，不纳入 API 备份。

## 验证

本地 `make ci`、隔离容器构建与 smoke、500 项容器后端测试、256 项 Web 回归、60 项 Android 单元测试与 7 项连续曲库界面测试已通过；Android Debug／Release 构建与 Lint 通过。4 项 AAC 浏览器场景由含 FFmpeg 的正式流水线执行。发布流水线另行核验；只有发布工作流完成后才提供正式 APK、Web 包和多架构容器镜像。设计与接口边界见 [曲库排序与多碟专辑](../product/catalog-sorting-and-discs.md) 及 [歌词草案与近期暂停接续](../product/lyrics-preview-and-handoff.md)。
