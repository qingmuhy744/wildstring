# WildString / 野弦 0.8.8

本版把四端（Web、Android、iOS、macOS）的界面语言、暗色主题和播放页收拢到同一套契约：界面文案全部走中英资源，服务端错误改为稳定错误码；Warm Carbon 暗色与 Warm Paper 浅色在不同端对齐；播客待播列表、单集收藏与歌词视图跨端统一。Android 播放页新增重做的卡带样式与横屏卡座，macOS 助手与传输栏完成改版。

## 相对 0.8.7

### 四端界面语言与文案
- **账号级中英切换**：Web、Android、iOS、macOS 共用 `auto | zh | en` 设置，登录后按账号生效；未登录跟随系统或浏览器语言，重启保留。
- **去硬编码**：对话框眉题、API Key 标签、目录根名称、通知标题摘要与动作、推荐理由、排行榜依据、外部音乐证据、歌词质量等级、巡检结论与规则摘要、播客下载队列错误全部改走语言包。
- **服务端错误码**：播客与出品方接口统一返回 `podcast_not_found`、`podcast_publisher_not_found`、`podcast_publisher_conflict`、`podcast_playback_settings_not_found`、`episode_not_found`、`episode_unavailable`，四端各自映射文案。
- **服务端生成文字**：站内通知、Telegram 验证码与测试消息、推荐理由与发现歌单默认标题按账号显式语言生成英文；`auto` 与 `zh` 仍返回中文，由客户端映射兜底。
- **校验**：`scripts/check_i18n_keys.py` 保证四端中英键位、占位符一致，并纳入 `make check`。

### 播客
- **统一待播列表**：稍后听、待播队列与新集处理合并为一套契约，订阅与自动入队解耦；新集默认进稍后听，也可按节目改为队尾、当前之后或不处理。
- **单集收藏**：收藏单集与自动清理联动，保留零引用音频；服务端新增保护与预览后手动清理。
- **目录与下载**：播客目录搜索、重复节目合并、下载队列与共享音频清理集中在管理中心；下载任务错误与「未知大小」本地化。
- **续播**：自动续播只在队列为空时预览下一集，不写入队列；四端行为对齐。

### 主题与材质
- **Warm Carbon 暗色**：Web、macOS、iOS、Android 统一暖褐黑底与珊瑚强调色，橄榄色只保留为文字色；黑胶盘面、纹路、唱臂、唱头、枢轴换暖。
- **Warm Paper 浅色对齐**：Android 的 Material 浅色方案从旧橙／绿换成规范令牌，发现页收紧卡片与间距。
- **黑胶默认样式**：四端默认 Vinyl，盘面纹理统一；Web 电台指针表改为分析器驱动的真实电平，播放键可选合成点击声。

### 播放器与歌词
- **歌词视图跨端契约**：歌曲开头从上方显示、短歌词整块居中且不滚动；只高亮当前行，已播与未播行统一弱化；播放中手动浏览停止约 2 秒自动恢复跟随，暂停时挂起，触屏与键鼠共用状态机。
- **Android 卡带播放器**：重画外壳、内窗、六齿带盘、磁头开口与手写标签（Caveat 子集，SIL OFL）；带盘按面积守恒随进度变化，转速与半径成反比，快进／回卷可见走带；切歌保留上一张封面与背景，消除闪烁。
- **竖屏歌词区**：卡带钉在顶部，歌词区固定高度，加载、有歌词、无歌词共用一帧；无歌词时从诗句牌堆随机显示自由主题诗句（中文 47、英文 39，抽完一轮前不重复）。
- **横屏卡座**：手动横屏（菜单或平放约 4 秒提示）进入全屏卡座，单行进度、六个按键、右侧队列、隐藏系统栏；返回键先回竖屏；按键回弹。
- **macOS 助手与传输栏**：助手操作移入窗口工具栏、检索方式并入输入区，窗口标题显示对话名；侧栏去掉品牌标语，播放条改用自绘音量滑杆。

### 推荐与连接
- **统一连接与来源**：模型连接与推荐来源共用一套配置与额度展示，保存不触发模型调用，显式请求才调用。
- **本地化理由**：每日推荐、排行榜、外部音乐证据的说明按界面语言显示，服务端返回的英文理由与客户端映射互补。

### 工程与安全
- **依赖升级**：Android Gradle Plugin `9.5.1`、KSP `2.3.13`、CommonMark `0.32.0`；同步更新锁文件与 Gradle 校验元数据（含 linux aapt2 校验和）。
- **CodeQL 清理**：删除 `podcasts.tsx` 中未使用的预设、过滤标志与队列错误状态；崩溃报告的线程 id 改用 `Process.myTid()`，不再调用已废弃的 `Thread.getId()`。
- **模拟器回归**：仪器测试固定 zh-CN 语言、重试前重启一次性合成 API，并单独归档首轮报告，避免偶发失败被脏状态放大。
- **测试隔离**：修复播客目录内存缓存跨用例残留、歌词跟随测试未传播放状态、下载的 wifi-only 偏好作用域等长期潜伏的测试问题。
