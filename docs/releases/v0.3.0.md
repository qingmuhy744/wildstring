# 野弦 0.3.0

这次围绕手机日常使用补齐 Android 和网页，把原未发布 0.2.3 的播放样式、歌词手势与指纹资料更新一起交付。

## 新增

- Android 普通／规则歌单编辑、多选加入、拖动排序、创作角色浏览和收听统计；管理员可修正元数据、核对资料与封面建议、编辑歌词并逐行打点，处理导入、扫描与待整理任务。
- 两端完整集合跨页播放，获取失败保留原队列；歌单排序保留暂时不可用的歌曲引用；睡眠定时、完整原音离线下载及容量管理、暂停继续、重试和删除。网页增加顺序／循环／单曲／随机，按账号恢复队列与位置，恢复时暂停。
- 每日推荐默认使用本地收藏、实际收听与元数据，同日稳定、可换批和反馈偏好；相同录音 ID 去重，现场等不同录音保留。AI 与 Last.fm 增强默认关闭。
- 自然语言找歌与歌单草案，预览后确认保存；只允许真实曲目 ID，模型失效明确回退本地检索。共享播放进度须明确操作，版本冲突不会自动覆盖。
- 封面、黑胶和磁带播放样式、横屏布局、长按大封面；PC 点击歌词定位、手机拖动预览后确认，空白处切换歌词与动画。样式只在设置切换。
- 可选 AcoustID 指纹衔接 MusicBrainz；单曲／专辑／整库手动更新，来源优先级拖动排序；CAA 候选由服务端代理预览，建议确认后应用。

## 数据和使用边界

升级自动迁移数据库到 v14，保留已有曲库、人工修正与个人数据。建议先用 SQLite backup API 备份数据库及持久卷，旧版不支持自动降级。导入源保持只读，已有音频标签不会自动改写。

离线下载保存完整原音，不预先转为 AAC；实际编码需设备可解码。网页下载需要页面保持打开，重新打开后可继续下载，浏览器可能回收存储；断网刷新页面需 HTTPS／localhost 的 Service Worker 支持。网页离线身份有效期 7 天；联网后重新核验权限，退出／换账号清理私密内容。Android 使用应用私有存储和用户发起的前台下载服务，仍受系统及厂商后台限制。

AI 每次最多发送 80 个候选的必要元数据，不含音频、歌词、路径或账号身份。规则回退可处理明确艺人、歌曲、专辑、收藏、未听过与日期等条件；未分析音色、节奏或情绪，不保证模糊听感描述的筛选准确性。真实云端模型和 Last.fm 用户授权同步需配置后自行核对；本批采用真实 HTTP 测试服务验证模型请求与异常回退，没有把模拟结果当成真实云服务验收。

上传入口、iOS 原生、车载、小组件和批量标签写回不在本版。

## 验证

后端隔离 Docker 202 项、网页全量 104 项与真实跨页专项 2 项，以及 Android 27 项 JVM、双 Lint 与 R8 构建已通过；边界修复另有定向回归。原生设备和正式签名 APK 检查由发布流水线执行。具体记录在 [0.3.0 验收清单](../product/mobile-completion-0.3.0.md)。Android 正式 APK、Web ZIP、SHA256SUMS 和公开签名指纹由发布工作流生成，容器同时提供 linux/amd64 与 linux/arm64。
