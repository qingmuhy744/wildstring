# WildString / 野弦 0.8.0

本版重做播客播放体验。播客单集使用独立播放信息层，不再复用音乐播放器的专辑、歌词、音质和收藏控件。

## 设计边界

- 播客频道页展示节目简介、来源和单集列表；点击频道进入频道详情，点击单集标题查看完整简介，播放按钮只负责开始播放。
- 播客播放页以节目封面、单集标题、节目名称和发布时间为主视觉，提供进度、倍速、上一集／下一集、队列、下载状态和已听进度。
- 音乐播放器继续保留专辑、歌词、音质和收藏操作；播客不会显示这些音乐专属入口。
- 单集详情使用底部弹层或对话框承载完整简介，避免长文本挤压播放控制。

## 当前实现

- 网页与 Android 的「我的下载」包含本人手动保存、自动下载和播放缓存，另以「服务器已有」查看共享音频。播放及下一集预取按触发账号记录，复用已有文件也会关联本人；播放缓存仍可按零引用规则回收，清理成功后同步移除归属。管理员显式下载全部单集会为自己建立保存记录。schema 41 保留原数据，旧缓存不猜测下载人。

- 本轮移除自动历史保护并修复浅色播客菜单悬停对比度；已完成个人节目自动下载、固定最新 N 集窗口、个人偏好和接口账号隔离，见[多用户设置检查](../architecture/multi-user-settings-audit.md)。

- 「自动下载」在网页与 Android 面向关注者开放，按账号和节目选择最新 3/5/10 集、本人未听完或全部；最新范围先确定再过滤已缓存和已听，重复检查不向旧单集扩张。手动与自动保存来源分开，底层音频和队列仍共享。
- 普通账号的列表、详情、出品方、播放、保存与进度接口只允许访问本人的节目关联；迁移从关注、保存和收听记录恢复关联，取关后保留历史访问。管理员的个人策略也只影响本人。
- 网页主题、播放样式、字号、浏览入口、离线音质、容量和网络许可按账号保存；Android 外观、播放/歌词偏好、离线设置及接续模式按服务器和账号保存。旧设备偏好只迁移一次，不复制给后续账号；启动图标仍属于整台设备。网页请求绑定账号，跨账号旧响应及旧页面写入被拦截。

- 普通用户的播客页只显示个人关注；管理员也默认进入个人关注，显式切换后才查看本服节目。出品方聚合跟随当前范围，网页和 Android 保持一致。
- 所有者可在网页「管理 → 设置」开启普通用户添加 RSS 并关注，迁移默认关闭；普通用户添加时不能修改全服更新与下载策略，同一 RSS 并发复用已有节目，新节目默认不批量下载音频。
- 每库可设置「新用户默认可访问」，创建账号时预选默认授权，也可逐项修改；更改默认策略不影响已有账号的授权。
- 网页来源、自定义托管位置及迁移目标提供服务器目录选择窗口，支持路径输入、面包屑、子目录和上级目录。来源处显示完整路径；账号库授权复选框与名称对齐。普通音乐浏览默认合并授权范围，有多个库时才显示可选筛选，播客不再显示音乐搜索和音乐库栏。
- 数据结构升级至 schema 41，保留原有账号、曲目、歌单、节目和进度；新增开关及默认授权支持重复迁移。后续权限复核将当前 schema 提升至 42，仅新增隔离登录计数。

- Android 和网页端均已接入单集详情查看与独立播客播放信息层，播客说明支持受限 HTML 富文本渲染。
- Android 播客播放页提供「封面／文章」切换，标题随文章滚动，时间标记可以跳转；收起播放器回到所属节目的单集列表。
- Android 返回单集列表保留当前数据、排序和滚动位置，不再随播放器收起重新请求；节目与单集列表使用下拉刷新，复用三根弦加载动画，刷新期间保留已有内容，失败后可再次下拉重试。
- Android 播客节目身份与封面地址随播放缓存保存，外部封面通过无登录凭据的连接加载，避免恢复播放后退回默认封面；音乐 AAC 偏好不会误套到播客音频。
- 网页设置与弹窗统一使用浅色／深色主题变量，修复账号偏好白字灰底及关闭按钮错位。
- 播放未下载单集时，客户端向服务端声明播放网络并触发当前单集后台缓存；下一集预缓存和网络范围由每个用户独立设置。
- 默认开启当前单集缓存、关闭下一集预缓存、仅 Wi‑Fi 缓存；缓存任务复用现有播客下载队列和宿主机挂载目录。
- 音乐接续与播客书签分开：播客按账号、单集保存进度，每约 5 秒本机落盘、每约 10 秒上报，暂停、跳转、切集和播完立即保存。
- 网页和 Android 增加播客续听偏好，默认询问，也可自动续听或从头播放；旧设备补传发生冲突时保留两边位置，由用户选择。主动向后拖动允许更新书签。
- 待发送进度跨重启保留；旧会话和乱序报告不会覆盖新进度，也不能触发听完清理。接口与升级边界见 [播客进度契约](../../contracts/podcast-progress.md)。
- 网页和 Android 增加出品方聚合页，展示本服已有且经人工确认的节目；节目详情支持确认、修正及解除归属，来源作者署名独立保留，RSS 刷新不会覆盖人工归属。
- 出品方属于共享节目资料，复用 `metadata:write` 权限；听众可浏览，所有者、曲库管理员和资料编辑员可修改。修改采用版本校验，个人未听数量仍按账号计算。数据库升级至 schema 35，接口见 [出品方契约](../../contracts/podcast-publishers.md)。
- 网页和 Android 区分“本服节目／我的关注”。个人取关保留进度和历史关联；普通用户添加 RSS 受实例开关控制，删除共享节目保留管理员权限。节目、单集与服务端音频只存一份。
- 音乐支持多库与每库多个只读来源，由所有者配置并分配用户权限；角色能力与库权限共同校验，移除来源或停用库保留托管副本。
- 普通歌单、收藏和播放接续支持跨获授权库；撤权后隐藏曲目并清理两端失效队列、页面和离线缓存，保留服务端私人引用，恢复授权可重新出现。
- 共享播客音频由个人手动或自动引用保留；听完按个人策略释放自动引用，取关暂停并释放自动引用，手动保存不受影响。零引用清理统一检查保护状态和使用租约。后台导入、资料查询、歌词扫描与 AI/MCP 保留用户和目标库并重新检查权限。
- 数据库升级至 schema 36，保留旧用户的原库权限、曲目/歌单 ID 与进度；不自动替所有账号关注旧节目。接口及边界见[多库与个人关注](../../contracts/multiple-libraries.md)。
- 后端、Web、Android 与 iOS 版本统一为 0.8.0，Android versionCode 为 36，iOS build number 为 35；正式发布通过 `v0.8.0` 标签由 Release 工作流执行。

## 远程回归问题修正

- 网页跨标签页回听测试原先只等待共享记录 `dirty=false`，可能误读播放检查点已同步的状态，而第二页恢复跳转/暂停还在上报；后续回听因此正确触发并发冲突。测试先等待恢复跳转完成，再等待暂停检查点同步，保留客户端和服务端的冲突保护。修正前后桌面/手机各重复 8 次均通过，完整播客网页 42 项回归和 `make check` 通过；远程结果另行核对。
- 全量容器测试保留各用例独立数据库和音频，超过测试容器原有的 512 MiB 临时目录限制；测试专用 `/tmp` 上限调整为 1 GiB。运行容器的临时空间、只读配置、媒体与数据卷均不变。
- Android 模拟器首轮发现迁移测试使用 instrumentation 包上下文，无法在应用进程内创建另一包的数据库目录；改用目标应用上下文和系统建库方法，继续验证 Room 1→2 的原队列、位置与账号隔离检查点保留。旧插件和专辑批量歌词测试改为核对旧路由的网页管理提示、配置控件缺席及无管理请求，不恢复已收回的管理功能。单元与测试编译本地复验，完整模拟器回归另行核对。
