# 野弦 0.2.3

把收藏的音乐放上唱片，或装进一盒磁带。

- 管理员可手动更新单曲、专辑或整库元数据，默认只查缺失资料，也可查询全部资料或重新联网查询。结果仍逐字段确认后应用；来源优先级可在网页设置拖动调整。
- 可选 AcoustID 音频指纹识别，衔接 MusicBrainz 和 CAA 建议；保留识别来源、相似度与发行版候选。Docker 在原镜像中包含指纹工具，凭据只留在服务端。

- Android 与 Web 全屏播放提供封面、黑胶、磁带三种样式。默认封面，仅在 Android 设置／Web 账号设置修改，记住当前设备选择。
- 黑胶使用唱纹、真实封面中心标、金属唱臂与固定光泽；磁带使用双卷轴、透明窗口、歌曲纸贴和封面角标，带卷随整曲进度变化。
- 黑胶中心封面放大；手机横屏采用视觉与播放控制左右布局，歌词和队列切换后仍可控制播放。
- PC 点击歌词跳转、点空白切换画面；移动端拖动预览、点 ▶ 确认跳转。Android 移除重复底栏，歌词与曲名留出间距。
- 长按封面、黑胶、磁带或歌词可看独立大封面，保持正向、完整显示；点空白或返回关闭，播放继续，松手不会误切换或跳转。
- 三种样式共用已有播放器、进度、收藏、歌词和队列。切换样式或查看歌词不重新加载音频，也不新建收听会话。
- 拟物动画跟随实际播放与缓冲状态；暂停、播放错误、隐藏页面、进入后台或系统减少动态效果时停止持续转动。返回后从保留的角度继续。
- Android 封面取色背景延伸到顶部状态栏和底部手势区，交互内容保留安全间距；系统图标随主题变色，设置页使用相应表面色。进度条采用主题暖橙／暖白与中性色，低高度窗口优先保证控制区域。

样式是当前设备的界面偏好，与日夜模式独立；Android 红布主题仍可搭配三种样式。元数据功能增加后台刷新接口与数据库 v13 迁移，原音频与标签不自动修改，基础播放接口不变。

发布工作流会执行 Python／Web／容器与 Android 回归、签名和安装检查，通过后生成 APK、Web ZIP、校验和以及双架构 GHCR 镜像。动画功耗、国产真机系统栏与完整后台行为仍需真机核对。

详细设计、实现和验证边界见 `docs/product/player-styles-0.2.3.md`。版本准备不代表已经发布，以对应 GitHub Release 为准。
