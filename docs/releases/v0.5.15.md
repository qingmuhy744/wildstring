# WildString / 野弦 0.5.15

本版把专辑级快速操作、批量元数据整理和后台查询反馈收成一套分层体验：安卓适合快速处理，Web 继续承担完整校对。

- Android 专辑网格和发现页支持长按操作：播放专辑、下一首播放、加入播放队列、离线保存、加入歌单、编辑专辑信息、批量核对资料和更新专辑元数据。
- Android 新增轻量专辑编辑，只统一修改专辑名与专辑艺人；后端以每首歌曲的 metadata version 做冲突保护，并保留元数据历史。
- Web 按文件夹整理增加数量概览、搜索、问题筛选、有限展开和当前文件夹编辑区，避免大量文件夹全部摊开。
- 强制联网查询优先于普通后台队列；重复强制点击不再生成空批次；安卓和 Web 加载状态减少重复文字。
- 后端、Web、Android 与 iOS 版本统一为 0.5.15，Android versionCode 为 29。

## 验证边界

- Python：Ruff、专辑批量更新、查询队列优先级、批次去重相关回归通过。
- Web：TypeScript 类型检查和生产构建通过。
- Android：源码与测试更新已完成；本机 Gradle 编译受受限环境中的 Gradle 缓存锁权限阻止，需由 CI 完成 Debug／Release 构建和设备回归。
- iOS：只统一版本号，不声称新增 Android 专辑操作已在 iOS 真机实现。
- 部署备份只包含 API 服务数据、SQLite、私有配置和插件状态，不包含音乐库或导入源。
