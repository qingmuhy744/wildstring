# WildString / 野弦 0.8.4

本版用户功能与 0.8.3 相同，是一次发布门禁修复。0.8.3 的签名 APK 已成功安装并显示连接页，但自动检查只识别中文文案，在默认英文的 CI 模拟器上误判失败，因此没有生成 GitHub Release。请不要使用尚未发布的 0.8.3 标签作为安装来源，改从 0.8.4 Release 下载附件。

## 相对 0.8.3

- Release 正式 APK 安装检查现在从 UI 层级解析文本，同时兼容中文和英文连接页，不再依赖模拟器默认语言。
- 用户功能、API、数据库 schema 47 与 0.8.3 一致，从 0.8.3 代码升级不新增迁移。
- GitHub Code Scanning 与 Dependabot 开放告警均为 0；Containers 产物随本版重新构建并记录镜像摘要。

0.8.3 的功能说明见 [0.8.3 发布说明](https://github.com/qingmuhy744/wildstring/blob/v0.8.3/docs/releases/v0.8.3.md)，包括播客探索、Web 与 Android 设置、Mac 首页与桌面歌词、文件夹导入和 Apple 播放修复。

## 安装

- 后端、Web、Android、iOS 与 Mac 统一为 0.8.4。Android versionCode 为 40，正式 APK 沿用发布签名，可覆盖升级并与「野弦 Dev」共存；iOS／Mac 构建号为 39。
- 发布附件包含 Android APK、Mac DMG、Web ZIP、数据源插件、SHA-256 校验文件和 Android 发布签名证书指纹。容器镜像支持 linux/amd64 与 linux/arm64。
- Mac 最低系统为 macOS 14；当前 DMG 使用临时签名、未公证，首次打开可能需要在系统设置中允许。本次不提供 IPA 或 TestFlight。

## 验证边界

- 本版在最终 main 提交重新执行完整 CI、Android 构建与模拟器门禁，并在 Release 中实际安装固定签名、R8 优化的 APK。
- 模拟器通过不等于真机后台、省电、来电／蓝牙、真实弱网或全部音频格式均已验收。发布不会自动升级个人音乐服务器。
