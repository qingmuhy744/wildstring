# WildString / 野弦 0.8.12

本版是面向 0.8.10 的小版本。`v0.8.11` 标签已创建，但其 Release 工作流在 Android 模拟器回归（`NativeNavigationTest`、`PadLayoutTest`）失败，未发布任何安装包、镜像或 GitHub Release；按发布规则不移动已有标签，0.8.11 的全部内容（PR #108）随本版一并发布。本版另合入 PR #110：Android 播客音频与封面统一由野弦服务器提供，新增服务端播客封面代理，修复平板设置导航（即 0.8.11 发布失败的原因），优化平板发现页与播客探索布局，并移除旧版实例级 AI 配置。

## 相对 0.8.10

### 0.8.11 内容（PR #108，首次随本版发布）
- **Android 手机／平板自适应布局**：平板与展开的折叠屏使用侧边导航栏、目录与搜索网格、宽曲目列表多列，以及播客订阅／单集、对话历史／聊天并排与设置双栏；手机、折叠状态与窄分屏保持层级布局。切换布局或返回页面时保留滚动位置、选中项与聊天草稿。
- **修复封面氛围间歇性超时**：对共享的音乐与播客图片加载器关闭 Coil 的 Android 网络监听，修复无已注册系统网络但本地服务器可达时封面冷加载返回 HTTP 504 的问题。
- **待播拖动手柄**：Android 与 iOS 待播列表常驻显示拖动手柄，松手后一次写回顺序；iOS 落位成功后提供触感反馈。
- **元数据任务单一队列**：后端新增合并的 `queue` 视图并设为默认；Web 元数据任务页改为单一队列，支持批量选择与应用，并逐行处理失败。Web 播客网格宽屏拉伸、待播行对齐四列，播客投递规则支持批量选择。
- Android 模拟器完整回归与 Release 冒烟改为 2 核 CPU、4 GB 内存。
- 完整说明见 [0.8.11 发布说明](v0.8.11.md)。

### Android 播客资源统一经服务器
- **音频经服务端代理**：Android 播客音频通过已鉴权的 `stream?proxy=1&cache=1` 获取，复用设备离线文件、设备播放缓存与服务端现存文件；网络请求及 Range 均由服务端代理，不再直接连接源站，也不在失败时切换源站。已下载到设备的单集仍可离线播放。开发过程中曾加入的「源站优先／服务器优先」偏好与回退传输已在合入前移除，统一为服务器模式。
- **服务端封面代理**：新增需要登录与节目访问权限的 `GET /api/v1/podcasts/{id}/cover`。Android 订阅列表、节目详情、待播、播放器与系统媒体封面均经此接口获取，并使用按账号隔离的封面缓存。服务端优先复用下载单集时保存的 `cover.jpg`，否则按现有出站策略抓取节目封面地址；只接受 JPEG/PNG/WebP，限制 8 MB，输出最长边 768px 的 JPEG。
- **目录封面**：探索列表中尚未入库的节目通过 `GET /api/v1/podcasts/directory-cover/{key}` 获取封面；`key` 来自搜索／榜单响应中的 `artwork_key`，服务端只允许获取已返回目录结果中的封面，不接受客户端提交的图片 URL，也不会因此创建节目或关注记录。目录封面在进程内缓存 1 小时。加载失败时显示占位图，不阻断播放。

### Android 平板与导航
- **修复平板设置导航**：宽屏下默认的「账号」分类改为按布局推导，不再写入保存的导航状态；从平板宽度回到手机宽度时，设置页重新显示分类列表，而不是直接停在「账号」子页。这是 `v0.8.11` Release 中 `NativeNavigationTest` 失败的原因。
- **平板发现页**：对齐搜索、快捷入口与专辑横滑区；宽屏曲目列表中点歌曲行播放，点艺人或专辑打开详情，多艺人合作曲目可选择艺人；元数据缺失时不提供跳转。
- **平板播客探索**：宽窗口固定并排显示列表与预览，窄窗口回到逐页进入。

### 移除旧版实例级 AI 配置（破坏性变更）
- 删除旧的实例级 AI 配置接口、表单与运行时模型回退，`/api/v1/manage/ai` 相关路由不再提供；模型统一通过助手设置中的「模型连接」配置。
- 数据库 schema 升至 51：升级时将推荐偏好中引用旧配置（`legacy`）的连接改为本地推荐并关闭 AI，对话中引用旧配置的连接清空。**升级后如需继续使用 AI 推荐或助手，请在助手设置中重新建立模型连接。** 基础播放不需要模型。

### Web
- 字段帮助只在信息图标上悬停或聚焦时出现，提示定位在当前字段之外，并保留键盘关联。

### 后端与 CI
- 修复 `podcasts` 与 `podcast_artwork` 模块间的循环导入（CodeQL 告警）：封面路由改由 `podcast_artwork` 单独注册。
- CI 音频依赖安装改为 `scripts/install_audio_deps.sh`：工具已存在时跳过；命中缓存时先离线安装（`apt-get --no-download`，失败再用 `dpkg` 直接安装缓存包）；最后才联网并带退避重试；联网前在 runner 的镜像列表中追加 kernel.org、Princeton、MIT 等非 Canonical 备用镜像（官方源仍优先），避免 Ubuntu 官方软件源或 DNS 故障导致后端与 Web 测试失败。
- Web 端到端的播客播放测试改为桩住目录榜单，不再依赖 Apple 接口；容器内挂载前端静态文件时，已移除接口的测试同时接受 404 与 405。

## 已知限制
- Android 播客音频与封面完全依赖野弦服务器可达；服务器不可达时只能播放已下载到设备的单集。
- 目录封面缓存仅在进程内保存，服务重启后清空，标识失效时刷新目录即可重新获取。
- Android 播客播放页「AI 导读」标签仍为即将推出占位。
- `podcasts.slow_download` 列沿用建表语句与运行时 `ALTER TABLE` 补齐。
