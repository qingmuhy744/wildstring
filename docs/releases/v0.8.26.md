# WildString / 野弦 0.8.26

本版修复 Android 系统媒体控件和音乐偏好输入，并改进 Android 栏目导航和 Web 播客续播设置的保存。

## 已实现

- Android 在通知栏或锁屏点击「上一首」，会切回播放队列中的上一首。再点当前底栏或平板侧栏标签可回到栏目首页，在首页再点可回到列表顶部。
- Android 通知页精简了空态和操作文案。助手的「音乐偏好」增加了输入示例，并修复输入文字不可见的问题。
- Web 播客刚改完续播设置就切集时，当前网页立即使用新设置。后台保存失败后，「重试」会重新提交这个节目的续播偏好。
- 发布流程核对五端版本和原生构建号。稳定渠道根据最高已发布的稳定版本更新。

## 版本与升级

- 后端、Web、Android、macOS 和 iOS 均为 `0.8.26`。Android versionCode 为 `62`，Apple 构建号为 `61`。
- 数据库 schema 沿用 `55`，数据源插件继续使用 API v2。已配置的 v2 插件可继续使用。若从 `0.8.24` 或更早版本升级并使用过 v1 插件，请按 0.8.25 的说明重新导入和配置。[插件升级说明](v0.8.25.md#版本与升级)
- Android 正式包沿用发布签名，可覆盖升级。

## 验证

- Android 模拟器验证系统上一首、手机和平板导航，以及软键盘中文和英文输入。音乐偏好用截图回归文字可见性。
- 桌面和移动浏览器中模拟延迟保存和 HTTP 503。回归确认重试后能从服务器读回新设置。[功能修复 PR](https://github.com/qingmuhy744/wildstring/pull/187)
- 正式构建、设备回归、签名 APK 安装和渠道同步结果见 [Release 工作流](https://github.com/qingmuhy744/wildstring/actions/workflows/release.yml)。
