# 野弦 0.4.1

本版修复 Android、网页及服务端的手动 AI 巡检授权：已有的实例 AI 配置现在可以用于手动巡检，无需重复填写 API Key 或开启自动巡检。

## 巡检

- 手动开启 AI 分析后，连接列表包含当前账号可用的模型，也包含只读的「实例 AI（已有配置）」。选择连接并提交，只授权本次任务。
- 未选择连接时显示具体提示；Android 不再在 AI 巡检中显示「本地找歌（不使用模型）」这一矛盾选项。已有实例连接说明可手动使用，并提示定时计划需要另行授权。
- 定时计划及 MCP 工具提交的巡检仍要求「允许自动巡检使用」。单次授权由服务端记录，客户端无法通过提交额外字段伪造；恢复旧任务不会提升原有权限。
- 手动任务仍受当前用户权限、连接版本、任务调用上限及每日额度限制。结果先生成草案，确认后才能应用。
- 修正主动选择本地找歌后显示「AI 未配置／暂不可用」的误导提示。本地模式按关键词匹配曲库信息，未调用模型，不代表具备自然语言理解能力。

## 历史对话

Android 与网页的历史对话列表支持逐条改名和删除，删除前确认，正在生成回复时提示稍后重试。删除其他历史不会清空当前对话，已有草案、歌单及音乐保留。「历史保留天数」改为明确的助手对话保留说明，仍按最后更新时间自动清理。

聊天在单次预算内预留最后一次模型调用生成回答，避免查询多轮后直接耗尽预算；模型忽略停止工具调用要求时不继续执行工具或追加调用，并显示清晰提示。当前聊天工具仅查询曲库与已有资料，尚不支持实时查询库外最新发行；发现页的 Last.fm 收藏候选也不等于最新发行榜。

## 升级与验证

请同时升级服务端与 Android App 至 0.4.1；网页随服务端更新后刷新。只升级 App 时，0.4.0 服务端仍会阻止未授权自动使用的连接。Android versionCode 为 13，沿用既有正式签名，可以覆盖安装。数据库保持 schema 18，无新增迁移。

回归覆盖已有实例连接及个人连接的手动执行、计划与工具的权限隔离、伪造授权拒绝、连接或账号变更、旧任务恢复和额度限制；网页覆盖桌面及移动布局，Android 覆盖实际对话框选择和按钮状态。模型响应使用合成夹具，不消耗私人 API 额度。正式流水线另执行完整测试、容器验证及签名 APK 安装启动检查，实际结果以工作流为准。

发布产物包括签名 APK、Web ZIP、SHA-256 校验文件、签名指纹，以及 amd64 / arm64 GHCR 镜像。升级不自动导入音乐或修改音频文件。
