# WildString 0.9.0 Alpha 1 发布草稿

- 电台增加自托管书架，覆盖电子书、有声书、章节标题校对、手动配对与拆分、个人书签和批注。Web 和 Android 共用按账号隔离的进度协议。具体覆盖见[书架契约](../../contracts/bookshelf.md)。
- 音乐库和书库支持独立副本、同挂载硬链接和显式模式迁移。便携元数据通过 [.wildstring 侧车](../../contracts/wildstring-sidecar.md)交换。

## 升级

服务端 SQLite 升至 v57。启动旧版前需恢复该版本支持的数据库备份。Android Room 升至 v3，旧队列和播客检查点随迁移保留。正式渠道跳过 Alpha 更新，Alpha 版需手动安装。

五端版本及构建号用发布脚本校验。实际发布和 L3 验收状态以[实施方案](../plans/self-hosted-bookshelf.md)为准。

## 验证记录

- 后端全量回归（`pytest -n 6`）通过 1001 项、跳过 2 项（Chromaprint 与可选原生插件夹具），覆盖旧库与旧音乐导入、书架电子书/有声书解析与流式播放、章节校对、配对拆分、跨端进度冲突仲裁、`.wildstring` 侧车还原清理及存储模式迁移。
- Web 完成 `build-web` 与 Playwright `bookshelf.spec.ts`（10 项）、`music-libraries.spec.ts`（18 项）、`podcast-player.spec.ts`（36 项）共 64 项测试；已逐张核查桌面 `1360×900`、`Pixel 7` 及 `390×844` 浅深主题截图，覆盖书架卡片、滚动/分页阅读、句内批注高亮、跨页有声书常驻停靠条、加载骨架屏、跨卷错误与成员受限状态。
- Android 完成 `make android-ci`（Debug/R8 Release 构建、Lint Debug/Release 与单元测试，含预发布 `UpdatePolicy`、Room `MIGRATION_2_3` 及分页测算），`wildstring-phone`（`1080×1920`）与 `wildstring-pad`（`2560×1600`）真后端回归均通过并逐张复查 12 张浅深主题截图（验证不透明模态浮层无窗口残影及非零 `char_offset` 书签）；`BookReaderPanelMotionTest` 在手机端正常通过，并在注入 `-e injectBookPanelJump true` 时按预期报错拦截（`127.6 / 52.5 px`）。
- 发布包版本校验（`package_release.py --check-only`）、插件构建测试（15 项）、Web/插件依赖审计及 `uv.lock` / `make check` 门禁均通过。
- 本机环境未覆盖项（待 CI 或目标环境补齐）：正式签名密钥 APK 安装冒烟、Apple 原生端（Linux 缺少 XcodeGen 与 Swift）、容器镜像构建与 `docker-smoke`、其余未受影响的 Web E2E 分片，以及可选 `test-native-plugin` 与 Chromaprint 外部依赖测试。
