# WildString / 野弦 0.9.0-alpha.1

本版为 `0.9.0` 系列首个预发布测试版（Pre-release），聚合了自 [0.8.29](v0.8.29.md) 以来的自托管书架、便携存储与侧车、MCP OAuth 2.1、Google Drive 原生远端存储以及 Google Gemini 原生协议与本地 AI 测试工具。正式发布渠道默认跳过 Alpha 更新，不会覆盖 `:latest` 镜像或 Homebrew 稳定版。

## 已实现

- **自托管电台书架与便携存储（PR #204）**：Web 与 Android 的电台新增自托管书架，支持 TXT / EPUB 电子书与有声书浏览播放、章节标题校对、双载体手动配对与拆分、个人书签、句内批注高亮及跨端进度冲突仲裁（见[书架契约](../../contracts/bookshelf.md)）。音乐库与书库同步支持独立副本、同挂载硬链接、显式存储模式迁移、源路径重绑定与 [.wildstring 便携侧车](../../contracts/wildstring-sidecar.md)导入导出，并补齐多端 UI 审计修复、播放队列／元数据保护及认证与播客资源加固。
- **MCP OAuth 2.1 授权（PR #209）**：在保留原有静态个人访问令牌（PAT）的基础上，为 MCP 服务新增 OAuth 2.1 授权码 + PKCE 与动态客户端注册流程，支持 Gemini、Claude Web、ChatGPT 等网页端连接器直接授权接入。
- **Google Drive 原生远端存储（PR #210）**：为音乐库与书架新增原生 Google Drive 存储后端，服务端仅保留轻量索引、解析缓存与受容量上限控制的远端热缓存，媒体文件按需流式读取并统一经由服务端 HTTP 代理层外发。
- **Google Gemini 原生协议与本地 AI 测试（PR #212）**：内置音乐助手新增 Google Gemini 原生 REST 协议（`generateContent` / `streamGenerateContent?alt=sse`、`x-goog-api-key` 请求头、`thoughtSignature` 多轮续接、`thinkingConfig` 推理强度映射及原生 Google Search Grounding 来源归一），Web 与 Android 连接表单同步开放「Gemini 原生接口」并联动原生搜索开关；合入 `make test-ai-local` / `make test-ai-live` 与离线回环代理测试。
- **构建与 CI 稳定性（PR #208 / #211）**：收敛测试临时目录清理、分离高耗时 Web E2E 分片，并加固容器镜像构建、Android 插件重试、Gradle 缓存与 CI 优先镜像源。

## 版本与升级

- 后端为 `0.9.0a1`，Web 与 Android 为 `0.9.0-alpha.1`（Android `versionCode` 为 `66`），macOS 与 iOS 为 `0.9.0`（构建号为 `65`）。
- 服务端 SQLite schema 由 `56` 升至 `64`（依次涵盖书架与存储模式迁移、便携音乐侧车、重绑定与音频指纹缓存、书架批注结构、会话过期索引、MCP OAuth 2.1 及远端 Google Drive 存储表）。升级前请务必备份 SQLite 数据库与凭据目录；如需回退至 `0.8.29`，必须恢复对应备份。
- Android Room 升至 `v3`，旧队列与播客检查点随迁移保留。
- 预发布渠道隔离：正式版客户端自动跳过 Alpha 更新，GHCR 仅推送 `v0.9.0-alpha.1` 标签而不更新 `:latest`，Homebrew Tap 保持稳定版不变；测试需手动拉取对应镜像标签或从 GitHub Pre-release 下载安装包。
