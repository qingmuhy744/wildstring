# WildString 0.9.0 Alpha 1 发布草稿

- 电台增加自托管书架，覆盖电子书、有声书、章节标题校对、手动配对与拆分、个人书签和批注。Web 和 Android 共用按账号隔离的进度协议。具体覆盖见[书架契约](../../contracts/bookshelf.md)。
- 音乐库和书库支持独立副本、同挂载硬链接和显式模式迁移。便携元数据通过 [.wildstring 侧车](../../contracts/wildstring-sidecar.md)交换。

## 升级

服务端 SQLite 升至 v57。启动旧版前需恢复该版本支持的数据库备份。Android Room 升至 v3，旧队列和播客检查点随迁移保留。正式渠道跳过 Alpha 更新，Alpha 版需手动安装。

五端版本及构建号用发布脚本校验。实际发布和 L3 验收状态以[实施方案](../plans/self-hosted-bookshelf.md)为准。

## 验证记录

- 后端全量回归覆盖旧库、旧音乐导入与书架，另跑通重链中断重试、有声书 AAC、EPUB 音频拦截、桥接配对与侧车还原专项测试。
- Web 合成库执行了桌面与 390px 的书架、分页阅读、书签、深链接刷新及有声书 Range 测试，截图复查覆盖浅深主题。Android Phone 和 Pad 合成库已核对书架、自适应列表及两种阅读模式，并验证离开书架后独立有声书会话仍在播放。
- 使用当前代码和静态包在缓存运行镜像中的非 root、只读音乐挂载冒烟通过。全新镜像构建验证仍受 Docker Hub 基础镜像 TLS 超时阻塞。当前 Linux 环境缺少 XcodeGen 和 Swift，Apple 原生验收未执行。
- Android 平板的目录和书签以浮层打开。逐帧采样覆盖浮层左边缘、工具栏上边缘的进出场、正文及触发按钮边界固定、落位像素稳定和减弱动态效果首帧落位。故意注入跳变时，测试报告单帧位移超过总行程。
- Web 回归覆盖滚动和分页切换、调整字号与行距、切换字体、改变视口宽高后的字符锚点，并核对提交的书签。书库管理回归覆盖加载、空库、跨卷提示、导出结果和授权不足。
- 便携侧车回归覆盖候选封面、歌词应用与撤回、章节标题校对。Android 真实后端流程核对了书签的非零字符偏移。
- 本机分开执行通用浏览器套件和其余 `make ci` 门禁。后端 996 项通过，Web 通用及专用套件合计 572 项通过。锁文件检查、Android 构建与 Lint、R8、Phone 和 Pad 回归均通过。原生插件夹具另行编译验证通过。
- 完整 L3 验收还需正式签名 APK 安装、Apple 原生测试和新容器镜像构建。
