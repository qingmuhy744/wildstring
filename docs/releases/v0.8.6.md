# WildString / 野弦 0.8.6

本版重点推出了 macOS 客户端多服务器管理与安全切换机制、全新 Editorial 视觉体系、播客倍速与布局重塑，升级了 CorePlayback 共享播放内核的队列持久化与首播加载性能，完善了 Android 全屏手势与每日推荐体验，并完成了 Web 端与 AI 助手全量中英双语国际化。

## 相对 0.8.5

### macOS 客户端与多服务器支持

- **已保存服务器快速切换**：在侧栏底部账号卡片中支持直观切换已保存的服务器，或快速添加并连接新服务器。
- **平滑切换与防中断回退**：新增或切换服务器时，原连接与播放保持活跃；若目标服务器无法访问或登录失败，优雅回退并保留当前连接，不中断使用。
- **独立会话与队列隔离**：各服务器的登录态、曲库选择、播放队列及暂停进度相互独立持久化。切换服务器时暂停当前播放，并以暂停状态恢复目标服务器的历史队列与进度。
- **退出二次确认**：账号菜单及设置中的退出操作增加二次确认弹窗；确认后仅清理当前服务器的凭据，不影响其他已保存的服务器。
- **新增回归单测**：新增 `MacServerTests` 测试套件，覆盖双服务器队列恢复、切服失败回退及安全退出逻辑。

### macOS 视觉设计规范与播客体验

- **Editorial 视觉体系落地**：根据全新沉淀的 `DESIGN.md` 设计规范，采用温润卡片、细边框与低对比度柔和背景；隐藏系统窗口工具栏底色，让内容与侧栏自然延伸至窗口顶部。
- **多主题支持**：支持自动跟随系统或手动切换浅色/深色主题（快捷键 `⌘+Shift+A`）。
- **播客倍速选择**：播客底部迷你控制条与独立全屏播客页均引入 `0.5×` 至 `3.0×` 丰富倍速菜单，带当前倍率指示；暂停状态调整倍速不会自动触发播放，切回普通音乐时自动保持原速。
- **播客探索与单集阅读排版**：重构播客探索页目录与榜单展示；优化单集正文章节识别与跳转锚点，安全过滤非信任脚本与外部图片。
- **首页与助手布局统一**：首页音乐助手与刷新按钮移至内容标题同侧，窄窗口自适应排版；助手整合顶部对话卡片与底部一体化输入卡片。

### CorePlayback 共享内核与网络提速

- **队列持久化保留**：为 `shutdown()` 和 `stopAndClear()` 增加 `preservingStoredQueue` 参数，支持切服与静默重置时保护磁盘队列。
- **流媒体预缓冲加速**：优化 `WildstringAudioResourceLoader` 预热策略，大幅降低首播起播等待延迟。
- **测试覆盖**：共享核心包测试增至 90 项全绿通过。

### Android 客户端体验优化

- **全屏播放器手势响应**：增强快速甩动手势（Quick Flicks）的拖动与回弹灵敏度，收拢迷你播放器动画打扰。
- **每日推荐（Daily Mix）聚焦**：优化推荐歌曲列表排版，修复从推荐页进入全屏播放器时丢失上下文批次队列的问题。
- **多语言与告警清理**：补齐中英文双语资源字符串（`strings.xml`），清理 Gradle/Kotlin 编译警告。

### Web 客户端与全面国际化

- **电台与播客界面材质升级**：重构播客电台与阅读布局样式（`podcast-player.css` / `podcast-stage.tsx`）。
- **发现页与推荐弹窗优化**：调优发现页栅格卡片与推荐反馈设置对话框。
- **中英文多语言对齐**：`locales/en.json` 与 `zh-CN.json` 扩充 380+ 项对照词条，覆盖 AI 助手、探索、设置与移动端；新增 `i18n.spec.ts` 自动化回归用例。

### 后端服务与 AI 助手

- **长连接保活**：本地与容器服务端 keep-alive 调整为 75 秒，优化高频切歌与轮询时的长连接复用率。
- **AI 助手双语与兜底**：AI 助手提示词、状态与会话支持中英文本地化以及英文兜底逻辑。

### 服务器线路、访问设置与曲目可用状态

- Mac、iOS 和 Android 支持本机别名、同一服务器的多条线路、自动回退与手动选线。各线路独立登录，切线保留曲库、队列与播放进度。
- Web 支持设置服务器名称和 HTTPS 访问策略，并可逐字段恢复环境配置。schema 48 首次升级保留旧策略。可信反向代理及配置优先级见 [服务器线路与 MCP 接入](../product/server-connections-and-mcp.md)。
- Web 提供四款客户端及通用 MCP 接入引导，生成的提示词和配置模板使用占位符。
- 四端显示缺失和不可读曲目，播放全部时跳过不可用项。恢复文件并重新扫描后沿用原曲目 ID、收藏及歌单位置。详见 [曲目可用状态契约](../../contracts/track-availability.md)。
- Mac 统一设置、添加服务器窗口及侧栏连接状态的布局，移除窗口硬分隔。

## 安装

- 后端、Web、Android、iOS 与 Mac 统一为 0.8.6。Android versionCode 为 42，正式 APK 沿用发布签名，可覆盖升级并与「野弦 Dev」共存；iOS／Mac 构建号为 41。
- 发布附件包含 Android APK、Mac DMG、Web ZIP、可选数据源插件、SHA-256 校验文件和 Android 发布签名证书指纹。容器镜像支持 linux/amd64 与 linux/arm64。
- Mac 最低系统为 macOS 14；当前 DMG 使用临时签名、未公证，首次打开可能需要在系统设置中允许。本次不提供 IPA 或 TestFlight。

## 验证边界

- 本版包含新增单元测试：CorePlayback 队列持久化断点用例、Mac 客户端服务器切换单测套件、Web i18n 双语自动化用例均已全绿通过。
- 发布门禁包括最终 main 提交的完整 CI、Android 构建及模拟器回归，以及 Release 流水线内正式签名、R8 优化 APK 的安装验证。结果以对应提交的 Actions 运行记录为准。
- 模拟器通过不等于真机后台、省电、来电／蓝牙、真实弱网或全部音频格式均已验收。发布不会自动升级个人音乐服务器。
