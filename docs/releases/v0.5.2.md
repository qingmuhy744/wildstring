# 0.5.2

本次整理 Web 与 Android 的日常使用界面，数据库仍为 schema 20。

- Web 账号设置和 Android 设置支持自定义头像、上传前预览及恢复默认头像，Android“我的”和 Web 账号入口同步显示。接受 JPG / PNG / WebP（最多 5 MiB、2500 万像素），服务端居中裁成 256 像素 JPEG 并移除 EXIF 等附带信息。头像保存在持久数据目录 `avatars/`，读取和修改均需本人登录，不改动音乐或数据库结构。

- 新建 AI 连接默认输出上限 8192 Token、推理强度 low、单次请求超时 90 秒。多个连接独立保存、选择和删除；已有连接的明确参数保留，保存不触发模型测试。low 是否生效仍由所选供应商和模型支持情况决定。
- 修复 Web 助手历史保留天数等表单在浅色主题下的输入背景与文字配色。
- 每日推荐采用紧凑临时歌单列表，收藏、不感兴趣和少推荐此艺人放进更多菜单。Web 支持右击、触屏长按和键盘，Android 支持长按；来源说明保留在折叠区域。
- Web 对话历史保留单行标题，将改名和删除收进三个点菜单；删除仍需确认，失败保留当前对话。
- Web 左栏按曲库、发现及折叠工具分组，管理与账号固定在底部；通知改为右上角铃铛与未读角标。
- Android“我的”保留最近听过、离线保存、收听统计和个人歌单；“发现”保留每日推荐、AI 找歌、发现新音乐三个入口。模型、联网、通知、跨设备进度及管理员的曲库和插件维护集中到设置，移除横向长入口条。
- 默认跨设备接续改为非模态小提示，不遮住页面、不抢焦点。仍需确认后才载入，并保持暂停；原有关闭和显式自动恢复选项保留。本机开始播放后收起旧提示。
- Android 同步歌词在停止手动操作后默认 2 秒恢复跟随，可在播放设置选择 1、2、3、5、10 秒。手指拖动和惯性滚动期间不计时，再次点选或滚动会重新计时；自动跟随不改变播放位置，跳转仍需确认。
- Android 歌曲操作面板由内部列表独立处理滚动，关闭列表边缘拉伸及面板拖动，避免快速滑动时两层手势联动；顶部提供关闭按钮，也可点遮罩或按返回关闭。
- 数据源插件的测试进度与结果显示在各自测试按钮附近；未保存的设置不能直接测试，停用与配置冲突分别给出提示，并在服务端保留脱敏错误码。
- AcoustID 区分 Application API Key 无效与普通网络错误，明确本机指纹由 Chromaprint 生成，无需额外密钥。网络检测未读音频时显示“本次未测试”，缺少分项时延时不再显示 NaN。

## 验证与边界

测试使用合成曲库和合成模型响应，覆盖多个连接的参数隔离、菜单与主题可读性、跨设备提示和歌词计时。未重发私人问题或自动重试外部模型；增加输出预算不保证所有问题都能在有限调用与时限内完成。

home 的旧兼容 AI 配置按用户本次要求单独移到私有备份，由用户手动添加新连接；发行版不自动删除其他实例的旧配置，也不会复制密钥或自动替用户选择付费模型。

APK、发布下载校验和 home 更新状态以实际流水线与部署记录分别核验。
