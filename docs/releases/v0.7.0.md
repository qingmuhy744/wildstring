# WildString / 野弦 0.7.0

本版是 WildString 的里程碑大版本更新，正式推出了自托管电台·播客完整生态系统、NAS/宿主机独立挂载与下载传输中心、专辑管理与实体文件重组织能力，并对 Web 端与 Android 端的信息架构与交互体验进行了全面重构。服务端、Web、Android 与 iOS 统一升级至 0.7.0。

## 主要变化

- **全新独立电台 · 播客生态系统（Podcasts & Subscriptions）**：
  - 将电台播客从曲库底层独立抽离为一级功能入口，支持标准 RSS 频道订阅与精选电台推荐。
  - **自动下载与宿主机独立挂载**：支持独立持久卷（`podcasts:/podcasts`）与环境变量 `WILDSTRING_PODCASTS_DIR`，音频以人机友好命名（`{YYYY-MM-DD} - {标题}.mp3`）及附带 `cover.jpg`、`podcast.json` 快照落盘，与 NAS/Plex/Jellyfin/Audiobookshelf 开箱即用；提供多档自动下载策略与收听完自动清理释放空间策略；支持本地秒播与服务端代理转发。
  - **下载队列与传输中心**：多 Worker 线程池并发管控；实时追踪瞬时下载速率（MB/s）与流式分块进度；精准捕获源站限流（HTTP 429）、防盗链（HTTP 403）、服务器过载（HTTP 503）与网络超时并转译为友好中文指引，页面绝不白屏崩溃，支持单集与全部失败重试。
  - **单集多维排序与即时搜索**：默认最近更新单集在最前，支持按发布时间、单集期号、时长、标题正反序切换；支持未听完与已存本地筛选，支持 400+ 单集即时搜索过滤；自动清洗简介中残留的富文本 HTML 标签。
- **专辑管理与实体文件重组织（Album Management & Organization）**：
  - 新增专辑右键/更多菜单与全屏编辑弹窗，支持修改专辑标题、艺人、年份与流派，支持在线元数据匹配补全。
  - 新增实体文件规范化重组织（File Reorganizer），支持基于标签对托管音乐文件进行重组织（`{Artist}/{Album}/{Track} - {Title}.{ext}`），并支持 Dry-run 预览与清理空目录。
  - 新增单曲文件底层信息诊断弹窗，可直接查看真实物理路径、音频编码格式、采样率、比特率与原始 ID3 标签快照。
- **Web 音乐上传器与曲库缺口发现**：
  - 支持浏览器端拖拽或批量上传音频文件至服务端并智能推断元数据。
  - 支持艺人唱片缺口分析与缺失专辑卡片补全建议。
- **Android 原生客户端体验重构（Android 0.7.0）**：
  - 发现页快捷入口重构为「收听排行」（单曲/专辑/艺人榜单），与底部「AI 助手」Tab 解耦。
  - 设置页单项配置直达独立界面。
  - 播客详情页同步支持最新优先与正反序切换及 HTML 清洗。
  - 彻底移除卡通悬浮形象。
- **Web 标签页状态记忆与细节打磨**：
  - 标签切换自动持久化同步，页面刷新精确保留在当前浏览标签页，不再跳回全部歌曲。
  - 移除了冗余的说明文字与副标题徽标。
- **版本对齐**：
  - 后端、Web、Android 与 iOS 版本统一提升为 0.7.0，Android versionCode 升级为 34。
