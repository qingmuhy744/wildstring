# WildString / 野弦 0.8.3

本版整理 Web 与 Android 设置，补齐 Mac 首页与桌面歌词，并改进播客探索、文件夹导入和 Apple 播放可靠性。

## 播客与 Web

- Web、Android、Mac 可以浏览 Apple Podcasts 区域热门榜，切换区域、搜索和预览 RSS。预览不写入服务器清单，明确关注后才添加或复用节目；普通账号沿用既有添加权限。
- 无人关注的节目停止定时更新，节目资料、单集、收听进度与手动保存继续保留。所有者在「管理中心 → 播客 → 共享音频管理」开启零引用音频自动清理并设置保留期；新实例默认关闭，有人保存、受保护或正在传输的文件会跳过。
- Web 侧栏集中内容入口；个人设置分为账号、外观、播放、下载、助手和关于，管理中心按音乐库、播客、数据源、权限、任务和服务器分层。切换设置保留当前播放与队列。
- 播客单集详情重新布局，正文独立滚动，支持下载原始 MP3、M4A 等音频到设备。下载沿用会话权限、Range 与本地文件租约，不转码、不创建个人保存引用。
- 探索页在页面内浏览，支持超时重试、窄屏布局和返回焦点；调整收音机螺丝、待播队列与服务器设置留白，移除歌词浏览辅助横线。

## Android 与 Mac

- Android 设置采用七个分类和二级页面，保留返回、旋转与语言切换后的所在位置；增加缓存容量选项，补齐发现页、播放、账号、下载和诊断等常用中英文。
- Android 发现页分别展示最近添加的专辑、歌曲和最近听过。AI 页暂停且未缓冲时收起迷你播放器，顶部入口可恢复当前播放器和原队列。
- Android 助手设置保留偏好与通知，聊天从 AI 页进入；资料、批量资料、封面、歌词与入库候选提示前往 Web 核对，歌单草案仍可预览和确认。
- Mac 登录后默认进入首页，展示推荐、继续收听、播客、最近添加与最近听过；艺人页首次默认显示专辑艺人，保留已保存的选择。
- Mac 桌面歌词可拖动，关闭后可从菜单重开并保留位置，按播放器偏好显示已有译文与音译；收窄歌词侧栏与全屏封面，修复底部、菜单栏及队列播客封面更新，让待播列表利用可用高度。
- iOS／Mac 共享播放内核使用毫秒级精确定位，修复连续跳转、切歌旧回调、准备或跳转期间暂停后意外恢复等问题；起播、缓冲与播客倍速交给 AVPlayer 的播放策略，音频会话激活失败可重试。

## 导入、数据库与插件

- Web 目录选择采用独立宽版窗口，来源、浏览、预览与实际导入范围一致。指定文件夹导入仅索引本次涉及的托管文件，常规扫描继续核对整库缺失，未变化文件批量更新扫描标记；原始导入源保持只读。
- 数据库从 schema 46 升级至 47，兼容补齐旧开发库缺失的登录尝试时间字段，保留已有账号、封禁状态、节目和收听记录，无需清库。升级前建议备份，升级后不要运行旧开发分支。
- 数据源插件源码继续保留在本仓库，通过 Web 手动导入 ZIP；新实例不默认安装，升级保留已有插件、配置、密钥和启用状态。
- 插件可使用薄 `adapter.py` 调用根目录或 `lib/` 内的 Nuitka 扩展，源码插件继续可用。原生扩展需匹配操作系统、架构与 Python ABI；本次实测 macOS ARM64／CPython 3.12，未验证 Linux／Windows 编译产物。

## 安装与验证边界

- 后端、Web、Android、iOS 与 Mac 统一为 0.8.3。Android versionCode 为 39，正式 APK 沿用发布签名，可覆盖升级并与「野弦 Dev」共存；iOS／Mac 构建号为 38。
- 发布附件包含 Android APK、Mac DMG、Web ZIP、可选数据源插件与 SHA-256 校验文件。容器包含后端、Web 与 FFmpeg，支持 linux/amd64 和 linux/arm64。
- Mac 最低系统保持 macOS 14。当前发布使用临时签名、未公证，首次打开可能需要在系统设置中允许；macOS 14 实机兼容性尚未验收。iOS 提供源码与模拟器构建检查，本次没有 IPA 或 TestFlight。
- 本地已验证隔离夹具上的数据库兼容、目录导入、播客探索／下载、Web 分层设置、Pixel 设置与助手、Apple 播放与桌面歌词；真实 Nuitka 编译、ZIP 安装、调用与升级回归通过。详细分批证据见[客户端与播客改进](../product/client-and-podcast-explore.md)和[Web 导航与设置](../product/web-navigation-and-settings-audit.md)。
- 发布门禁在最终 main 提交运行完整 Android 模拟器回归，通过后打标签；Release 再检查代码、后端、Web、容器与 Android 构建，并实际安装固定签名的 R8 正式 APK。最终结果以对应 main 提交和 v0.8.3 标签的 Actions 为准。
- 模拟器与合成音频测试不代表真机后台、省电、来电／蓝牙、真实弱网或全部音频格式均已验收。发布不会自动升级个人音乐服务器。
