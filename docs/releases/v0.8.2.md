# WildString / 野弦 0.8.2

本版加入原生 Mac 客户端，统一三端每日推荐的歌曲操作，并提供播客目录搜索、OPML 迁移和重复节目管理。

## 客户端与播放

- Mac 音乐全屏页支持封面取色、浅色／深色、居中歌词和逐字高亮；长歌词按栏宽折行并保留原始时间。逐字高亮需要歌词源提供字级时间，普通 LRC 仍按行高亮。
- Mac 播客使用独立页面，提供后退 15 秒、前进 30 秒、倍速、定时暂停、单集简介和章节跳转。队列按实际收听顺序展示，可拖动和上移／下移。
- Mac 菜单栏播放器显示封面、曲目与进度；桌面歌词入口再次点击即关闭，窗口只保留左上角关闭按钮。艺人与专辑可以直接跳转，浏览时保留播放。
- Mac 助手支持本地检索、已有模型连接、流式回复、对话历史和歌单草案预览／确认保存；其他资料草案的完整差异与应用继续在网页处理。Debug 会话使用独立本机开发存储，避免临时签名导致重启反复请求钥匙串权限；Release 继续使用钥匙串。
- Web、Android、Mac 每日推荐支持单曲菜单、多选、下一首播放、追加队列、加入已有／新建歌单和歌词预览。挑选歌曲时保留当前曲目、进度与暂停状态。
- Web、Android、iOS 增加首批中英文界面与账号语言同步；Android 助手排版更紧凑，长工具结果完整保留。

## 播客搜索与整理

- 网页添加节目时可按名称搜索 Apple Podcasts，默认并行查询美国、台湾和中国大陆目录并去重；RSS 地址可直接预览，确认后才添加并关注。
- 曲库管理员与所有者可调整搜索区域和成人内容过滤，回填已有节目的 Apple 编号，查看重复报告并合并已核实的重复节目。服务器选择保留的节目，合并关注、单集、进度与已下载文件。
- 启动约 3 分钟后自动回填一次缺少 Apple 编号的节目；与搜索共用限流额度，未找到的 7 天内不再重试，只补编号、不自动合并。可用 `WILDSTRING_PODCAST_IDENTITY_AUTO_BACKFILL=false` 关闭。
- 网页支持 OPML 预览、勾选与分批导入，以及个人关注导出；沿用现有权限和网络校验。安全 XML 解析拒绝实体声明，包括 UTF-16 编码中的实体扩展。
- 播客代理失败返回明确错误，不再跳转远程音频；补充上游、代理和 fake-IP DNS 的诊断提示。

## 升级与安装

- 数据库从 schema 42 升级到 46：账号语言为 43，播客标识、搜索配置和身份回填为 44–46。兼容两个开发分支曾使用的旧编号，保留既有账号、节目、单集及 ID，无需重建数据库；升级后不要切回旧开发分支。
- 后端、Web、Android、iOS 与 Mac 统一为 0.8.2。Android versionCode 为 38，正式包沿用发布签名，可覆盖升级并与「野弦 Dev」共存；iOS／Mac 构建号为 37。
- 附件包含 Android APK、Mac DMG、Web ZIP、数据源插件及 SHA-256 校验文件。容器镜像包含后端、Web 与 FFmpeg，支持 linux/amd64 和 linux/arm64。
- Mac 最低系统保持 macOS 14。本次未配置 Apple Developer ID 与公证凭据，DMG 使用临时签名、未公证；首次运行可能需要在系统设置中允许打开。macOS 14 实机兼容性尚未完成验收。
- iOS 已更新源码版本并通过模拟器构建；本次不提供 IPA 或 TestFlight 安装。

## 验证与边界

- 两批功能 PR 合并前均通过 13 项 GitHub 检查；合并后 main 的 CI、Android、macOS、iOS 与 CodeQL 检查通过。
- 本批本地 Pixel API 35 完整回归为 97 项通过、0 失败。Pixel 10 Pro API 37 的覆盖由首批 67 项及修复后的 2 项、28 项组成，属于分批回归，不是一轮完整 97 项成功。
- 修复 Pixel 测试的物理宽度假设及弹窗选择器，保留播放与布局断言；覆盖队列排序、主题与旋转时播放连续性、歌词、账号隔离和每日推荐选择。
- 发版门禁要求在最终 main 提交上手动运行完整模拟器回归；通过后才打标签。Release 再执行 CI、Android 构建／单元测试／Lint，并实际安装固定签名、R8 优化的正式 APK，检查连接页。最终结果以对应提交和标签的 Actions 为准。
- 日常完整设备回归在本地 Pixel 运行，日常 CI 保留构建、JVM 测试、Lint 和设备测试源码编译。模拟器通过不等于真机后台、省电与所有音频格式均已验收。
- Android 设置分层仍是规划，不属于本版已交付功能。发布不自动升级个人音乐服务器。
