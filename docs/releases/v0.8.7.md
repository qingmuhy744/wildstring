# WildString / 野弦 0.8.7

本版重点推出了 macOS 全屏播放器毛玻璃抽屉式待播队列（对齐 Apple Music 原生体验）、macOS 远程大码率音频卡顿缓冲修复与紧凑导航打磨，全平台统一专辑封面继承与回退机制，增强了多服务器与线路自定义管理（重命名与彻底删除），并在 Android 客户端引入了崩溃日志收集与诊断导出系统，同时对齐了各端播客轻量级续播体验。

## 相对 0.8.6

### macOS 全屏播放器抽屉式待播队列
- **解绑歌词与队列互斥关系**：右上角「歌词」与「队列」改为独立 Toggle 按钮，播放音乐时歌词默认保持连贯滚动。
- **原生毛玻璃抽屉面板**：点击「队列」时，右侧以 Spring 弹簧动画滑出 `.ultraThinMaterial` 毛玻璃队列抽屉。
- **宽屏智能让位**：在宽屏（≥ 1050pt）下，主舞台（封面与歌词）平滑向左让位，实现「封面 + 动态滚动歌词 + 待播队列」三者同屏呈现且零遮挡。
- **便捷退出与全功能队列**：抽屉内嵌「定位当前播放（scope）」与「✕ 关闭（Esc）」按钮，支持拖拽调序、双击切歌及上下文菜单；紧凑屏幕支持轻触背景收起。
- **播客专属视图**：播客模式自动在主舞台直接呈现节目选集队列，不展示多余的歌词开关。

### macOS 播放与性能优化
- **远程 FLAC 流媒体缓冲修复**：修复 `automaticallyWaitsToMinimizeStalling` 导致的远程大码率 FLAC 流媒体缓冲暂停问题。
- **导航视觉打磨**：专辑与目录详情页引入紧凑型回退按钮（`chevron.backward`），优化目录层级切换视觉体验。

### 全平台专辑封面继承与回退强化
- **曲目封面智能继承**：Track 优先使用自身内嵌封面，无自身封面时自动继承所属专辑封面并优雅回退占位符；macOS、iOS、Android 与 Web 四端统一步调。

### 多服务器与线路管理强化
- **线路重命名**：macOS、iOS、Android 客户端支持为服务器线路设置自定义友好名称。
- **彻底删除与安全回退**：支持删除失效线路与整机服务器，安全清理本地凭据并在删除活跃服务器时自动平滑回退至可用服务器。

### Android 客户端稳定性与播客交互体验对齐
- **崩溃日志收集与诊断**：新增全局未捕获异常崩溃日志收集（`CrashHandler`），本地自动轮转保留最新 10 条日志，提供崩溃提醒弹窗、诊断查看与剪贴板一键导出。
- **播客继续播放轻量化**：移除阻塞式模态进度选择弹窗，默认自动续播；当前曲目本地恢复播放即时响应，远端冲突改为轻量级警告条提示。
