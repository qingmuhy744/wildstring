# WildString / 野弦 0.8.15

本版是面向 0.8.14 的小版本，修复 Android 下滑收起全屏播放器时的闪退，并打磨平板探索页与播客播放器入口。GitHub Release 开始附带对应正式包的 R8 混淆映射。

本版不增加新的服务端不兼容。数据库 schema 仍为 52。**0.8.12 及更早的客户端依然无法正确对接 0.8.13 及更新的服务器**（`/podcasts/inbox` 已在 0.8.13 移除），须使用 0.8.13 或更新的客户端。

## 相对 0.8.14

### Android 收起播放器闪退
- 下滑收起全屏播放器时，偶发 Compose 断言失败：`onReuse is only expected on attached node`，应用直接退出。根因是打开播放器时，用 `movableContentOf` 把背后的曲库或设置（含 LazyColumn，可能正处于可暂停预加载）整棵搬到播放器垫层，收起时再搬回原位；Compose Foundation 1.12 默认重新打开可暂停预加载后，预加载可能在节点已脱离时调用 `LayoutNode.onReuse`。
- 曲库与设置始终留在同一个组合槽位，播放器改为覆盖层：收起只平移并移除播放器，下滑露出底下页面的手感保持不变。`movableContentOf` 仍用于设置与曲库之间的切换。
- 作为兜底，在 `WildStringApplication` 关闭 `ComposeFoundationFlags.isPausableCompositionInPrefetchEnabled`，并在 R8 规则中用 `-assumevalues` 固定该值，避免正式包把默认 `true` 常量折叠掉。新增 `PlayerDismissCompositionTest` 反复打开／收起该覆盖层结构。

### 平板探索与播客播放器
- 探索页热门榜标题在加载时保留当前区域名（如「台湾」），没有区域信息时不再留下悬空的「·」；宽屏加载条改为与其他页面一致的骨架屏；右栏补上「选择一个节目」标题，两栏顶部对齐。
- 「已关注」按钮按当前语言下最宽的状态文案（关注节目／已关注／已关注 · 队尾／已关注 · 最前等）固定最小宽度，切换状态时旁边的播放与待播按钮不再跳动。
- 播放器左侧节目名和右上角橙色节目名可点击：先收起播放器，等覆盖层退出动画结束后再打开节目详情；作者名仍为普通文字。
- 播放器顶栏补上与音乐播放器一致的单集收藏红心：点按立即更新，保存失败自动恢复并提示。后端接口与 iOS／macOS 播放器此前已支持收藏。
- 待播列表横幅去掉多余的「· 点击查看」，只保留「共 N 集待播」，整张卡片仍可点击。

### 发布产物
- 正式 GitHub Release 增加 `wildstring-X.Y.Z-mapping.txt`（R8 混淆映射）并计入 `SHA256SUMS`，便于还原后续正式包崩溃堆栈。调试包不受影响。

## 验证
- 发版准备本地检查：`python3 scripts/package_release.py --tag v0.8.15 --check-only` 通过；Android 单元测试 157 项、instrumented 测试编译与 Lint 通过。本版无后端或 Web 代码变更。
- GitHub Actions：PR 须跑通 **CI**（后端全量 pytest、Web 端到端测试、容器构建与冒烟、代码质量）、**Android APK**、**iOS Build**、**macOS Build**、**CodeQL** 与依赖审查。合并进入 main 后，再手动运行开启 `run_emulator` 的 **Android APK** 完整模拟器回归（含新增的 `PlayerDismissCompositionTest`）。
- 发布由 GitHub Actions **Release** 工作流完成：核对标签与三端版本及 `main` 祖先关系、重跑完整 CI 与 Android 模拟器回归、构建固定签名 R8 正式 APK 并做模拟器安装冒烟、打包 macOS DMG 与数据源插件 ZIP、推送双架构 GHCR 镜像并生成 GitHub Release（含 mapping 文件）。

## 尚未覆盖的验证
- 未在物理折叠屏、平板或 iPhone／Mac 真机上检查；窗口尺寸模拟无法验证铰链遮挡与实际折叠行为。
- 新增的 `PlayerDismissCompositionTest` 等 instrumented 用例将在发版前的模拟器回归中执行，发版准备时未在本地模拟器运行。
- 下滑收起闪退依赖时序，很难稳定复现；修复针对已确认的组合结构与官方已知的可暂停预加载问题，但不能用单一用例穷尽所有列表场景。

## 已知限制
- 0.8.12 及更早客户端仍不能对接本版服务器，须使用 0.8.13 或更新的客户端。
- 关闭可暂停预加载可能使快速滚动时的预组合略多一些开销。
- Android 播客播放页「AI 导读」标签仍为即将推出占位。
