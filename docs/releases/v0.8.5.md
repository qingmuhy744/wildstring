# WildString / 野弦 0.8.5

本版深度修复了专辑元数据修改后的封面上传链路，新增播客共享音频零引用待清理清单弹窗预览，优化 Apple 原生播放内核对远程流总时长的动态监听，全面打磨任务管理与下载卡片在深浅双色主题下的视觉质感，并完成了全量 GitHub Wiki 文档刷新与依赖加固。

## 相对 0.8.4

### 专辑元数据与封面管理

- 修复在 Web 端编辑专辑信息（如专辑标题、专辑艺人）后立即上传或删除封面报 404（`所属专辑已变化或不可用，请刷新曲库后重试`）的链路问题。
- 后端 `update_metadata_album` 现在准确计算并返回曲目在重新计算 `album_key` 后迁移到的最新 `album_id`。
- Web 端专辑编辑弹窗与封面上传、删除接口无缝对接返回的最新 ID，并在保存后自动定位并刷新最新专辑视图。
- 移除了在解析艺人为空时向后端兜底提交 `未知艺人` 的隐式行为，严格尊重用户的原始输入与编辑意图。

### 播客与存储空间管理

- 在「管理中心 → 播客 → 共享音频管理」中新增“查看待清理清单”宽框弹窗。
- 在执行物理空间回收之前，用户可清晰查看所有零引用待清理候选的详细信息：包含单集标题、所属节目、相对存储路径以及实际磁盘占用体积。
- 弹窗针对桌面宽屏与移动端窄屏进行了自适应布局优化，支持点击遮罩层或使用 Escape 键一键退出。

### Apple 原生播放内核与播放体验

- 优化 iOS 与 macOS 原生播放内核（WildStringKit）的时长监听机制：在监听 `AVPlayerItem.status == .readyToPlay` 时动态核验并刷新音频总时长，彻底解决远程流媒体或部分编码格式起播时总时长识别为 0 的问题。
- 修复歌词行点击首次精准跳转（Seek），保持单轨连续播放。
- Web 顶部 Brand Logo 统一采用客户端无刷新平滑路由，防止在浏览过程中意外切歌或中断背景播放。

### 视觉与界面打磨

- 重构任务列表与下载卡片配色体系，解决浅色模式下暗色背景文字对比度偏低及深色模式下的反色问题，呈现温润、通透的高品质视觉质感。
- 播客收音机复古金属旋钮与调谐指示器细节微调。

### 文档、Wiki 与生态建设

- GitHub Wiki 全量修订并推送到 Wiki 仓库，通过自动化测试管道捕获并更新了全套 10 张高分辨率 Web 客户端界面截图。
- README 全面支持中英双语，上线全新宽幅摇滚视觉 Banner，新增 Google Gemini 与 DeepSeek 官方矢量 Logo 及真挚技术致谢，明确了基于 Tauri + Rust 跨平台桌面端长期路线图。

### 依赖升级与流水线加固

- 升级核心依赖组件：FastAPI 0.162.0, pydantic-settings 2.16.2, pytest 9.2.0, ruff 0.17.3, axios 1.21.0, pako 3.0.3，同步校验并刷新了 Nuitka / Node 数据源插件。
- 升级 GitHub Actions 流水线动作：setup-gradle@v6.4.1, setup-uv@v10.3.3, docker/login-action@v4.7.0。
- 依赖机器人（Dependabot）提出的开放升级请求均已验证并合并处理。

## 安装

- 后端、Web、Android、iOS 与 Mac 统一为 0.8.5。Android versionCode 为 41，正式 APK 沿用发布签名，可覆盖升级并与「野弦 Dev」共存；iOS／Mac 构建号为 40。
- 发布附件包含 Android APK、Mac DMG、Web ZIP、可选数据源插件、SHA-256 校验文件和 Android 发布签名证书指纹。容器镜像支持 linux/amd64 与 linux/arm64。
- Mac 最低系统为 macOS 14；当前 DMG 使用临时签名、未公证，首次打开可能需要在系统设置中允许。本次不提供 IPA 或 TestFlight。

## 验证边界

- 本版包含新增单元测试：后端专辑管理与重算 ID 校验用例、Web 专辑编辑器端到端 Playwright 自动化用例均已全绿通过。
- 本版在最终 main 提交重新执行完整 CI、Android 构建与模拟器门禁，并在 Release 中实际安装固定签名、R8 优化的 APK。
- 模拟器通过不等于真机后台、省电、来电／蓝牙、真实弱网或全部音频格式均已验收。发布不会自动升级个人音乐服务器。
