# 野弦 0.3.2

本版补齐从歌曲查看所属专辑的入口，并统一歌曲操作菜单的图标与视觉对齐。

## 查看所属专辑

- Web 与 Android 歌曲操作菜单增加“查看所属专辑”，全屏播放器的专辑名可直接点击；网页桌面歌曲列表的专辑列也提供入口。
- 按歌曲的专辑 ID 打开完整专辑，清除原艺人、歌单及搜索限制，避免同名专辑混淆。艺人页面原有的专辑卡片仍保留艺人筛选。
- 跳转保持当前播放、进度与队列；Android 返回可回到原浏览页。历史 Android 队列缺少专辑 ID 时，先按歌曲 ID 读取信息。
- 专辑读取失败时提供提示；网页保留原页面，全屏播放器内也可看到加载与错误反馈。

## 图标与界面

- 网页歌曲操作使用统一线条图标，专辑入口增加唱片与方向提示；收藏和更多按钮统一尺寸与中心，菜单图标、文字及歌单选择框按固定位置对齐。
- Android 歌曲操作采用原生图标列表，顶部显示曲名、艺人和封面，浏览、播放与管理操作分组；播放页专辑入口与顶部控件对齐。
- 检查桌面、手机、横屏及深浅色布局；图标由 SVG / Android 原生矢量绘制，不增加图片资源或外部请求。

## 升级与验证

服务端数据库保持 schema 15，没有新增迁移。歌曲、收藏、歌单及 Last.fm 配置沿用现有数据；本版不修改音乐标签或导入源。

Android 正式包使用既有发布签名，versionCode 递增到 9，可覆盖 0.3.1；0.3.1 用户可在应用内检查更新，也可从本页下载 APK 后确认安装。

本地验证覆盖专辑定位、完整专辑、失败提示及播放连续性；PR 与 Release 工作流继续执行后端、网页、容器、Android Lint / 单元测试 / 模拟器与正式包安装检查。最终构建与发布状态以对应工作流为准，不以文档代替执行结果。
