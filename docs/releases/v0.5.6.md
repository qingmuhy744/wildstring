# WildString / 野弦 0.5.6

本版增加列表中的当前播放标识，并收录 0.5.5 之后的兼容依赖维护。数据库继续使用 schema21。

## 改进

- Web 与 Android 的歌单、我喜欢、每日推荐和播放队列增加当前歌曲高亮、标题强调和小音柱，可直接看出正在播放哪首歌。
- 标识跟随真实播放状态：播放时轻微律动，暂停与缓冲时保持静态；切到后台或系统减少动态效果时停止动画。音柱用于提示播放状态，不表示实测频谱。
- 队列按具体条目定位，同一首歌重复加入时只标记当前条目；切歌、暂停、拖动排序与原有播放操作保持一致。
- 更新 TypeScript 7、Android Gradle Plugin 9.4.1／Gradle 9.8.1、Android Core 1.19.1、OkHttp 5.5.0 和 setup-uv；锁文件、Gradle 校验与上游来源记录同步维护，Node 类型声明继续匹配 Node 22。
- 酷狗独立 ZIP 插件升级至 1.1.3，更新歌词解压依赖 Pako 3.0.2，并补充中英文 KRC 兼容测试。QQ 音乐和网易云插件继续为 1.1.1。
- 改进 Android 回归测试对键盘生命周期、歌单编辑、歌词扫描初始加载与窗口焦点的等待；草案审批在延迟响应下等待实际界面结果及操作可用，保留版本、权限和单次应用校验。

## 验证

播放标识已在 Web 桌面／手机、Android 真实 API 与 Media3 播放测试中核对，覆盖歌单、收藏、每日推荐、重复队列以及播放／暂停状态；人工截图比较确认播放时音柱变化、暂停时静止。

版本提交与正式标签继续执行完整 CI、隔离容器后端测试、Web 浏览器测试、Android JVM 与完整模拟器回归、Lint 和 R8。发布流水线检查固定签名 APK 的安装启动，并构建 Web ZIP、独立插件 ZIP 和 amd64／arm64 容器。下载产物的版本、校验和、签名与镜像摘要分别核验，实际发布状态以 Release 为准。

## 升级

请升级服务端和 Android，网页随服务端镜像更新。Android versionCode 为 20，沿用现有正式签名，可覆盖升级。本次没有数据库迁移；升级前备份数据库、私有配置与已安装插件。

独立导入的酷狗插件需另外导入本次 Release 附带的 1.1.3 ZIP；服务端升级不会自动替换实例中安装的插件。旧版发布资产保持原样。

本次不导入、移动或写回音乐文件。GitHub 发版与 home 实例更新分别验收，本次不自动更新远程实例；第三方来源可用性与手机厂商后台行为仍需结合实际环境核对。
