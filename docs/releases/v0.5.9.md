# 0.5.9：自动整理与专辑批量核对

可按账号选择人工审核或自动整理，并分别选择歌单、元数据、导入、歌词、封面和专辑批量修改的自动应用范围。默认保持人工审核；新设置不追溯应用已有草案。MCP 凭据仍需相应权限，模型不能替用户开启自动应用。自动失败会保留草案及原因。

Web 与 Android 的“接受并应用”在同一事务完成批准和应用，无需点两次。旧客户端的批准／应用接口继续兼容，版本校验、来源检查、幂等和审计沿用同一业务服务。

新增专辑批量核对工作台，入口位于曲库管理或歌曲联网建议：

- 按专辑查看歌曲，当前值、建议值、来源并排比较；手机使用紧凑字段卡片。
- 默认只展示变化，人工覆盖字段默认不勾选；可查看文件原始值及匹配依据，切换来源。
- 按歌曲或同字段选择，本页批量接受，也可接受本曲并下一首，或本次跳过。
- 封面先下载并固定为内容快照，显示成功后才能应用；可用于本页同专辑歌曲，与所选文字资料在同一事务提交。
- 同屏进入已有在线歌词候选预览，保留双语、逐字时间与来源。
- 固定底部操作区显示选择数量；Web 支持 Ctrl／Cmd + Enter；大专辑每页最多 500 首。

候选摘要与歌曲版本由服务端核验。任一冲突使整批保持原值，失败重试复用同一幂等键。仅修改数据库及已选封面；导入源和音乐文件不写回。

数据库仍为 schema22，无新增迁移。服务端／Web／Android 版本统一为 0.5.9，Android versionCode23。自动整理需要用户在设置中主动选择，不会在升级时默认开启。

验证覆盖后端原有业务、自动应用权限及撤销、批量选择和候选过期、封面与文字一起回滚、重复提交；Web 在桌面和手机尺寸回归，Android 使用 API35 模拟器验证。最终流水线与发布产物验证以对应 Actions 运行结果为准。
