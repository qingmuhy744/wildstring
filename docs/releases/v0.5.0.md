# 野弦 0.5.0

聊天可以通过用户配置的官方搜索服务核对库外最新发行与音乐资料，并展示可点击来源。长对话支持上下文摘要，长期记忆支持用户明确保存、编辑、删除。本版合并原计划 0.4.1 的手动 AI 巡检、历史对话管理与本地检索提示修复。

## 助手与联网

- 模型连接支持 Chat Completions / Responses，供应商档案处理推理参数与工具续接状态。已有连接与密钥无需重填，也不会自动更换模型或开启付费搜索。
- Web 设置和 Android 助手新增“联网与记忆”：可选 DeepSeek 官方 Search / Fetch 或 Tavily，独立配置密钥与每日请求上限。默认关闭；每轮最多四次搜索/正文读取，同一结果缓存15分钟。
- 搜索结果和正文分别处理，正文仅可按本轮来源 ID 读取。标题、有效 URL、来源日期及检索时间随回答保存；结果不会冒充本地可播放曲目或完整发行列表。
- Responses 可选择模型原生 web_search（OpenAI / DeepSeek Pro / 千问，仍受具体模型和账号限制）；一次模型请求可能包含多次搜索，独立搜索额度不限制这部分费用。
- 连接检测分别报告文本、合成 JSON、工具调用与工具回传闭环。合成 JSON 成功不代表服务支持 JSON Schema，原生联网能力保留未验证状态。

## 上下文与记忆

- 长对话在本轮预算内用一次模型调用摘要较早内容，并保留最终回复预算；摘要可查看、清除或关闭，是有损上下文，不保证保留全部原文。
- 长期记忆只保存用户明确提交的音乐偏好，按用户隔离，每人最多50条；模型不会自行推断保存，用户可关闭使用或逐条编辑、删除。删除对话仍保留独立记忆。
- 记忆、摘要和外部网页均不授予额外业务权限；元数据与歌单修改继续先生成草案，由用户在站内确认。

## 同批修复

Android、Web 与服务端同步修复手动 AI 巡检选择已有实例连接的问题。提交仅授权本次任务，定时计划和工具提交仍要求自动使用授权。历史列表支持逐条改名、删除；本地关键词检索明确标识未调用模型。

## 升级与验证

请同时升级服务端与 Android App；网页随服务端更新。Android versionCode 为14，正式包沿用现有签名。数据库迁移至 schema 19；升级前备份 SQLite、私有配置和 agent-secrets，回滚需恢复相应备份。升级不会导入、移动或写回音乐文件。

本批使用合成曲库与供应商响应验证兼容、来源、权限、预算、摘要、记忆及迁移，真实供应商账号和实际中文检索覆盖率需单独检测。没有通过真实账号调用的能力不作为已验证交付。

验证入口：`make test-research`、`make ci`、`make android-ci`、`make docker-up docker-smoke`。正式发布流水线检查签名 APK 安装启动、Web ZIP 校验，以及 amd64 / arm64 镜像。发布产物和实际检查结果另行核验。

本地已通过 `make ci`（后端349项、网页192项及独立大曲库／浏览检查；本机缺少 FFmpeg 的15项后端检查跳过）、Android 构建／单元测试／Lint，以及隔离数据卷的 Docker smoke。联网与记忆另有桌面／手机网页4项交互回归；供应商请求由合成响应验证，不消耗真实搜索额度。远端完整检查与发布产物以对应流水线为准。

详细边界见[联网检索与助手记忆](../architecture/assistant-research.md)。
