# WildString / 野弦 0.5.14

本版集中收口客户端播放反馈和元数据整理可靠性，并将 Web 的文件夹批量编辑接入现有版本化元数据流程。

- Android 播放页支持左右滑动切歌、向下滑动收起播放页；封面预览支持双指缩放和拖动。
- Android 的双语歌词以中文行在上、原文行在下展示；发现、曲库、歌词、核对和助手页面在等待网络时显示低动态骨架或进度反馈。
- 元数据候选保存查询输入快照。封面、流派和简介等无关修改不会使候选整体过期；标题、艺人、专辑、时长或外部标识变化时明确提示重新查询。
- 强制元数据刷新会升级同一条排队任务；正在运行的旧任务会保存刷新意图，结束后自动接续当前版本，避免出现“已点击刷新但没有新查询任务”。
- Web 曲库管理增加按托管文件夹批量统一专辑名称和专辑艺人的入口，应用前显示版本和冲突提示，每首歌曲继续保留历史版本。
- 数据库迁移至 schema 26；后端、Web、Android 与 iOS 版本统一为 0.5.14，Android versionCode 28。

## 验证边界

- Web TypeScript 类型检查与生产构建通过。
- Python Ruff、候选/刷新/迁移相关回归通过；完整测试中的本地 socket 绑定用例受当前受限环境阻止，未将该环境限制误报为产品失败。
- Android Debug 编译、单元测试与 Lint 需在本机 SDK 环境完成；本次没有可用的 Android 真机/模拟器时，连接设备回归不纳入通过结论。
- iOS 继续使用 0.5.13 已验证的播放基础；本版只更新统一版本号，未声称新增 iOS 行为已由真机验证。
- 发布部署只备份 API 服务数据、SQLite、私有配置和插件状态，不备份或修改导入源及音乐文件。
