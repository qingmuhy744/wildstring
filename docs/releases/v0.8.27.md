# WildString / 野弦 0.8.27

本版改进 Web 专辑歌词与资料整理，修复 Android 封面预览拖动，并更新 iPhone、iPad 和 macOS 的播放与播客体验。

## 已实现

- Web 专辑菜单可批量查找歌词。候选支持试听和时间偏移，可选择歌曲并应用。底栏可打开当前艺人和专辑，长弹窗滚动时可以直接关闭。
- Web「整理」集中显示待确认资料和曲库检查。应用或拒绝资料后会更新待确认数并切到下一首。封面只有确认应用后才进处理记录。
- 曲库可检查最近入库的歌曲，或在后台分批检查整库。页面显示实际进度，按问题列出歌曲并可打开对应专辑。
- Android 放大封面后横向和纵向拖动都跟随手指。从歌词返回黑胶封面时唱针直接就位。通知页用三弦图标提示标记已读和刷新，等待时保留通知列表，失败就地提示。收听统计增加累计时长和带封面的常听歌曲。
- 库外推荐识别曲库里已有的版本。「想听」支持按专辑版本选择播放。
- iPhone 短横屏保留播放、进度和队列控件。iPad 宽窗支持歌词或文章与队列并排。移动端新增曲库多选、批量离线保存、规则歌单、专辑编辑、在线歌词候选、播客出品方、全局单集收藏和更多个人设置。
- iPhone、iPad 和 macOS 的播客续播偏好即时生效，保存失败可按节目重试。Apple 端助手可管理音乐偏好。
- 更新 GitHub Actions、后端 Python 和 Web 依赖。发布工作流可独立重试稳定渠道同步。

## 版本与升级

- 后端、Web、Android、macOS 和 iOS 均为 `0.8.27`。Android versionCode 为 `63`，Apple 构建号为 `62`。
- 数据库 schema 为 `55`，数据源插件使用 API v2。从 `0.8.24` 或更早版本升级时，曾使用 v1 插件的用户请查看插件重新导入和配置说明。[0.8.25 升级说明](v0.8.25.md#版本与升级)

## 验证

- Web 已在合成曲库核对桌面和 390px 手机宽度的浅深主题、资料核对、封面预览和检查结果。
- Android 已在手机和平板模拟器核对歌曲与播客的封面预览，并用像素位移回归复现旧版拖动差距。
- iPhone 与 iPad 已验证模拟器交互。真机安装、锁屏、外部 AirPlay 接收器和 iPad 系统分屏留待后续统一核对。
