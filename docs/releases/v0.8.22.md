# WildString / 野弦 0.8.22

本版修复 Android 批量保存离线音乐时的界面无响应，并在歌曲列表支持原地多选。服务器 API 和数据库 schema 保持兼容。0.8.21 标签在歌曲菜单设备测试中失败，未生成正式 Release。0.8.22 承接同一批功能，设备测试会滚动到「编辑歌曲信息」再验证入口可见。

## 已实现

- 手动下载和自动离线歌单在后台提交队列，每批只读取一次新任务的音质设置。撤回曲库权限时批量清理离线项，AAC 音源校验失败后继续处理后面的歌曲。
- 长按歌曲或从单曲菜单进入原地多选。字母索引和滚动位置保留，可将已选歌曲加入歌单或离线保存。
- 一次手动操作实际新增或恢复超过 100 首时先显示数量并要求确认，取消保留勾选和位置。

## 版本与升级

- 后端、Web、Android、macOS 和 iOS 为 `0.8.22`。Android versionCode 为 `58`，Apple 构建号为 `57`。
- 数据库 schema 仍为 `54`。Android 的本批功能可连接现有 0.8.20 服务。
- Android 正式包沿用发布签名，可覆盖升级。iOS 不提供签名 IPA 或 TestFlight 附件。

## 验证

- [PR #171](https://github.com/qingmuhy744/wildstring/pull/171) 通过 GitHub 检查。用户已完成 Android Dev 包验收。
- 本地通过 200 项 Android JVM 测试、Lint 和 11 项连续曲库设备测试。手机和平板核对了浅深主题、歌曲行位置、加入歌单和下载确认。
- 1,698 首合成曲库测试中，主线程最长采样间隔由约 1.34 秒降为 240 毫秒，播放中的播客继续前进。两项中文输入用例在同一模拟器的修改前后均有失败，保留为本地验证缺口。
- 正式发布工作流继续执行 Android 全量设备回归及 R8 正式包安装冒烟。签名、分发产物和最终结果以 [0.8.22 Release](https://github.com/qingmuhy744/wildstring/releases/tag/v0.8.22) 及对应 Actions 为准。
