# WildString / 野弦 0.8.11

本版是面向 0.8.10 的小版本，合入 PR #108：Android 新增手机／平板（Phone／Pad）自适应布局，修复 Android 封面冷加载在无系统网络时间歇性超时，播客待播列表四端统一可见拖动手柄与落位反馈，Web 元数据任务合并为单一队列，并调整 Web 播客网格与 Android 模拟器 CI 资源配置。

## 相对 0.8.10

### Android 手机／平板自适应布局
- **按可用窗口尺寸分档**：平板与展开的折叠屏使用 Pad 布局；手机、折叠状态的折叠屏与窄分屏窗口使用 Phone 布局。手机旋转不会切换导航模式。
- **跨模式保留状态**：导航、播放、选择与页面状态在两种模式间共享；调整窗口大小或离开再返回页面时，保留目录与单集列表滚动锚点、选中的播客与对话、聊天草稿以及消息滚动位置。
- **Pad 布局**：使用侧边导航栏（navigation rail）；目录与搜索以艺人、歌单网格展示，足够宽的曲目列表显示艺人、专辑与等宽时长列；较宽窗口下播客订阅与单集详情、对话历史与聊天并排显示，宽 Pad 窗口的设置页为双栏；较窄窗口保留 Phone 的层级布局。
- 保留触控目标尺寸与安全区，阅读区限制在舒适的最大宽度；宽屏播放器的待播队列仍为浮动面板，不挤动歌词舞台。

### Android 封面加载修复
- **修复封面氛围间歇性超时**：Android 可能在没有已注册互联网网络的情况下仍能访问本地服务器，此时 Coil 的网络监听会把冷启动图片请求切换为仅读缓存，OkHttp 返回 HTTP 504。现对共享的音乐与播客图片加载器关闭 Coil 的 Android 网络监听，继续使用现有 HTTP 客户端与私有缓存，不增加重试、不延长界面超时。
- 新增仪器测试：关闭 Wi-Fi 与移动数据、确认无已注册网络后，从回环测试服务器冷加载图片。

### 播客待播与元数据队列
- **待播拖动手柄**：Android 与 iOS 待播列表常驻显示拖动手柄，拖动过程中仅在本地暂存顺序，松手后一次写回；Android 音乐与播客队列按行标识共享拖动状态，iOS 在落位成功后给出选择反馈（触感）。
- **元数据任务单一队列**：后端任务列表新增合并的 `queue` 视图（合并待确认与需关注两类，按曲目去重计数，并作为默认视图），归档行为明确并保留历史；Web 元数据任务页改为单一队列，支持批量选择与应用，并逐行处理失败。

### Web 与 CI
- Web 播客网格在宽屏下拉伸铺满，待播队列行对齐为四列；播客投递规则支持批量选择。
- Android 定时／手动模拟器完整回归与 Release 正式包模拟器冒烟改为分配 2 核 CPU 与 4 GB 内存；普通 push 与 PR 的 Android 任务仍只构建、Lint 并运行 JVM 单测，不启动模拟器。

## 尚未覆盖的验证
- 本版未在物理折叠屏或平板真机上检查；窗口尺寸模拟无法验证铰链遮挡与实际折叠行为。
- 新的 2 核／4 GB 模拟器配置在合入前尚未经过远程 CI 实测；普通 push／PR 任务按设计不运行模拟器测试。

## 已知限制
- Android 播客播放页「AI 导读」标签仍为即将推出占位，本版不包含语音转写或摘要生成。
- `podcasts.slow_download` 列沿用建表语句与运行时 `ALTER TABLE` 补齐，`SCHEMA_VERSION` 保持 50。
