# WildString / 野弦 0.5.16（本地草稿，未发布）

本批把曲库浏览和管理权限拆得更清楚：Web 继续承担精确校对，客户端和 MCP 复用同一套服务端权限；音乐源仍只读，删除先进入可恢复回收区。

- Web 歌曲列表和专辑卡片中的艺人名称可点击，按名称定位真实艺人后进入艺人页；歌曲播放按钮与艺人入口分开，避免误触播放。
- Web 播放队列改为明确的上移／下移按钮，队列打开时点击面板外的空白区域即可收起；移动端继续保留更适合触控的手势方向。
- 账号增加四种资料档案：所有者、曲库管理员、资料编辑员、听众。旧的 `admin`／`user` 字段继续兼容，MCP、Agent 和管理 API 都按档案能力校验。
- 管理端提供只读导入源的来源和目录浏览、导入预览及按当前文件夹提交导入任务；目录条目会标出 `.part` 等未完成下载，预览不会把未完成文件列为可导入内容。
- 专辑安全删除先把托管副本移入带清单的回收区，保留曲目 ID 和元数据历史；曲库管理员可以恢复，只有所有者可以永久清理。导入源不参与移动或删除。
- 元数据候选中心区分“重新读取”和“重新查询”：歌曲信息或查询依据变化的旧候选会明确标为不可应用，待确认／需处理任务可直接进入核对结果；批量核对弹窗扩大桌面宽度，避免来源列表和差异表过窄。
- 元数据任务支持安全清空等待队列，只取消尚未开始的查询；正在查询、已有候选、历史和需处理记录均保留。取消记录进入历史，不伪装成来源失败。
- 数据库升级到 schema 29，新增档案字段、导入任务路径和回收区清单；旧数据库会自动迁移，现有 `role` 语义保持兼容。
