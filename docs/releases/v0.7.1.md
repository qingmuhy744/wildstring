# WildString / 野弦 0.7.1

本版修复客户端连接地址输入体验：用户可以直接填写域名、IP 或带端口的地址，省略协议时客户端自动补全为 `https://`；需要使用明文 HTTP 时仍必须显式填写 `http://` 并确认风险。

## 主要变化

- Android 服务器地址规范化接受省略协议的输入，默认使用 HTTPS。
- iOS 连接页同步更新提示，并保留既有 HTTP 风险确认与按服务器授权策略。
- Android 添加服务器、连接页和文档说明统一使用无协议示例。
- 后端、Web、Android 与 iOS 版本统一为 0.7.1，Android versionCode 为 35，iOS build number 为 34。

## 验证情况

- Android 单元测试与 AndroidTest 编译通过。
- Android Debug Lint 通过。
- iOS `make ios-test` 通过，CoreNetwork 地址规范化测试通过。
- 既有后端、Web、容器与 PR #64 CI 已通过；本版发布提交会重新触发完整流水线。

## 安全边界

- 缺少协议时只默认使用 HTTPS，不会静默把地址降级为 HTTP。
- HTTP 连接仍需用户显式填写 `http://` 并确认未加密传输风险。
