# WildString / 野弦 0.5.5

本版集中维护安全与稳定性，数据库继续使用 schema21。

## 改进

- Android 本地账户资料改用 Android Keystore 管理的 AES-GCM 密钥加密，首次启动原子迁移各个已保存服务器的旧资料并保留登录会话；删除服务器时清理新旧字段。
- 巡检任务与计划加载完成前禁用“详情与恢复”，避免点击被繁忙状态吞掉。系统栏与媒体会话采用当前依赖支持的接口，并保留控制器权限校验。
- 提取助手公共契约、歌词候选模型和导入文件操作，解除循环依赖；文件描述符在正常退出、异常和拒绝符号链接时均明确关闭，继续保护只读导入源。
- 加固 Web 导航与设计预览的设置值处理，改进错误日志和文件状态检查；保留 Last.fm 官方签名协议及 Android 更新包的校验与系统确认流程。
- 酷狗独立数据源插件升级至 1.1.2，裁剪与元数据／歌词查询无关的上游配置。QQ 音乐与网易云插件继续为 1.1.1，平台适配仍由各插件维护。
- Android 模拟器测试迁移至 Compose v2 调度器，改用可观察状态等待推荐列表和任务加载，覆盖加载期间的操作限制。

## 验证

功能修复合并后的主分支已通过完整 CI：后端原生环境与隔离容器分别 441 项测试、Web 234 项浏览器测试、Android 58 项 JVM 测试及 72 项模拟器测试；CodeQL 四种语言分析完成。API 35 的本地 Mac 与 GitHub Ubuntu 模拟器均执行过完整原生回归。

版本提交及正式标签继续走发布流水线：重新检查 CI、完整 Android 回归、固定签名 R8 APK 安装启动、Web ZIP 和双架构容器。正式资产及下载校验以对应 Release 的实际完成结果为准。

## 升级

请同时升级服务端和 Android，网页随服务端镜像更新。Android versionCode 为 19，沿用现有正式签名，可覆盖升级。升级前备份数据库、私有配置和已安装插件；本次没有数据库迁移，不导入、移动或写回音乐文件。

独立导入的酷狗插件需要另外导入本次 Release 附带的 1.1.2 ZIP 升级；更新服务端镜像不会自动替换实例中安装的插件。旧版发布和 Git 历史保留，本版对当前源码与新插件包的整理不会改写历史内容。

GitHub Release 发布与 home 实例升级分别验收；本次发版不自动更新远程实例。第三方来源可用性、真实账号登录及手机厂商后台行为仍取决于实际环境。
