# WildString / 野弦 0.8.10

本版是面向 0.8.9 的问题修复与稳定性收口版本，集中解决 Android 播客待播同步 HTTP 422、四端统一待播列表手动排序回弹、透明代理 Fake-IP 下播客目录搜索与榜单拦截、Web 空闲播放器待播起播与切歌时长闪烁，以及 Android 横屏控制坞与测试流水线稳定性问题。

## 相对 0.8.9

### 播客待播同步与四端显式顺序保持
- **修复 Android 待播同步 422**：Android 全局 `networkGson()` 启用了 `.serializeNulls()`，此前未带时间戳的新增或重排条目在 `PUT /api/v1/podcasts/queue` 时会写出 `"added_at": null`，触发服务端请求体校验返回 HTTP 422（表现为添加、移除、拖拽排序和点播插队首都提示请求格式有误）。现 Android 请求体显式省略空白／空值 `added_at`（并在 422 旧服务端回退路径真正剔除该字段），后端 `QueueItem` 同时将 `added_at: null` 归一为空串并回退既有时间戳。
- **保持显式队列顺序**：修复 Web、Android、iOS、macOS 在统一待播列表中把 `podcast_queue` 与 `podcast_inbox` 合并后整体按 `added_at` 重排，导致手动拖拽／上下移动、点播插队首与 `queue_next` 在重新打开面板或刷新后回弹为加入时间顺序的问题。四端统一改为：`podcast_queue` 条目严格保持显式顺序，仅对尚未并入队列的 `podcast_inbox` 条目按 `added_at` 升序追加在后。
- **交互细节对齐**：Android 待播长按拖拽改为按最近可见行中点命中落位并立即做本地乐观更新，避免拖到卡片间隙或列表底部时松手回弹；Web 待播弹窗在移除、重排和一键播放全部时与底栏播放器同步队列版本，避免自触发 409 版本冲突。

### 播客目录搜索 Fake-IP 兼容
- **全端生效的后端修复**：后端 `podcast_search.py` 调用 Apple Podcasts 公开目录接口（搜索、单节目查询与区域热门榜单）时补齐传递 `allow_fake_ip=self.manager.allow_fake_ip` 到 `SafeHTTPHandler` / `SafeHTTPSHandler`。Web、Android、iOS、macOS 四端均通过后端接口检索目录与榜单，开启 Fake-IP 兼容开关后四端同步恢复可用。

### Web 与 Android 播放体验修复
- **Web 空闲播放器待播起播**：播放器空闲时通过行内 `+ 待播` 或菜单加入播客单集后，自动采纳队首单集为当前待播项（不自动出声），使底栏播放按钮保持可用且刷新后不丢失；在未起播前继续调整队列顺序或清空待播时，底栏同步跟随新队首或回到空闲态。
- **Web 切歌时长防闪烁**：`onDurationChange` 忽略切歌 `load()` 瞬间浏览器短暂上报的 `NaN` / `0`，保留已知曲目或单集元数据时长，避免进度条总时长闪回 `0:00`。
- **Android 横屏控制坞与提示条**：修复横屏全屏播放器（卡带与黑胶）控制坞布局挤压与操作提示（Snackbar）被常驻错误提示阻塞不显示的问题。

### 自动化测试与发布门禁加固
- 修复 Android 歌词视图进度循环时钟混用、拆分串行 `NativePlaybackTest` 为独立自包含用例，并在模拟器离线时快速中止重跑，避免耗尽 45 分钟超时。
- 移除 `WildStringKit` 单测中的固定 `sleep` 与外部域名请求；补齐 Web 播客跳转测试在拖动滑杆前等待有限音频时长就绪。

## 已知限制
- Android 播客播放页「AI 导读」标签仍为即将推出占位，本版不包含语音转写或摘要生成。
- `podcasts.slow_download` 列沿用建表语句与运行时 `ALTER TABLE` 补齐，`SCHEMA_VERSION` 保持 50。
- 两台物理设备同时离线编辑后的并发冲突体验、真机蓝牙／锁屏音频会话切换，仍以实际设备使用反馈继续跟进。
