# WildString / 野弦 0.8.19

本版主要修复 Android 播客点播与切集卡顿，同时收敛曲库浏览界面。数据库 schema 保持 54，不迁移音乐、进度、收藏或待播数据。

## 已实现

- Android 私有元数据／封面缓存首次访问时建立容量和 LRU 索引，此后增量更新；不再在每份缓存写入后遍历并排序整个目录。容量限制、最近读取时间和进程重启后的缓存恢复保持有效。
- 连续点播单集或切换节目时，新选择取消尚未完成的旧播放准备；账号重置也取消旧任务，提交播放前再次检查任务及账号，避免迟到结果覆盖最新选择。
- Android 手机专辑页固定两列，平板保留自适应列数，加载占位与网格一致；默认专辑／艺人页去掉重复总数，搜索保留结果数量；歌曲菜单与专辑排序入口降低视觉权重。字母索引保持独立列，避免遮住封面。
- 播客进度网络规则回归迁移到 JVM / Robolectric，保留真实设备播放、生命周期和界面用例，缩短常规反馈。

## 性能实验

隔离的 Android 16 x86_64 Pad、默认 32 MiB 元数据容量、每集两份 1 KiB 合成记录。初始 5,000 个缓存文件、50 集首次处理，原缓存类约 21.784 秒，新实现约 0.087 秒；相同内容重复处理约 0.029 秒。五个并发缓存任务的最后完成时间由约 109.840 秒降至 0.176 秒。

这些数据仅覆盖缓存层，不代表完整 App 点击到出声耗时，也不等同于真实连续点击或双设备现场复现。

## 版本与升级

- 后端 Python、Web、Android、macOS、iOS：`0.8.19`。
- Android versionCode：`55`；Apple 构建号：`54`。
- 数据库 schema：`54`，与 0.8.18 相同。
- Android 正式包沿用发布签名，支持覆盖升级。其他客户端同步版本，本轮没有修改其播放逻辑。
- 延续 0.8.18 的升级顺序与兼容边界：从更早版本升级时先升级服务器，再升级客户端；0.8.12 及更早客户端不兼容 0.8.13 及更新的服务器。
