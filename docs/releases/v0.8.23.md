# WildString / 野弦 0.8.23

状态：标签已创建，Release 未发布。签名 R8 APK 安装检查通过，三项 Android 设备回归在点播准备完成前操作，发布任务跳过。本批功能由 [0.8.24](v0.8.24.md) 承接。[发布检查记录](https://github.com/qingmuhy744/wildstring/actions/runs/44487753117)

本版缩短了长歌曲列表点播后的等待时间，并改善 Web 滚动大曲库时的响应。

## 已实现

- Web、Android、macOS 和 iOS 从长列表点歌时，从所选歌曲向后最多装入 100 首。队列自然播完后，心动模式打乱最近一批已生成的每日推荐接着播放。没有缓存时在队列末尾停止。
- Android 在后台准备点播和手动入队所需的音源。连续操作按发起顺序提交，推荐页在实际入队后提示成功。暂停离线下载时也在后台保存下载状态。
- Web 长列表优先渲染视口附近的歌曲，保留字母跳转、键盘焦点和返回列表的位置。歌曲行和曲目菜单也减少了跟随播放进度的渲染。
- macOS 在后台整理播客分组。macOS 和 iOS 只重试待上传的播客进度。

## 版本与升级

- 后端、Web、Android、macOS 和 iOS 为 `0.8.23`。Android versionCode 为 `59`，Apple 构建号为 `58`。
- 数据库 schema 为 `54`。客户端通过新增的只读接口读取已有每日推荐，建议同时升级服务端和客户端。
- Android 正式包沿用发布签名，可覆盖升级。iOS 安装仍需自行签名。

## 验证

- 四端队列和心动模式回归覆盖 100 首边界、推荐缓存为空、显式暂停以及跨设备暂停接续。Android 15 手机模拟器验证离线索引锁争用下的点播和入队顺序。[四端优化 PR](https://github.com/qingmuhy744/wildstring/pull/176)
- Web 用 257 首合成专辑验证从第 201 首播放、键盘导航和返回位置。在同机 Chromium 的 2,000 首合成库中，暂停且开启 4 倍 CPU 限速时，约 4 秒内的 p95 帧间隔由 166.7ms 降至 16.8ms。Safari 和 Firefox 的性能未测。[Web 虚拟化 PR](https://github.com/qingmuhy744/wildstring/pull/177)
- 列表密度回归在桌面和模拟手机分别重复 20 次，均通过。[Web 回归测试修正](https://github.com/qingmuhy744/wildstring/pull/179)
