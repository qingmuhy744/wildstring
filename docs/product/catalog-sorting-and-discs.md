# 曲库排序与多碟专辑

Web 与 Android 提供专辑名称、入库时间、发行时间、艺人排序；歌曲提供碟号与曲序（专辑内）、名称、入库时间、时长、播放次数、收听时长和最近听过。可切换升降序，默认专辑名称升序、专辑内碟号与曲序升序。偏好按当前客户端、服务端账号和页面类型保存，不修改标签或歌单原始顺序。

多碟专辑在原始曲序下使用小号 `DISC 01`／`DISC 02` 标题与曲数、细分隔线，每碟内显示曲序；单碟不增加分组标题。其他排序把碟号移到歌曲副标题。分组不插入队列条目、不折叠、不暂停，整张专辑连续播放。点击歌曲或播放全部，完整队列都使用当前筛选与排序。

服务端先排序后分页；相同主排序值以名称及真实 ID 稳定排序，未知值排后。新客户端使用 `sort=track_number` 明确曲序、`sort=name` 明确歌曲名称，保留旧客户端 `sort=title` 在专辑内表示原始曲序的行为。`order=asc|desc` 可选，旧请求默认方向保持。升序名称排序才提供拼音首字母定位。

入库时间来自歌曲首次保存的 `added_at`，扫描更新不重置；专辑取当前可用歌曲中最早的入库时间，补入新歌不使旧专辑置顶。发行时间取本专辑可用歌曲中最早的非空发行日期，不推断首次发表或音乐史事实。缺失日期排在已知日期之后。

专辑曲目响应补充全量、同权限与同筛选的 `discs`（number、track_count、duration_ms、offset）；曲序排序时 offset 指该碟的全局起点，跨分页不重复计算标题。普通／手工歌单保留现有顺序。

验证入口：`make test`、`make test-catalog-web`、`make test-browse-web`、`make test-large-web`、`make android-ci` 和 `make android-connected-test`。发布及 home 部署分别核验。

## Android 页面操作（0.5.11）

升降序放在排序菜单内，并标记当前方向；选中已有方向不重复切换或重载。播放全部、曲数、排序与列表操作根据实际文字宽度和系统字体大小排列，空间足够时单行，不足时分行，曲数不逐字换行。

发现、专辑／艺人列表和“我的”主页的顶栏菜单提供播放队列、最近听过、离线音乐。歌曲列表及专辑／歌单详情只保留列表旁的操作菜单；管理员的专辑元数据更新、歌词补全入口也归入这里，保留原有权限与确认流程。设置和通知仍使用独立图标。

刷新页面统一使用下拉手势和弦线反馈，并提供“刷新当前页面”无障碍操作。发现页快捷卡片随内容一起滚动，可从卡片区域开始下拉。刷新只重新读取当前页面，不启动服务端扫描或元数据更新。
