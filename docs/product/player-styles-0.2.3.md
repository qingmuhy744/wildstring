# 0.2.3 播放页样式

日期：2026-10-17。状态：范围、默认值、磁带造型与双端实施已确认，功能已接入；验证结果以本批 PR 检查与设备报告为准，0.2.3 尚未发布。

## 本批范围

1. 修复 Android 播放页上下系统栏与封面氛围背景断开的色带。
2. 保留现有封面样式，增加黑胶、磁带两种拟物播放样式。
3. 三种样式共用播放、收藏、进度、歌词与队列；深浅主题和红布主题独立于播放样式。

已确认「三种可切换、默认封面、记住本机上次选择」，Android 与 Web 全屏播放页一起实施，磁带采用单盒双卷轴与歌曲标签。无需新增服务端业务接口。

## 三种样式

| 样式 | 主视觉 | 播放状态 | 歌曲信息 |
| --- | --- | --- | --- |
| 封面 | 保留现在的大方形专辑封面 | 保留轻量切换过渡 | 封面下方展示曲名、艺人与收藏 |
| 黑胶 | 细唱纹黑色唱片、真实封面圆形中心标、右上唱臂 | 唱臂落下、唱片匀速缓转；暂停抬臂并停转 | 曲名等信息保持与封面样式相同位置 |
| 磁带 | 圆角磁带壳、双卷轴透明窗口、纸质标签、少量螺丝与压纹 | 两个卷轴转动，带卷大小随整曲进度轻微变化 | 标签显示曲名与艺人，小封面作为角标，下方仍保留完整信息 |

黑胶借鉴网易云的唱片与唱臂构图，用野弦的暖橙、深绿、暖白和封面氛围重新绘制。中心专辑图片直径约占唱片的 56%，保留外围唱纹。唱片本体保持清晰，不把歌名一起旋转；唱臂固定在面板上，不跟随唱片转动。

磁带首版推荐「一盒磁带」，材质以深色塑料、暖白纸贴、暖橙印记为主。完整磁带机的外壳、机械键和 VU 表可后续扩展，首版给歌词和控制保留空间。不添加与真实音频无关的音量表或默认磁带噪声。

## 布局与操作

- 样式仅在 Android 设置／Web 账号设置的「播放样式」修改，保留本机偏好。播放页不额外放切换按钮。
- 手机保持上方视觉、下方曲名与播放控制。点击视觉或空白区域在歌词与播放动画间切换，返回后恢复原样式与动画相位；移除最底部重复的歌词／队列一行，队列仍由播放控制右侧图标打开。
- 平板及桌面宽窗左侧放视觉与播放控制，右侧沿用歌词／队列切换。手机横屏左侧放大视觉，右侧放曲目信息和播放控制；歌词、队列切换后占用左侧区域，控制保持可用。Android 极小高度允许控制区滚动，不把唱片／磁带挤成缩略图。
- PC 点击歌词文字直接跳转，点击空白处切换歌词和播放动画。移动端拖动只浏览，居中预览候选时间，点右侧 ▶ 才跳转；点击歌词文字只选择预览，不直接跳转。拖动不会同时触发切换。纯文本歌词可浏览，但没有跳转时间。
- 歌词底部与曲名之间留出 32dp 安全间隔；手动浏览后可回到当前歌词，播放进度保持独立。
- 三种样式的收藏、进度、播放／暂停、上一首／下一首、循环／随机和队列入口位置一致，触控范围不少于 48dp。
- 切换样式采用短淡入淡出，保持同一播放器、当前曲目、队列条目、进度、模式与暂停状态，不额外请求音频。
- 进度条、按钮与选中态统一使用当前主题的暖橙／暖白与中性色，避免出现与主题割裂的默认紫色控件。

## 动画规则

- 以播放器实际 `isPlaying` 为准；暂停、缓冲、播放失败或音频焦点丢失时停止转动，不能只根据按钮状态判断。
- 唱片建议 20 秒左右一圈，光照固定，只有唱片与中心封面旋转。暂停后保留角度，继续时接着转，不跳回起点。
- 换歌时唱臂短暂抬起、中心标淡换，再随真实播放状态落下；动画不延迟音频开始，也不阻止快速连续切歌。
- 磁带两个卷轴分别绘制和旋转；带卷大小由整曲进度估算，跳转时平滑更新，不据此改变实际音频进度。
- 只有播放页可见、应用处于前台且实际播放时才持续驱动动画；离开播放页、锁屏或后台停止装饰动画，原播放服务继续管理音频。
- 遵循系统减少动态效果／关闭动画设置。关闭持续转动时仍用唱臂或卷轴静态状态区分播放与暂停。
- 首版不增加黑胶底噪、机械声或额外触感；沿用已有关键操作反馈开关。

## 主题与系统栏

封面取色背景覆盖整个窗口，延伸至顶部状态栏、底部手势区及横屏边缘；返回键、曲名和播放按钮仍在安全区内。时间、电量等系统图标继续随深浅主题切换，状态栏保持可见。

系统栏、播放器背景与切入／退出播放页使用协调的短过渡。设置页系统栏使用设置页表面色；缺封面时使用当前主题默认背景。红布独立于播放样式，保持正红布面，不被黑胶或磁带替换成其他主题。

参考 Android 官方的 [系统栏](https://developer.android.com/develop/ui/compose/system/system-bars) 与 [窗口安全区](https://developer.android.com/develop/ui/compose/system/insets-ui)：背景全屏绘制，只让交互内容消耗安全区。

## 实现边界

- Android：新增独立播放样式偏好，与日夜、红布、图标偏好分开保存；视觉拆为封面、唱片、磁带组件，复用现有 `MusicViewModel`、Media3 与封面缓存。
- Web：样式保存到当前浏览器，复用同一音频元素和播放状态；不重新挂载播放器，不发起新的收听会话。
- 样式属于本机界面偏好，首版不做账号／设备间同步。
- 唱纹和磁带几何优先使用 Canvas／矢量与缓存材质；不随动画帧重复取色、模糊封面或刷新整页列表。
- 复用 0.2.2 的音频、封面、歌词、联网建议和 Last.fm 接口，不改变音频文件、标签或目录。

## 验收与当前状态

- 系统栏修复与两端三种样式均已实现；设置入口、本机偏好、前台与减少动态效果处理已接入，共用原播放器。已按反馈放大中心封面，播放页移除样式按钮，补充手机横屏布局。
- Android 验证入口为 `make android-ci android-connected-test`，包含 Debug／Release、JVM、Lint、R8 和原生设备回归；`NativePlaybackTest` 核对换样式保留音频与暂停位置，并保存手机、平板、深／浅／红布截图。
- Web 入口为 `make ci`；`playback-styles.spec.ts` 核对真实音频元素和串流不重建、暂停位置、偏好记忆、缓冲／页面隐藏／减少动态效果及窄屏边界。CI 保存 `browser-visual-evidence`，所有截图来自隔离的合成测试曲库。
- 本机拟物验证截图保存于未跟踪的 `artifacts/player-styles/`；原系统栏截图保存于 `artifacts/android-system-bars/`。真实音频播放须以实际时间推进验收，不能只根据“播放中”按钮判断成功。
- 0.2.3 尚未发布，已发布的 0.2.2 标签不变；版本更新、正式包与发布在本批实现和验证完成后统一执行。

验收重点：切换样式和主题不重开音频、不改变进度／暂停状态、不重复计数；快速切歌不串封面；缺封面、无歌词、缓冲与错误正确；深浅背景上系统图标可读；手机、平板、横屏、挖孔与手势／三键导航均保留安全区。动画功耗和国产真机系统栏仍需真实设备核对。
