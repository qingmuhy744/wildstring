# 客户端与播客探索改进

日期：2026-11-01。开发分支：`feat/podcast-explore`。以下是本地实现与验证记录；0.8.3 发布准备见[发布说明](../releases/v0.8.3.md)，合并、发布和远程部署分别核验。

## 播客探索与无人关注节目

Web、Android、Mac 的电台页增加「探索」入口。空关键词浏览 Apple Podcasts 区域热门榜，可切换区域；输入关键词沿用多区域公开目录搜索。点击结果先读取 RSS 简介与最新单集，点击「关注节目」才添加／复用服务器节目并建立本人关注。浏览与预览不写入服务器节目清单，不自动播放。

Web 的探索与搜索采用页面内浏览，提供「返回电台」。宽屏使用结果与预览并排布局，窄屏进入预览后可返回结果；返回结果会恢复所选卡片的键盘焦点。搜索框和区域筛选按可用空间换行，预览与列表沿用当前深浅主题。

普通账号仍不能从搜索结果获知其他用户的私人 RSS 或节目关联。是否能添加新节目由既有 `catalog-settings` 权限控制；没有添加权限时仍可浏览、预览公开目录。成人内容过滤、区域选择、上游缓存和请求限额沿用服务器设置。新接口与错误约定见[播客目录搜索契约](../../contracts/podcast-search.md)。

无人关注的节目停止定时抓取 RSS，重新关注后继续原定时策略。节目资料、单集、收听进度和手动保存保留；零引用音频继续遵守既有清理开关、保留期、保护与传输租约。这一轮没有自动删除无关注节目的元数据。

## Mac

- 登录恢复后默认进入首页，展示每日推荐入口、继续收听、电台与播客、最近添加的专辑与歌曲、最近听过。最近添加按入库时间倒序，历史按个人播放时间读取；打开首页不会替换队列或自动播放。首页歌曲可右键安排下一首或加入队列，专辑可进入详情；宽窗口卡片均分可用宽度，展开侧栏后自动改为单列。
- 歌词跳转及原音续播改用毫秒时间基准和零容差。原来 600 Hz 时间基准会把 32.289 秒变成 32.288333 秒，暂停后原生播放时间回调会让高亮退回上一句。真实 FLAC 的 7 次前后跳转核对修复后落点一致；没有改写歌词时间，也没有给整首歌加补偿。
- 播客全屏页「接下来」取消前三集限制，后续节目继续填充左侧剩余高度，超出后左侧独立滚动。「查看与调整队列」放在列表前，长队列仍可直接操作。
- 底部播放条、菜单栏播放器和队列中的播客封面按单集所属节目读取。播客不再受音乐 `hasCover` 字段限制；切换项目会清空旧封面并取消旧请求。
- 桌面歌词使用原生浮动 `NSPanel` 和拖动区域，关闭按钮与菜单入口同步真实可见状态。关闭再打开复用位置，重新创建歌词内容；穿透点击关闭时可拖动。
- 桌面歌词遵循主播放器的译文与音译显示偏好。只有歌词源包含相应内容时才显示，不自动生成翻译。
- 歌词侧栏收窄到 320 点，原文与译文居中；全屏封面、标题和歌词字号收紧。侧栏左上角提供关闭按钮。
- 艺人页首次使用默认显示专辑艺人，保留用户已经保存的艺人类型选择。

## iOS 与 Mac 播放可靠性

共享 `CorePlayback` 在关联播放项之前安装状态监听，并读取初始状态；切歌后的旧状态、结束和跳转回调不再影响新播放项。原音跳转保留毫秒时间基准与零容差，等待当前跳转完成后处理最后一次目标，完成后再同步进度与系统播放信息；初始续播位置也等待播放项准备就绪。用户在准备或跳转期间暂停时，完成回调不会重新开始播放。

网络起播与恢复改用 `defaultRate` 配合 `play()`，允许 AVPlayer 按系统缓冲策略起播，保持播客倍速；缓冲期间仍可暂停。iOS 音频会话激活与一次性事件监听分开，激活失败显示错误并允许下次播放重试，中断结束只在用户仍有播放意图时恢复。

本轮 `make ios-test` 的 67 项播放测试与 90 项网络测试通过，包含 6 项新增生命周期回归：初始定位与暂停、连续跳转后暂停、倍速保持、音频会话激活失败后重试、跳转时清空队列、跳转时切歌。测试使用静音合成音频驱动实际 AVPlayer，音频会话失败使用可控注入。`make ios-build`、`make macos-build` 和 `make macos-test` 的 16 项现有回归通过；未做真实 iPhone 来电／蓝牙中断或真实弱网听感验收。

## Android

- 设置首页收敛为账号与服务器、播放与歌词、播客、外观与语言、缓存与下载、助手偏好与通知、关于 7 个入口。各子页保留滚动位置，系统返回和顶部返回先回分类页；旋转或语言切换后恢复所在子页。
- 助手设置只保留通知、联网与记忆、通知偏好，聊天从底部 AI 页进入。手机收到资料、批量资料、封面、歌词或入库候选时提示到网页核对，不提供批准、拒绝或封面预览；歌单草案仍可从 AI 对话打开、确认并返回。
- 缓存选择改为可滚动列表：曲库与歌词提供关闭及 8–256 MB，封面提供关闭及 32 MB–1 GB，音频提供关闭及 128 MB–32 GB。界面选择和偏好写入共享同一容量定义，仍按账号隔离。
- 补齐发现页、曲库工具栏、设置与常用子页、账号资料、Last.fm、离线下载、更新与播放诊断等中英文资源；切换语言后界面重建并使用对应资源，歌曲、专辑、艺人和服务器提供的内容保留原文。
- AI 页暂停且未缓冲时隐藏迷你播放器，顶部保留打开当前播放器的入口。重新打开保留当前项目、队列与暂停状态；播放／缓冲时迷你播放器保持显示。
- 发现页按入库时间倒序展示「最近添加的专辑」和「最近添加的歌曲」；「最近听过」单独展示。各歌曲区块播放自己的列表，「查看全部」进入对应排序的曲库列表。
- 探索页使用全屏列表与预览，支持切换区域、关键词搜索、失败重试和关注权限提示。电台顶部工具栏在窄屏可换行。

## Web 歌词

移除手动浏览歌词时横穿内容的跳转辅助线，保留时间标记和右侧明确跳转按钮，点击歌词、拖动浏览与回到跟随的交互保持可用。

## 文件夹导入与播客单集

导入目录使用独立宽版窗口，来源切换、文件夹浏览、预览和最终导入保持同一范围；取消不改变已有选择，读取失败可以原地重试。指定子目录导入只索引本次涉及的托管副本，普通扫描仍核对整库缺失。导入源保持只读，详见[自动导入契约](../../contracts/automatic-import.md)。

Web 单集详情改用原生对话框，标题、节目、日期、时长与正文分区，正文独立滚动，播放和文件操作固定在底部。支持下载原始音频到设备，与个人保存到服务器分开；会话、节目访问权限、Range 和本地音频传输租约沿用现有校验，下载不创建个人保存引用或播放缓存。关闭后恢复原入口的键盘焦点。接口边界见[存储与共享资源契约](../../contracts/storage-and-podcast-resources.md)。

探索榜单超时后支持原地重试及重新点击热门探索刷新；收音机底部螺丝对称排列，待播队列使用剩余高度。服务设置与转码卡片补齐留白，窄屏字段换行保持对齐。

## 可选数据源插件

源码暂留本仓库，插件继续通过 Web 手动导入 ZIP 并启用。新实例没有预装插件，服务启动和升级保留已有包、配置、密钥及启用状态。编译插件可通过薄 `adapter.py` 入口调用根目录或 `lib/` 内的 Nuitka 扩展；源码插件仍可使用。打包、平台要求及本地验证见[数据源插件](../architecture/source-plugins.md)。

## 开发库登录修复

旧开发库声明 schema 46，但 `login_attempts` 缺少 `last_attempt`，登录时触发 SQLite `OperationalError`。schema 47 按实际表结构补列，保留登录失败次数、仍有效的封禁与会话；已经存在的时间戳不改写，重复初始化幂等。

本机修改前使用 SQLite 在线备份保存为 `runtime/backups/wildstring-before-login-repair-20261101-131959.sqlite3`，权限为 0600，完整性检查通过。备份 SHA-256：`0276ee14e00b078362722535ce0f87350416388f5a302d2bb80714209dbf4321`。原库已修复到 schema 47，开发服务就绪接口返回 200，测试无效账号登录返回 401；没有清库，修复前后的用户、歌曲、歌单、节目、单集、进度和会话数量一致。
