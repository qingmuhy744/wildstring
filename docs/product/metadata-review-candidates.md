# 元数据核对：候选、拒绝与滚动

0.5.12 补齐以下行为；发布和 home 部署分别核验。

## 候选记录

同一平台可返回不同专辑、现场、改编或重新发行条目，因此不会按平台名直接合并。核对页按平台、歌曲资料版本、来源链接、完整建议字段与封面地址合并相同查询结果，显示最近一条及重复记录数；匹配分数变化不作为不同音乐版本。分组发生在每曲 30 个候选的上限之前，避免重复历史挤掉其他版本。

候选选择显示平台、不同的歌曲标题、专辑、发行日期与匹配程度；过期资料另行标记。匹配程度来自来源适配的启发式评分，不代表事实准确率。原始记录保留在数据库和查询历史中。

待核对专辑统计只计算适用于当前元数据版本的候选，已失效旧建议不继续增加待处理曲数。

## 跳过与拒绝

“本次跳过”仅清除本次勾选并切换歌曲，不改变服务端记录。“拒绝当前建议”校验管理员权限、歌曲版本和候选摘要，把这份候选及读取时已存在的相同旧记录标为 ignored；不修改歌曲、人工覆盖值、文件、其他发行版本或随后新查询的结果。重复提交已完成的拒绝不会继续影响新结果。

拒绝后重新读取候选，保留其他歌曲仍有效的勾选，并清空当前歌曲的选中字段，避免自动采用下一份候选。之后可以重新查询资料，不会永久禁用来源。

## Web 滚动

弹窗标题、重新读取、关闭及底部操作固定；专辑列表与右侧资料分别滚动，滚动不传递到背景页面。歌曲选择列表默认折叠。手机使用横向专辑列表，资料仍在独立区域滚动；关闭弹窗恢复背景原来的滚动设置。

## 验证

后端测试覆盖内容分组、不同来源／发行版本、候选上限、重复拒绝、后续查询、冲突、权限和过期统计；浏览器覆盖桌面／手机滚动、操作区位置、候选标注和重试；Android 模拟器覆盖拒绝和原有接受及歌词流程。正式发布还需完整流水线及签名 APK 验证。
