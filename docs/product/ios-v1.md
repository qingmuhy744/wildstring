# iOS 第一版

日期：2026-10-19。状态：设计草案——先记录定位与目标；技术路线、模块划分、批次与发布流程待评审补充。前置条件已就绪：Apple 开发者账号、Mac 与 Xcode、iPhone 真机。

## 定位

iOS 是同一个野弦自托管服务的原生客户端，与 Web、Android 并列，源码计划位于 `frontend/ios`。共享服务端业务、API 契约、测试夹具与设计语言；界面与播放器按 [ADR 0003](../decisions/0003-native-android.md) 的约定在各平台原生实现，不新增私有服务端接口。首版目标是把 Android 0.5.6 的功能面对齐到 iOS，而不是做精简版；功能基线以本文件日期冻结，之后 Android 的增量改动按批次评估是否补入。

## 首版目标

1. **功能对齐 Android 0.5.6**，覆盖：
   - 连接与登录；多服务器保存、切换与独立退出
   - 曲库浏览、关键词搜索与首字母定位；歌曲 / 专辑 / 艺人 / 歌单
   - 原音串流播放：后台播放、锁屏与耳机控制、队列编辑、循环 / 随机、睡眠定时、AAC 转码与音质设置
   - 歌词：手机全屏滚动歌词、平板（iPad）双栏与窄分屏；跟随可调
   - 收藏、普通 / 规则歌单浏览与编辑；每日推荐；AI 找歌与助手（草案批准流）
   - 离线下载与片段缓存（容量可调）；收听上报与跨设备续播
   - 管理员：元数据 / 歌词编辑与打点、导入与扫描任务入口
   - 外观：深浅色 / 跟随系统、封面 / 黑胶 / 磁带播放页样式、列表大小、轻触反馈
2. **平台等价实现，不逐行照抄**：Keychain 替代 Keystore 加密会话；AVPlayer / AVAudioSession / Now Playing 替代 Media3 与媒体会话；原生 Swift 持久化替代 Room；自动更新模块不移植（分发由 TestFlight 托管）。
3. **真机质量基线**：后台、锁屏、耳机键与音频中断在 iPhone 真机验收；单元测试、模拟器 UI 回归与对临时合成曲库的集成测试与 Android 基线相当。
4. **分发**：TestFlight 外部测试（朋友试用）；首个外部构建通过 Beta App Review，准备演示服务器与测试账号；维护 90 天构建有效期。

## 非目标（首版）

- App Store 公开上架（作为后续独立批次评估）
- 客户端自更新；CarPlay、小组件与上传入口（与 Android 侧同样另行安排）
- 离线统计等两端都未实现的协议增强

## 成功标准

- Android 0.5.6 的使用闭环在 iPhone 上完整可用，真机验证项通过
- 自动化验证基线不低于 Android：单元、UI 回归、集成三类测试可重复执行
- 朋友可在 TestFlight 安装并连接实例正常收听
