# iOS 第一版

日期：2026-10-19。状态：设计草案——定位、目标与实施顺序已记录；技术路线见 [ADR 0004](../decisions/0004-native-ios.md)。前置条件：Mac 与 Xcode、iPhone 真机已就绪；Apple 开发者账号未过审（不依赖商店分发，见「分发」）。

## 定位

iOS 是同一个野弦自托管服务的原生客户端，与 Web、Android 并列，源码计划位于 `frontend/ios`。共享服务端业务、API 契约、测试夹具与设计语言；界面与播放器按 [ADR 0003](../decisions/0003-native-android.md) 的约定在各平台原生实现，不新增私有服务端接口。首版目标是把 Android 0.5.6 的功能面对齐到 iOS，而不是做精简版；功能基线以本文件日期冻结，之后 Android 的增量改动按批次评估是否补入。

## 首版目标

1. **功能对齐 Android 0.5.6**，覆盖：
   - 连接与登录；多服务器保存、切换与独立退出
   - 曲库浏览、关键词搜索与首字母定位；歌曲 / 专辑 / 艺人 / 歌单
   - 原音串流播放：后台播放、锁屏与耳机控制、队列编辑、循环 / 随机、睡眠定时、AAC 转码与音质设置
   - 歌词：手机全屏滚动歌词、平板（iPad）双栏与窄分屏；跟随可调
   - 收藏、普通 / 规则歌单浏览与编辑；每日推荐；AI 找歌与助手（草案批准流）
   - 离线下载与片段缓存（容量可调）；收听上报与跨设备续播
   - 管理员：元数据 / 歌词编辑与打点、联网建议与封面核对、导入与扫描任务入口
   - 外观：深浅色 / 跟随系统、封面 / 黑胶 / 磁带播放页样式、列表大小、轻触反馈
2. **平台等价实现，不逐行照抄**：Keychain 替代 Keystore 加密会话；AVPlayer / AVAudioSession / Now Playing 替代 Media3 与媒体会话；SwiftData 替代 Room；自动更新模块不移植（无商店分发，也不需要）。
3. **真机质量基线**：后台、锁屏、耳机键与音频中断在 iPhone 真机验收；单元测试、模拟器 UI 回归与对临时合成曲库的集成测试与 Android 基线相当。
4. **分发（暂缓）**：Apple 开发者账号未过审，首版不做 TestFlight / App Store；以模拟器与本机真机自签（免费个人团队，7 天有效期）为主验证路径；朋友试用、侧载与商店提交等账号可用后再评估。

## 非目标（首版）

- App Store / TestFlight 分发（开发者账号未过审；账号可用后再评估）
- 客户端自更新；CarPlay、小组件与上传入口（与 Android 侧同样另行安排）
- 离线统计等两端都未实现的协议增强

## 成功标准

- Android 0.5.6 的使用闭环在 iPhone 上完整可用，真机验证项通过
- 自动化验证基线不低于 Android：单元、UI 回归、集成三类测试可重复执行
- 本机真机（自签安装）可连接实例正常收听

## 实施与验收顺序

按内部批次推进，交付目标不变；每批以可验证产物收口，完成后更新 CHANGELOG 未发布条目。真机验证用免费个人团队自签（7 天有效期，过期重装）。

| 批次 | 交付 | 通过标准 |
| --- | --- | --- |
| I0 工程骨架 | `frontend/ios` 工程与生成配置、Makefile / CI 入口、本机自签路径 | 模拟器可启动占位页面；CI 构建绿 |
| I1 连接与登录 | Keychain 会话、URLSession 客户端、地址校验、登录 / 退出；后端 `require_client` 白名单加 `ios` | 真机自签安装并登录自托管实例、重启保持会话；401 / 过期路径单测 |
| I2 播放最小闭环 | 资源代理（转发形态）、AVPlayer、队列基础、后台 / 锁屏 / 耳机、恢复点（SwiftData） | 真机后台 / 锁屏 / 耳机 / 中断清单通过；seek 与恢复正确 |
| I3 曲库 | 歌曲 / 专辑 / 艺人、详情、搜索、分页 | 真机浏览流畅；空态与错误真实 |
| I4 歌词与播放页 | 全屏滚动歌词、iPad 双栏、跟随可调 | 与 Android 交互一致 |
| I5 收藏与歌单 | 收藏、普通 / 规则歌单、每日推荐入口 | 409 版本冲突先刷新再重做 |
| I6 缓存与离线 | 资源代理磁盘缓存、容量设置、后台下载、清理 | 与 Android 缓存策略一致；退出清理验证 |
| I7 AI 助手 | 找歌、草案批准、推荐面板 | 模型不可用不阻断基础播放 |
| I8 管理员 | 元数据 / 歌词编辑、导入与扫描任务 | 写请求带 `X-Wildstring-Client: ios` |
| I9 外观与收尾 | 深浅色、播放页样式、列表大小、触感、全量回归、README | 成功标准全项通过 |

## 对齐 Android 0.5.12（2026-10-20）

Android 0.5.7–0.5.12 的客户端增量已按 iOS 交互方式落地：

- 曲库排序与多碟专辑：专辑/歌曲/专辑曲目排序与升降序、按服务器保存偏好；`DISC 01` 分组、整张连续播放。
- 元数据核对工作台：专辑维度对比与整批接受、逐字段/同字段选择、拒绝候选（0.5.12+）、固定封面快照后应用；候选相同记录由服务端合并、不同发行版分别保留。
- 整理方式：按账号的审核/自动整理与自动应用类型；草案待处理优先、处理记录与「接受并应用」。
- 跨设备接续：仅提示最近 30 分钟内的真实暂停，每次暂停只提示一次，来源恢复播放后撤回；自动恢复同样受此限制。

仍未移植：通知中心、导入管理与下载完成后缀策略、在线歌词候选预览、MCP 凭据管理。标签写回尚未在任何客户端/服务端实现，后续只针对托管副本显式操作。
