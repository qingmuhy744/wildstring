# 服务器线路、连接安全与 MCP 接入

2026-11-05。本地工作区实现，尚未提交、发布或部署。

## 使用入口

- Web 管理中心 → 服务器 → 访问设置：统一服务器名称、HTTP + HTTPS / 仅 HTTPS。
  每字段显示页面／环境／默认来源；“恢复使用环境配置”清除该字段的数据库覆盖。
- Mac 左下角服务器菜单 → 服务器名称与线路：本机别名、Fallback / 手动、线路排序、
  单独登录与重新登录。卡片显示名称、线路及原有延迟指示。
- iOS 我的 → 设置 → 服务器：本机别名和线路。已保存服务器列表也可管理线路。
- Android 服务器列表：本机名称作为别名；当前服务器的“线路与故障切换”用于管理线路。
  未登录页面可选择已保存线路重新登录。
- Web 个人设置 → 助手与通知 → MCP 工具凭据：选择 Codex、Cursor、Antigravity、
  OpenCode 或通用客户端，输入完整 MCP 地址，复制提示词或专用配置。
  凭据单独生成、单独复制，不插入提示词或模板。Antigravity 使用需手动替换的令牌占位符。

## 行为边界

线路和别名只保存在本机。新增线路需服务端支持实例身份，并用相同账号独立登录；
公开实例 ID 只作核对，不作为转发 Cookie 的依据。旧服务端仍能单地址连接。
Apple 当前不允许同源下不同路径作为两条线路，以免共用原有按 origin 保存的会话。

Fallback 按配置顺序选路，保持可用线路；重新选择 Fallback 会尝试最高优先级。
手动线路连接失败不自动跳其他线路；手动选线失败保留原连接、原模式并提示错误。
连续两次探测失败后尝试其他线路，音频网络失败可提前触发。认证错误需重新登录。
切线保留逻辑服务器的库选择、队列、播放进度和缓存；尝试续播，可能缓冲。
下载暂停后由用户继续；不自动重放写入、助手消息。

数据库 schema 48 持久化实例身份、可空设置覆盖与会话协议。首次升级保留旧策略，
选择新策略后 HTTP / HTTPS 会话隔离。仅 HTTPS 拒绝 HTTP API/MCP；健康与匿名实例信息保留。
由部署配置明确可信代理；应用统一处理转发头，Uvicorn 入口关闭额外代理头处理。
服务器名称和连接策略按显式 DB > ENV > 默认解析；默认行不算覆盖，重启不回写覆盖。
其他部署参数仍由 ENV 管理；旧 AI 私有配置文件和显式“代理跟随环境”语义保留。
