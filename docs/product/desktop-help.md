# Web 桌面端就地帮助

0.5.12 开发分支增加跨页面的简短帮助，暂不合并、发布或部署。手机 Web 与原生 Android 本轮不增加此功能。

## 行为

- 仅在宽度至少 761px、主指针支持精确指向和悬停时启用；窄屏或触摸设备不显示新增标记，也不增加状态文字的键盘焦点。
- 参数名称旁的 `ⓘ` 表示有解释。悬停约 400 毫秒显示；聚焦相应输入框、选择框或状态文字时也可阅读。标记不改变字段名称与标签关联。
- 提示可被鼠标悬停阅读，阅读期间不自动消失。离开后收起；切换对象只显示一份。Esc 先关闭提示，再次按 Esc 才交给原弹窗处理。
- 提示按屏幕边缘避让，在原生弹窗内显示于上层，避免被滚动容器裁切。鼠标提示随滚动收起；键盘焦点仍在视口内时重新定位。调整窗口、对象消失或切到触摸布局时收起，并清理临时的说明关联。
- 图标按钮复用已有无障碍名称；有具体语义的控件另写说明。普通文字按钮不普遍重复解释。
- 不读取输入值、密钥或 Cookie 来生成提示；说明以纯文本展示。不会因查看帮助请求网络、修改设置或执行操作。

## 本批覆盖

| 界面 | 解释内容 |
| --- | --- |
| 播放与曲库列表 | 播放模式、音质、定时、队列、排序、收藏与歌曲操作图标 |
| 模型连接与助手 | 接口协议、供应商适配、推理强度、输出 Token、调用次数预算、超时、流式显示、后台授权、模型连接范围 |
| 联网与记忆 | 搜索服务及预算、原生搜索、摘要与长期记忆、历史清理 |
| 管理与导入 | 附属文件、重复、冲突、待整理、等待稳定等计数；检查间隔、稳定期和下载临时后缀 |
| 数据源与网络检测 | 来源优先级、外部服务地址、已保存凭据、代理、AcoustID 应用密钥、公开地址、检测结果含义 |
| 响度、离线与转码 | ReplayGain 模式、前级、峰值保护、专辑／单曲增益、请求／实际增益；浏览器离线空间与音质；转码缓存和并发 |
| 歌词与资料核对 | 扫描模式、目标等级、洗版偏好、限速、强制扫描、候选状态、歌词偏移；发行版本候选、人工值及跳过／拒绝／接受的范围 |
| 草案、任务、通知与诊断 | 依据变化、预算／授权暂停、部分完成、投递状态、历史归档、已读含义和诊断编号 |
| 工具与访问设置 | MCP 操作范围、域名白名单、Telegram 时区与目标参数 |

错误、当前状态、重要后果和必要操作步骤仍直接显示。就地帮助解释眼前一项，完整文档说明功能流程与限制。

## 维护与验证

简短说明集中在 `frontend/web/src/help-content.ts`，交互及媒体条件在 `desktop-help.tsx`／`desktop-help.css`。参数使用 `HelpLabel`，可聚焦状态使用 `HelpText`，已有按钮可使用 `data-help`。新增帮助应说明实际行为，避免把匹配分数说成准确率，或把任务结束说成修改已应用。

本地浏览器回归覆盖延迟、悬停阅读、键盘聚焦、说明关联恢复、弹窗层级、Esc、视口避让、主题与手机无新增提示。全量 Web 回归及格式／类型／安全检查结果在本批完成后记录；不代表分支已推送或部署。
