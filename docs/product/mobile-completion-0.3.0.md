## 共同规则

- 手机的主要动作使用可达的操作面板，列表和编辑表单可滚动，弹窗避免阻断已有播放；先反馈处理中，失败提示或恢复。
- 网页和 Android 共用服务端身份、歌单、建议、推荐及跨设备快照；外观、睡眠定时与离线文件属于本机状态。
- 本地每日推荐以收藏、实际收听和元数据为依据，冷启动与小曲库仍可生成；同一首录音去重，控制艺人／专辑密集度。大模型只从候选 ID 中选择，外部信息失效不阻断播放或推荐。
- AI 每日推荐和 Last.fm 相似增强默认关闭；显式自然语言查询才请求已配置模型。模型请求不包含密钥之外的其他服务器配置，不向模型上传音频或完整私人曲库。
- 完整离线与可回收的最近播放片段缓存分开管理；浏览器静态壳缓存不包含通用认证 API 响应。退出／换账号清理私密离线内容。

离线额度：Web 默认 512 MB、可设 100–2048 MB，最多 1000 首；Android 默认 4 GiB、可设 1–64 GiB，最多 5000 首，单文件最多 2 GiB。离线内容是完整原音。网页关闭时暂停下载，重新打开可继续；断网重开页面依赖 HTTPS／localhost 的静态壳支持，离线身份有效期 7 天。Android 的下载使用应用私有存储与用户启动的前台服务。

接口契约见 [客户端补全接口](../../contracts/mobile-completion.md)。
