# 每日推荐与个人播放清单

更新日期：2026-10-31。当前开发分支的客户端实现与本地验证记录，未合并、发布或部署。

## 使用方式

每日推荐是一份可以自由挑选的临时歌单。可以直接播放整份推荐，也可以仅挑其中几首，加入自己的播放队列或个人歌单。

| 操作 | Web | Android | Mac |
| --- | --- | --- | --- |
| 单曲菜单 | 右键／更多按钮 | 长按／更多按钮 | 右键 |
| 下一首播放、加入播放队列 | 支持 | 支持 | 支持 |
| 挑选歌曲、全选、批量排队 | 支持 | 支持 | 支持 |
| 加入已有或新建手工歌单 | 支持 | 支持 | 支持 |
| 查看所选歌曲歌词 | 独立预览弹窗 | 独立预览弹窗 | 原生预览面板 |
| 收藏、不感兴趣、少推荐此艺人 | 支持 | 支持 | 支持 |

“下一首播放所选”按推荐列表中的顺序插入当前歌曲之后；“加入播放队列”放到队尾。添加时保留当前歌曲、播放进度和播放／暂停状态。歌词预览只读取所选歌曲，不替换当前歌曲或队列。Android 每日推荐页增加底部播放条，可以暂停、切歌和预览当前音乐歌词；播客不会进入音乐歌词接口。Web 和 Mac 继续使用全局播放条、歌词和队列入口。

歌单保存前读取当前版本，再提交所选曲目 ID。创建歌单成功但添加曲目失败时，弹窗保留已创建的歌单，用户可继续重试，不重复创建同名空歌单。收藏和推荐反馈仍是独立操作。

本轮复用既有推荐、歌词和歌单 API，没有改变推荐算法、后端权限或数据库结构。Web 的 AI 候选列表和 Mac 共用歌曲列表也获得单曲队列、歌单与歌词操作。
