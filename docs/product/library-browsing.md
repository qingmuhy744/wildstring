# 连续浏览与专辑曲目布局

2026-10-17。用户确认 Android 与 Web 一起去掉曲库翻页按钮，连续向下浏览；按名称查看时提供固定的 `0–9 / A–Z / #` 索引。本批按 0.3.3 准备发布，升级说明见 [0.3.3](../releases/v0.3.3.md)，实际产物和远程部署以执行结果为准。

## 浏览与定位

- 歌曲、专辑、艺人和歌单内容按需加载，加载期间保留已有内容。请求失败提供重试，不能把失败当作“已经到底”。后台接口仍分页，避免一次下载全部曲库。
- 名称排序由服务端统一为拼音顺序，数字先于字母，其他字符归入 `#`；展示名称保持原标签。多音字使用固定词典的确定读音，不承诺所有人名都能自动读对。
- 字母栏空组灰显。点击直接定位；拖动时预览大字母，松手后定位到该组第一项。可直接定位尚未加载的字母，定位后仍能向前、向后浏览。
- 字母栏只用于名称排序。按收听次数、收听时长、最近收听浏览时隐藏；专辑按碟号、曲号，手工歌单保留人工顺序。
- 专辑与艺人歌曲接口显式支持三种个人统计排序；默认仍保持专辑曲序。最近听过默认按最近时间，切换名称后实际按名称排序。
- 搜索、艺人角色与集合过滤作用于完整结果及字母索引。切换条件后重置相应结果；返回之前的页面恢复浏览位置。
- 连续浏览与完整集合播放分别处理：点击播放仍读取当前集合完整队列，不把已显示的几十首当作全部歌曲；读取失败保留原播放。

## 专辑与移动端空间

- 专辑内曲目使用曲号代替重复专辑封面，显示歌名、艺人两行；全曲库歌曲继续保留小封面。
- 普通浏览不再为每首歌固定显示第三行“0 次 · 0 分钟”。按统计排序时，将相应指标放入第二行。
- “更新专辑元数据”收进专辑更多菜单。排序使用菜单，与“播放全部”和曲目数合并成紧凑工具栏。
- 保留清晰字号和可点击区域。底部播放器保留胶囊外观，减少高度和上下留白；列表最后一项必须能滚动到播放器上方。
- 手机页面以同屏约 6–7 首为设计目标，实际数量随屏幕、系统字号和导航方式变化。网页桌面保留适合鼠标和宽屏的列布局。

## 歌曲列表大小

Android 在「设置 → 外观与触感 → 歌曲列表大小」，Web 在「账号设置 → 歌曲列表大小」选择小、中（推荐）、大；默认使用中。本机记住选择，切换立即生效，不需要重新登录。作用于全部歌曲、专辑曲目、艺人歌曲和歌单中的歌曲。

| 选项 | Android 最小行高 | Web 最小行高 | 封面边长 | Android / Web 歌名字号 | 艺人字号 |
| --- | --- | --- | --- | --- | --- |
| 小 | 56 dp | 56 px | 36 dp / px | 14 sp / px | 12 sp / px |
| 中（推荐） | 64 dp | 68 px | 44 dp / px | 16 sp / 15 px | 12 sp / px |
| 大 | 80 dp | 80 px | 56 dp / px | 18 sp / px | 14 sp / px |

字体仍遵循系统字号或浏览器缩放，必要时行高自然增长。长标题省略显示，主要操作保留足够点击范围；切换大小保留当前歌曲、进度、队列和列表位置。专辑曲目继续以编号代替重复封面。设置存在当前设备／浏览器，非法或损坏的本地值回到中档，浏览器禁用存储时当前页面仍可调整。

## 播放页与返回

专辑入口位于歌曲信息区，避免挤占播放页顶部。打开所属专辑不重建音频或队列。

- 播放页 → 专辑 → 返回：恢复播放页原来的展示模式与面板。
- 曲库／搜索／歌单 → 专辑 → 返回：恢复原列表及其位置。
- 播放页 → 专辑 → 其他浏览页面：逐级返回，不跳过中间页面。
- 浏览期间切歌后，返回展示当前歌曲和实际进度，不恢复旧的音频快照。
- 专辑读取失败保留原页面并提示重试。
