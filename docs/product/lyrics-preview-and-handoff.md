# 歌词建议、处理记录与近期暂停接续

2026-10-19 开发分支实现；尚未推送、发布或部署。现有 home 仍为正式 0.5.9。

## 歌词建议闪退

正式 API 的待处理草案包含 `result: null`。Android 0.5.9 新增的应用方式提示用 Gson `getAsJsonObject` 读取该字段，触发 `JsonNull cannot be cast to JsonObject`，不限于逐字歌词。此前 UI 测试省略 result 字段，未覆盖真实空值。

已增加对象类型检查，并用显式 null 的双语逐字歌词草案复现后确认修复。预览仍展示当前／候选歌词、质量和偏移，接受后才应用；本次不改变歌词格式或写回原音频。

## 处理后的内容

Android 草案默认待处理，已应用／已拒绝自动归入处理记录。记录按最近处理时间排列，通知跳转仍能直接查看具体草案。Web 沿用待确认、待应用、已应用、已拒绝视图，服务端统一优先待处理并按处理时间排序。

Web 与 Android 通知默认未读，显式标为已读后移入已读记录，可切换全部。只改变工作视图，不自动将读取当成已读，不删除差异、来源、诊断和审计记录。

## 设备接续

仅对其他设备最近 30 分钟内真实暂停的队列提示一次，来源恢复播放后撤回。刷新／重开不会重复提示同次暂停。自动恢复模式也受相同规则限制，载入后保持暂停；旧记录可手动载入。详见 [架构与兼容性](../architecture/client-continuity.md) 和 [接口](../../contracts/mobile-completion.md)。

需要 schema 22 → 23 的增量迁移，仅增加播放快照状态和暂停时间；原音乐、元数据、曲序、歌词、封面、队列和账号均保留。旧客户端和旧服务端使用兼容请求，不把旧记录误认作最近暂停。
