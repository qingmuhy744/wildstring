# Web 界面梳理与验证

本轮基于隔离合成曲库检查 Web，不代表部署或真机验收。

| 范围 | 检查与调整 | 验证边界 |
| --- | --- | --- |
| 登录与首次设置 | 按用户反馈恢复原有双栏介绍、唱片装饰和登录卡片；保留登录错误及首次配置指引 | 1100×720 浅色、390px 深色登录；登录成功路径 |
| 歌曲、专辑、艺人、歌单 | 收紧列表标题与数量；标题采用展示字体，曲目序号和时长使用等宽数字 | 两种视口的列表、专辑详情与播放中切页；其他详情及长文案未逐页复验 |
| 推荐、排行榜、库外推荐 | 推荐改为直接标题，去掉装饰眉题；保留推荐来源与设置 | 两种视口每日推荐；排行榜及库外推荐本轮未逐状态截图 |
| 播客与电台 | 空态操作按组留间距；缓存进度使用主题色并移除宽度动画；已听完单集弱化标题与播放按钮 | 两种视口关注空态、节目详情、已听完与部分进度；错误和权限状态未逐一截图 |
| 播放器、队列与歌词 | 队列去除装饰眉题，序号和播放时间使用等宽数字；磁带进度不再做宽度过渡 | 合成曲目播放、拖动、切页，以及两种视口的队列与歌词；其他模拟播放界面未逐一视觉复验 |
| 助手、工作台与通知 | 工作区标题采用展示字体和 28px 层级，移除装饰眉题，保留模型与权限说明 | 两种视口助手初始态；其他工作台的全部边界状态未逐页截图 |
| 离线、设置与管理 | 上一轮已整理空态、重试、说明及操作间距；完成下载不再显示满进度条 | 离线空态和上一轮下载、重试、长标题的隔离截图；未覆盖所有权限与主题组合 |

审查按信息密度、布局与破坏性操作、圆角与表面、字体和数字、播放状态、动效与无障碍六个维度进行。此次针对明确发现修复；并非声明所有页面均符合每个细则。仍有其他局部过渡、圆角、复杂弹窗及辅助技术状态需要逐项验收。实际测试结果以本次交付记录为准。

本地验证：`make check` 通过；最终播客颜色选择器调整后单文件格式检查及 Web 构建通过。固定构建上的 `make test-affected-desktop` 共 144 项通过，随后针对最终样式的播客播放专项 11 项通过。隔离截图覆盖 1100×720 浅色与 390px 深色；已听完单集的浅深主题计算样式与未听状态不同。未覆盖全站的加载、错误、权限、长文案和主题组合，真实设备、发布及部署需单独验证。
