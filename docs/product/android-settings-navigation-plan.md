# Android 设置分层方案

日期：2026-10-31。状态：方案，尚未实施设置导航重构。

当前 `SettingsScreen.kt` 将账号、Last.fm、助手、播放、跨设备接续、播客缓存、外观、本机缓存和关于全部展开。歌词参数混在播放组，下载偏好另在离线页，退出登录藏在关于末尾。页面长，相关设置也不够集中。

## 页面结构

设置首页只显示当前账号卡片和分类入口，每项一行摘要；不在首页展开开关或长说明。常规操作最多两层，音质等离散选项使用弹窗，不再创建第三层页面。

| 首页入口 | 二级页内容 | 首页摘要示例 |
| --- | --- | --- |
| 账号与服务器（顶部卡片） | 个人资料、头像、界面语言、服务器切换、修改密码、退出当前账号 | 昵称 · 当前服务器 |
| 播放与接续 | 播放音质、音乐跨设备接续模式、手动接续入口、播放诊断入口 | 原音 · 接续轻提示 |
| 歌词 | 字号、恢复跟随间隔；汇集已有翻译／音译偏好时复用原存储 | 标准字号 · 2 秒后跟随 |
| 外观与交互 | 日夜模式、主题、歌曲列表大小、播放样式、桌面图标、屏幕方向、轻触反馈 | 跟随系统 · 封面模式 |
| 下载与存储 | 音乐下载音质、仅 Wi-Fi、自动下载歌单、本机缓存分类用量与上限、清理缓存 | 已下载／缓存用量 |
| 播客 | 单集续播方式、播放时缓存、下一集预缓存、缓存网络策略、跳转个人下载 | 播放前询问 · 仅 Wi-Fi 缓存 |
| 助手与通知 | 联网与记忆、通知渠道与偏好；对话、通知列表、草案提供快捷入口 | 未读数／通知状态 |
| Last.fm | 连接状态、授权及现有记录偏好 | 已连接／未连接 |
| 关于与帮助 | 客户端／服务端版本、更新与现有帮助入口 | 客户端版本 |

服务端管理仅对有权限账号显示“打开网页版管理”入口，放在首页末尾；音乐库路径、文件夹、权限和插件保持网页版管理边界。播客服务端缓存与本机离线下载在各自页明确区分；清理本机缓存不使用暗示会删除离线下载的文案。

## 导航和状态

- 分类页使用完整页面及明确标题；系统返回、返回箭头均先回设置首页，再回原曲库页面。
- 保留每页滚动位置与当前分类，旋转、打开播放器再返回仍停在原位置。切换账号／服务器后重置设置路由与临时编辑状态。
- 保留底部迷你播放器。宽屏使用左侧分类、右侧内容，手机单列导航，二者复用同一组设置组件。
- 分类摘要只展示实际状态；读取失败展示可重试提示，不默认为关闭。进入分类页才读取该页额外接口。
- 本机、账号同步、服务端偏好沿用现有作用域和保存接口；界面语言接入远程国际化分支现有的账号语言设置。
- 红布主题与日夜模式的关系须在外观页说明，不能因换主题让用户误以为日夜设置丢失。
- 第一版不增加设置搜索；先让分类稳定，避免额外维护搜索索引和重复入口。

## 实施与验收

1. 给 `SettingsPage` 增加标题，拆出设置首页和分类内容；沿用 `SaveableStateProvider` 保存路由和滚动状态。
2. 逐组迁移现有组件，不改偏好默认值、存储键和接口。复用 `OfflineSettings`，让离线页与设置页进入同一份下载偏好。
3. 将退出登录移到账号页末尾，保留原确认对话框。诊断保留播放页快捷入口，通知和对话仍可从主导航直接进入。
4. 验证所有旧设置都有对应入口；返回栈、旋转、播放器往返、账号切换、语言切换、保存失败、清理缓存，以及手机／平板和大字体布局。

验收目标：首页只保留分类与摘要，播放音质、歌词大小、日夜模式、缓存清理等从设置首页两次点击内可达；设置不遮挡迷你播放器。
