## 现在如何开启播客自动清理

所有者登录 Web 后，进入「管理中心 → 播客 → 共享音频管理」。在「自动清理」中勾选「自动清理零引用音频」，填写「零引用后保留天数」，点击「保存清理策略」。「电台 · 播客」顶部保留快捷入口，跳到同一个完整管理页面。曲库管理员、资料编辑员和听众没有这个配置权限；界面与后端都按所有者校验。

新建实例默认关闭自动清理，默认保留期为 7 天；已有实例以保存的策略为准。自动清理针对服务器共享音频文件，零引用并经过保留期才会进入候选。有人保存、手动保护或正在播放／下载的文件会跳过。手动「预览零引用清理」与自动保留期不同：手动确认会立即清理符合条件的零引用文件。

无人关注的节目会停止定时更新，但节目资料、单集与收听记录仍保留。「零引用音频」和「无人关注节目」不是同一个清理对象。

对应实现：

- `frontend/web/src/management.tsx`、`podcasts.tsx`：分类页和共享音频管理快捷入口。
- `frontend/web/src/podcast-resources.tsx`：开关、保留期、保存及手动预览。
- `backend/src/wildstring/podcast_resources.py`：所有者权限与清理规则。
- `backend/src/wildstring/podcasts.py`：后台定时调用自动清理。

## 重组前的组织问题

1. 侧栏混合内容页面、播放队列开关与配置入口。「发现与电台」下面还放着音乐助手；收听记录、离线内容藏在「更多音乐」，助手设置与草案、任务混在「助手工具」。同一层级无法表达操作类型。
2. 个人偏好分散：语言、主题、播放样式和列表大小在「账号设置」弹窗，助手偏好在单独页面，离线设置和播放相关选项还有各自入口。
3. 「曲库管理 → 设置」是一张不断增长的长页，同时包含音乐库、播客准入、目录搜索、重复节目、数据源、模型连接、转码、域名、歌词扫描、库名称和服务状态。实例设置与当前音乐库设置混在一起。
4. 播客管理没有统一归属：搜索区域和重复节目管理在管理页，共享音频清理与服务器下载管理在收听页，个人自动下载又在节目详情。只凭标题很难判断影响本人还是全服。
5. 模型连接已有统一实现，但入口同时出现在助手设置和管理页；主题也同时有侧栏快捷切换和账号设置。快捷入口可以保留，但应明确指向同一个配置位置。

核对范围：`library.tsx`、`accounts.tsx`、`management.tsx`、`assistant-settings.tsx`、`podcasts.tsx`、共享资源组件与后端权限。

## 已实现的入口结构

| 位置 | 内容 | 组织方式 |
| --- | --- | --- |
| 主侧栏：发现 | 每日推荐、电台 · 播客、音乐助手 | 只放内容入口 |
| 主侧栏：我的音乐 | 歌曲、专辑、艺人、歌单、喜欢、最近收听、离线内容 | 同类内容集中，常用入口直接可见 |
| 侧栏底部：个人设置 | 账号与安全、外观与语言、播放与歌词、下载与接续、助手与通知、关于 | 分类页进入具体设置，显示作用于当前账号或当前浏览器 |
| 侧栏底部：管理中心 | 音乐库与导入、播客、数据源与模型、用户与权限、任务与诊断、服务器 | 按现有权限显示；各分类有二级页面 |
| 播放条 | 播放队列、音量、播放相关快捷操作 | 队列保持唯一主入口，侧栏不重复占位 |
| 顶部 | 搜索、通知 | 跟随当前内容页 |

管理中心中的「播客」集中放置：节目准入、目录搜索与区域、重复节目处理、服务器下载任务、共享音频与清理。所有者独有的清理入口继续受现有权限约束；个人自动下载留在节目详情，个人设置的「下载与接续」提供说明和前往播客的入口。单个节目的重试、流式播放等服务器下载选项仍随节目详情编辑。

配置页面采用固定分类导航和可滚动内容。手机使用分类首页进入子页，返回先回分类；较大的表单、资源列表使用完整页面，短暂的确认或单项编辑使用弹窗。每项设置只有一个实际表单，其他位置的快捷入口跳到该表单。

## 实现与验收

1. 个人设置替代账号弹窗；账号资料、密码和 Last.fm 分页，外观、播放、离线和助手偏好各有归属。歌词译文、音译和字号与播放器快捷控制共用按账号存储的偏好。
2. 管理中心首页显示业务分类，子页显示当前分类的具体功能。音乐库切换只出现于依赖当前库的页面，模型连接跳到同一份个人／共享连接配置。
3. 主侧栏把最近收听和离线音乐直接列出，移除重复的队列入口与设置入口；保留播放器、通知和助手任务入口。
4. 设置采用统一页头、分类导航和内容宽度；手机显示分类目录，子页返回分类，再返回原来的音乐页面。切换配置保留播放来源、位置和队列。

验证使用本地一次性测试库，覆盖新分类、清理策略持久化、旧快捷入口、账号隔离、权限、播放连续性、浅深主题和桌面／手机布局。真实服务器的策略与资源没有调整。
