# 野弦 Android

Kotlin / Compose / Media3 原生客户端，Android 8.0（API 26）起可安装。所有曲库、封面、歌词、收藏与歌单来自用户配置的野弦实例；生产 APK 没有内置演示曲库或测试音频。测试夹具只打包到独立的 androidTest APK。

当前源码版本：0.6.0（versionCode 30）。账号档案改为 `profile` 并移除旧 `role` 字段；专辑长按操作和轻量专辑编辑见 [0.5.15 发布说明](../../docs/releases/v0.5.15.md)，本版变更见 [0.6.0 发布说明](../../docs/releases/v0.6.0.md)；正式安装包以 GitHub Releases 为准。

0.3.0 在设置中增加封面／黑胶／磁带选择，默认封面并记住本机选择。黑胶中心封面放大，手机横屏采用视觉与播放控制左右布局。长按视觉或歌词可查看正向大封面，点空白或返回关闭，播放继续。唱臂、唱片与双卷轴跟随实际播放状态，暂停、缓冲、后台及关闭系统动画时停转；三种样式共用音频和队列。播放背景延伸至系统栏，按钮保留安全间距，进度条使用主题配色。实现与验证状态见 [播放页样式](../../docs/product/player-styles-0.2.3.md)。

当前功能：服务器连接/登录与加密会话保存；歌曲、专辑、艺人、关键词搜索、连续浏览与拼音首字母定位；原音串流、后台媒体服务、系统控制、队列增删/三横杠拖动排序、循环/随机；手机全屏歌词、平板双栏与窄分屏布局；收藏、歌单浏览/创建/加入和在线收听上报；按曲目 ID 保存队列及暂停恢复。

0.3.0 增加普通／规则歌单编辑、多选加入、拖动排序、角色筛选、统计、管理员元数据与歌词编辑／打点、曲库导入扫描任务；两端共享每日推荐、AI 找歌预览和跨设备进度。完整原音离线下载与片段缓存分开管理，支持容量设置、暂停继续、重试和删除；睡眠定时支持分钟数与播完本曲。详见 [本批验收](../../docs/product/mobile-completion-0.3.0.md)。Android Auto、iOS 和小组件另行安排。支持的容器以服务端曲库协议为准，实际编码仍需设备解码验证。无歌词、无封面和网络错误使用真实空态或反馈，不填充虚构内容。

0.2.0 增加可调缓存、封面取色毛玻璃、自然过渡、轻触反馈，以及独立红布彩蛋。经典深色主题保留原暖橙 / 深绿，支持浅色及跟随系统自动切换；红布固定正红，不随日夜变化。变化与验证状态见 [CHANGELOG](../../CHANGELOG.md)。

## 0.2.1：原生页面布局

手机以「发现 / 音乐 / 我的」底部导航切换，平板保留侧边导航；曲库使用专辑 / 歌曲 / 艺人标签，个人页集中展示账号、最近听过和歌单。启动页提供搜索、横向专辑预览和真实最近收听。设置是独立页面，返回栏固定，选项按组排列并使用单选弹窗；封面取色的悬浮播放条在曲库和设置中都可控制播放或打开队列，展开后返回保留页面位置与播放状态。

触感仅用于播放与关键操作：点播、收藏、队列增删、悬浮条展开、进度松手和歌词定位轻反馈；拖动队列区分开始与有效落位，取消不触发落位反馈。共用反馈节流，普通浏览、列表滚动和自动歌词跟随保持安静。设置中的「轻触反馈」即时生效，使用系统原生反馈并遵循系统开关；实际强弱取决于手机，模拟器不能验收马达手感。

交互设计稿也已同步为这套结构，执行 `make android-design` 后访问 `http://127.0.0.1:18782/android-v1.html`；可切换手机 / 平板、主题和设置选项，并预览播放器返回与队列拖动。HTML 仅使用示例资料，不连接实例、不播放音频、不保存真实设置，不能代替 APK 验收。设计稿已完成 JavaScript / HTML / CSS 语法及静态检查，浏览器视觉验收待补；下述设备回归针对原生 APK。

本批 UI 与交互改进归入 0.2.1（versionCode 4）。本地 `make android-ci android-connected-test` 已通过：20 项单元测试、Debug / Release Lint、R8 构建及 9 项 Android 15 ARM64 模拟器回归；含触感开关与节流、反馈异常不阻断操作、队列拖动反馈类型、发现页数据与查看全部、悬浮播放条 / 队列、设置轻下拉防抖、返回与列表位置恢复、手机 / 平板导航、主题 / 缓存设置，以及真实音频播放与缓冲 / underrun 指标检查。截图使用 androidTest 接口夹具；国产真机手势、后台限制和功耗仍待验证。

## 构建

准备 JDK 21、Android SDK `platforms;android-37` 与 `build-tools;36.1.0`。在仓库根目录执行：

```sh
make android-ci                 # Android Lint、单元测试、debug APK 与校验和
make android-connected-test     # 已启动的设备/模拟器上运行原生登录/播放/歌词测试
make android-locks              # 修改依赖后刷新锁与 SHA-256 校验元数据
```

`ANDROID_HOME` 指向本机 SDK，`JAVA_HOME` 指向 JDK；`local.properties` 只用于本机且不跟踪。Gradle Wrapper、版本目录与依赖校验资料入库，构建缓存、APK 和签名私钥不提交。

`make android-ci` 的安装包位于 `artifacts/android/`，包含 `wildstring-<version>-debug.apk`（当前开发包为 `wildstring-0.5.2-debug.apk`）与 `SHA256SUMS`。GitHub 的 **Android APK** 工作流通过后，在该次运行的 **Artifacts → wildstring-android-debug** 下载并解压 ZIP 后安装 APK。原有 Python/Web/Docker CI 继续独立运行。

CI 另启动一次性合成曲库，并通过 `ANDROID_TEST_ARGS=-Pandroid.testInstrumentationRunnerArguments.realBackend=http://10.0.2.2:19882/` 运行真实 API 集成。该参数只允许指向临时测试实例，使用固定的公开测试账号，会创建／删除测试歌单及修改测试曲目。不要指向个人服务器。

设备测试用 `UiAutomation.takeScreenshot()` 生成手机和平板 PNG，写入 AGP 传入的 `additionalTestOutputDir`，在测试卸载应用前自动取回到 `frontend/android/app/build/outputs/connected_android_test_additional_output/`。Actions 的 `android-test-reports` 同时保存这些截图及失败截图。手工查看本地已连接设备时，也可用 `adb exec-out screencap -p > screenshot.png` 保存当前屏幕。

debug 包 ID 为 `com.wildstring.app.debug`，与正式包 `com.wildstring.app` 隔离。CI 使用一次性 debug 签名，不上传私钥；不同运行的签名可能不同，安装更新提示签名不匹配时需卸载旧测试包。卸载会清空本机连接/队列，服务端曲库、收藏和歌单保留。

## 正式发布

显示名称为「野弦」，英文名称 WildString。0.1.0 的正式包 ID 为 `com.wildstring.app`，versionCode 为 2。旧的 `dev.wildstring.app.debug` 测试包属于另一应用，无法直接覆盖；首次安装正式版需要重新连接服务端。服务端曲库不受影响。

GitHub [Releases](https://github.com/qingmuhy744/wildstring/releases) 提供正式的 `wildstring-<version>-release.apk` 与校验和，实际已发布版本以该列表为准。正式包启用 R8 优化，使用固定发布签名；后续保留同一包名和密钥，以递增 versionCode 更新。私钥不进入源码、Actions 缓存或发布附件。公开证书指纹在 Release 的 `android-signing-certificate.sha256` 中。

本地签名构建需要从未跟踪的 `.env.android-release` 导出 `ANDROID_KEYSTORE_PATH`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`，再执行 `make android-release`。`make android-release-smoke` 会在一次性模拟器安装正式包并检查连接页；不要对正在使用的正式客户端运行这个安装检查。工作流与密钥备份约定见 [发布说明](../../docs/releasing.md)。

## 连接与数据

- 默认 HTTPS，校验系统可信证书，不提供跳过 TLS 验证的开关。当前版本的 HTTP 仅限 debug 包显式启用的 `localhost`、`127.0.0.1` 与 Android 模拟器宿主地址 `10.0.2.2`；普通局域网地址请提供 HTTPS 入口。未全局开放明文连接。
- 服务端默认回环监听，手机不能用自己的 `127.0.0.1` 访问另一台服务器。使用可达的 HTTPS 反向代理，客户端不会修改服务器监听或防火墙。
- 普通接口、封面与媒体 Range 请求共用 CookieJar 和同源/路径校验；拒绝重定向。当前服务支持 `X-Wildstring-Client: android`；旧服务仅返回明确的 `client_header_required` 时，在同一地址使用已有 Web 标识重试，认证仍需有效 Cookie。
- 密码只用于本次登录，不落盘。Cookie 由 Android Keystore 管理的 AES-GCM 密钥加密，应用禁止系统备份。401 清理会话并停止受保护播放。
- Room 保存队列条目 ID/曲目 ID、顺序和位置。0.2.0 新增应用级曲库 / 歌词 / 封面 / 最近播放片段缓存，容量可在设置中调整或关闭。0.3.0 另提供完整原音离线副本，未完成下载仍只具有片段缓存的能力；在线播放离线副本前核验权限与文件版本。0.3.1 按服务器隔离缓存及离线内容，切换保留各服内容，退出只清除当前服务器的私密内容，详见下方多服务器说明与 [Android 缓存](../../docs/architecture/android-cache.md)。
- 进程重建后恢复到暂停状态；后台服务仍在时重新连接同一播放器。强制停止、厂商省电策略和断网尾段统计另按真机结果验收，不能以可构建 APK 代替这些验证。

## main 新功能适配（0.2.0）

- 默认原音，设置可选 AAC 128/192/256/320 kbps；FLAC/ALAC 由服务端按实际编码决策，有损源直放，页面显示实际输出。
- Media3 加载线程读取播放决策，保留认证和同源路径约束；转码尾段按 `start_ms` 重新请求，整曲位置用于歌词、系统媒体控件、收听与 Room 恢复点。音质切换保留位置与暂停状态。
- 登录账号可自由输入；设置显示账号和角色、支持改密。退出、改密与登录失效停止播放，换账号隔离私密缓存与队列。
- 播放页可刷新 Web 管理员保存的人工歌词，刷新不重新设置音频源；歌词打点、账号管理及 Host 白名单设置继续使用 Web。
- 旧服务仍可使用默认原音；AAC 与改密需要目标服务实际部署对应新接口。转码繁忙/失败可重试或切换原音。

合成 FLAC、fragmented AAC 及偏移尾段只在测试 APK；生产 APK 不包含样本。适配验证见 CHANGELOG 和 PR 的实际结果；不以模拟器替代真机后台与全部格式验收。

### 多服务器（0.3.1）

设置中的“服务器 / 切换服务器”与“退出登录”分别操作。未登录页面也能管理服务器：添加、选择、修改名称或地址、删除。地址会规范化并去重，不接受内嵌账号、密码、查询参数；正式版继续使用 HTTPS。

每个服务器分别保存加密会话、账号与私密缓存，切换后可继续使用该服务器之前的登录。切换会停止播放、清空当前播放队列、取消在途请求并暂停下载；不会把当前队列自动带到另一服务器。各服务器已完成的离线音乐与缓存分别保留，返回后可以继续使用，未完成下载需要手动继续。退出登录只清除当前服务器的会话与私密数据；删除配置或修改其地址也会清除该配置原有的本地数据，不改服务器上的音乐或账号。

旧版单服务器配置首次启动时自动迁移，保留加密 Cookie、账号、原缓存归属与已有离线索引；播放数据库结构不变。实现分别使用持久文件归属和每次选择都会变化的请求归属，防止 A→B→A 后旧请求写回、改 Cookie 或串用账号。

新增验证包括旧配置/密文与缓存迁移、独立账号和相同歌曲 ID 的完整离线隔离、存储选择的并发保护，以及两个实际 HTTP 测试服务的登录、管理、播放后切换、返回免登录与仅当前服务器退出。测试只使用一次性合成数据。

### 应用更新（0.3.1）

关于页面提供“检查更新”和 GitHub 仓库入口。正式版启动时最多每 12 小时自动检查一次 GitHub 最新稳定 Release，只提示更高版本，不自动下载。下载会验证官方发布资产、SHA-256、应用包名和签名；安装由 Android 系统再次确认，不会静默覆盖。更新检查使用独立网络客户端，不携带音乐服务器的 Cookie 或账号；调试包默认不自动联网检查。

## 0.4.0：助手、草案与站内通知

发现／我的快捷入口和设置中的「野弦助手 / 通知与草案」打开同一组原生页面；曲库右上角的通知铃显示未读数。与网页共用 `/api/v1/agent`，无需在手机配置 MCP 或给应用额外的推送权限。

- 助手支持选择可用模型连接、多轮对话、恢复历史与删除对话。发送后立即显示处理状态；响应丢失时读取会话结果，不自动重发可能计费的模型请求。未配置模型时保留明确标识的本地找歌回退。
- 草案展示当前值、新值、真实歌曲名称、来源依据与版本；「批准此版本」和「应用已批准草案」是两个明确操作。共享元数据仍由服务器校验管理员权限，应用使用稳定幂等键；不会因阅读通知或巡检完成自动修改曲库。
- 站内通知在登录、返回前台、恢复网络和持续前台每五分钟补拉。全量分页从第一页游标继续增量，按 ID／版本合并；游标过期重新全拉。列表读取不标已读，单条已读与快照范围全部已读单独操作，不误读后来到达的结果。
- 手机可启动规则／AI 巡检，查看阶段、问题与诊断编号，协作取消或恢复，配置定时计划。AI 任务需明确选择获准后台使用的连接并设置调用上限；计划默认关闭。
- 手机可新增／编辑／删除个人连接，管理员可配置实例共享；选择模型、超时、预算及后台授权，并显式检测文本／工具能力。密钥只发送给当前选定服务器，不回显、不持久化在界面状态中。
- Telegram 为可选外部渠道：保存目标后显式发送验证码并回填，验证前不接收私人结果；可设置事件、级别、静默时段，查看投递状态。结果未知的投递必须先核对再明确确认重试，站内通知不受外部失败影响。

所有新页面、在途请求和通知同步位置绑定当前服务器与账号；切换后清除界面内容，迟到响应被拒绝。旧服务端缺少新接口时说明需升级至 0.4.0，基础播放与原有功能继续使用。请求错误的 `X-Wildstring-Trace-Id` 经过格式检查后展示为可长按复制的诊断编号。

### Android 系统媒体进度

歌曲时长同时写入标准 `MediaMetadata.durationMs`，覆盖初始／分段 AAC 尚无容器时长时的元数据兜底。有限 AAC 歌曲向会话公开整曲时间轴、绝对进度和 seek 命令，清除不适用的 live 标记；仍只有 `MediaSessionService` 中的一个播放器与会话，不另建通知会话。

`PlatformMediaSessionTest` 使用实际 `android.media.session.MediaController` 验证平台时长、位置、速度、`ACTION_SEEK_TO`、原音／AAC、系统跳转、暂停和 Activity 后台，不以应用界面的数据库兜底代替系统证据。标准平台通过不等于 OPPO／OnePlus 流体云最终视觉已验收：ColorOS 16.0.10 真机的通知栏、锁屏和流体云仍需安装后核对；不冒充网易云包名，不包含未验证的厂商私有 SDK。

自动化只使用合成曲库／模型／Telegram 服务；真实模型、Bot 投递和 ColorOS 真机验收与正式发布状态分别记录，见本版交付说明。

ColorOS 或其他系统媒体进度异常时，可在「设置 → 播放 → 播放诊断」，或当前歌曲操作菜单中打开诊断并复制。诊断直接读取本应用的标准平台会话，无需 USB、Root 或通知读取权限；只包含应用版本、设备厂商／型号／SDK、采样时间、时长／位置／速度／状态／seek 标志、内部时间轴和音质，不含歌曲名称、曲目 ID、服务地址、账号、Cookie 或令牌。可分别在原音和 AAC 播放、暂停后复制，供比较系统收到的状态。


### 发现、每日推荐与库外音乐

每日推荐、AI 找歌和助手使用同一份有权限的个人／实例共享／兼容连接列表，默认明确选择本地找歌，不自动选择付费模型；连接展示共享的每日预算及已用次数。发现与推荐模型请求使用不自动重试的客户端，预算不足或连接失败时展示实际降级，保留本地结果。

「每日推荐 → 推荐设置」按账号保存数量、连接和来源：我常听、大家常听、本地探索、很久没听，以及可选 Last.fm 相似／公共榜单／公共标签（最多三个标签）。主列表显示曲目依据与真实来源状态。「收听排行」支持本人／所有用户汇总、时间范围和播放次数／收听时长，直接播放本库曲目；不展示其他用户账号。

「发现新音乐」独立展示官方 Last.fm 的外部候选，包含来源、理由、歌名／艺人复制和来源页面。库外条目没有播放按钮；导入后服务端匹配到本库曲目才可播放。可标记想听或不感兴趣，不提供下载器，不抓取资源，也不改动导入目录。新发现不声称近期发行。每账号可开启并设置仅手动或每 1／3／7／14／30 天更新，默认间隔七天，到期后下次读取时更新，不宣称定时后台推送；外部 AI 编排需单独开启并明确选择连接，沿用统一预算。外部资料暂不可用时显示状态并保留已有缓存。
