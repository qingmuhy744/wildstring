# 野弦 Mac

原生 macOS 14 应用，与 iOS 共用 `frontend/ios/WildStringKit` 的网络、模型和播放。窗口是侧栏、主内容、底部播放条，歌词和队列从右侧展开。当前实现没有使用必须提高到 macOS 15 的 API，因此先保留 macOS 14 作为最低版本。

Debug 构建不访问钥匙串，而是把会话放在独立的本机开发用 `UserDefaults` suite 中，避免临时签名在重编译或重启后失去钥匙串访问。Release 构建仍使用钥匙串；不要把 Debug 构建当作正式安全配置。

## 菜单

左边是应用菜单：

- 「控制」：播放/暂停（⌘↩）、上一首/下一首（⌘[ / ⌘]；播客单集会自动变为后退 15 秒/前进 30 秒）、随机（⌥⌘S）、循环（⌥⌘R）。
- 「显示」：歌词（⌘L）、队列（⌥⌘J）、桌面歌词（⇧⌘L）、全屏播放（⇧⌘F）。同一桌面歌词入口再次点击会关闭窗口，按钮状态同步；窗口只保留左上角关闭按钮。全屏页按 Esc 收起，底部播放条上的封面和歌名也能打开它。

右边状态项使用野弦波形图标。点开后显示封面、歌曲／单集、艺人／节目、可拖动进度、播放状态和下一项；音乐与播客使用各自的控制，支持定时暂停和打开主窗口。设置里可以关掉「在菜单栏显示播放器」。

系统正在播放接到 `MPNowPlayingInfoCenter` 和远程命令，媒体键、控制中心和耳机操作走这一路。桌面歌词是置顶窗口，可按当前行显示，也可设为穿透点击。

2026-11-01 开发分支改用原生浮动面板管理桌面歌词：关闭后从菜单再次打开会恢复原位置；关闭穿透点击时可拖动歌词区域。译文与音译遵循主播放器偏好。首次打开和关闭后重开已有原生回归，真实鼠标拖动尚待手动验收。

## 播放与浏览

应用启动并恢复登录后默认进入「首页」，提供每日推荐、继续收听、电台与播客入口，以及最近添加的专辑、歌曲和个人收听记录。打开首页不会自动播放或改变队列。歌曲支持右键加入下一首或播放队列，专辑可进入详情；首页会随内容区宽度调整布局。

首页的「音乐助手」和刷新按钮放在内容标题旁，窄窗口时排到标题下方；使用与内容卡片一致的暖色背景和细边框。窗口标题栏隐藏系统工具栏底色，让侧栏和内容区的背景延伸到顶部。

侧栏集中展示首页、搜索、我的音乐和发现。播放队列从底部播放条或显示菜单打开，以独立圆角面板显示；通知与设置保留在侧栏底部的小图标中。跨设备继续、待确认草案和管理入口收进底部账号与服务器菜单；外观仍可在设置或显示菜单调整。

侧栏「搜索」或 `⌘F` 会同时搜索歌曲、专辑和艺人，结果按类型分组；歌曲可直接播放，专辑和艺人沿用现有详情页。快速连续输入只保留最后一次查询，清空输入会立即回到搜索首页。

音乐全屏页从封面取色，分别适配浅色与深色；歌词居中，歌曲开始时从上方显示。歌词源包含字级时间时支持逐字高亮，并可独立显示翻译与音译。没有逐字时间的歌词按行高亮。长文本片段按歌词栏宽度折行，折行保留原始时间戳。

2026-11-01 开发分支修复歌词点击后偶尔回到上一句：原音跳转与续播采用毫秒时间基准和零容差，避免 600 Hz 时间换算把落点舍入到歌词之前。原生播放器回归和真实 FLAC 数值对照通过；首页及原有 Mac 回归共 16 项通过，具体边界见[客户端与播客探索改进](../../docs/product/client-and-podcast-explore.md)。

播客使用独立播放页：左侧节目资料、进度、后退 15 秒／前进 30 秒、倍速及定时暂停，右侧单集简介和章节。简介的有效时间点可跳转播放，HTTP(S) 链接可打开；文字渲染不执行 RSS 脚本或加载正文图片。节目封面由 RSS 来源加载。

播客底部播放条和独立播放页均显示「倍速」菜单，支持 0.5×、0.75×、1×、1.25×、1.5×、1.75×、2×、2.5×、3×，并标记当前倍率。暂停时调整倍速不会开始播放，音乐仍以正常速度播放。

当前开发分支增加播客探索：在电台页打开「探索播客」，可浏览区域热门榜、搜索公开目录、预览后关注。播客底栏、菜单栏和队列读取节目封面；全屏「接下来」列表利用左侧剩余高度并独立滚动。艺人页首次使用默认专辑艺人，已有偏好保留。完整范围与验证见[客户端与播客探索改进](../../docs/product/client-and-podcast-explore.md)。

队列按实际收听顺序展示，支持拖动和上移／下移，随机状态下也保留当前播放与已有顺序。同一曲目可出现多次，每个队列项分别排序。歌曲列表中可点击艺人或专辑进入详情，多艺人曲目先选择具体艺人；浏览不会切换当前歌曲。

2026-10-31 验证：共享包 60 项播放与 87 项网络测试、11 项 Mac 助手／播客正文／歌词布局回归通过；本机 Debug 实测播客续播、暂停时调速、章节跳转、简介滚动与封面加载，艺人／专辑跳转和返回，桌面歌词开关、歌曲开头歌词位置及封面取色。最低系统仍为 macOS 14；macOS 14 实机和正式签名安装包尚未验收。

写请求使用 `X-Wildstring-Client: macos`。旧服务返回 `client_header_required` 时改用 `web` 重试。

## 音乐助手与草案

助手的历史／新对话／刷新操作位于窗口工具栏，窗口标题显示当前对话名；底部使用独立输入卡片，检索方式选择器与发送按钮都在输入区域内。

- 可以明确选择本地检索或已有模型连接，显示剩余额度；本地模式只接受歌名、艺人等关键词，不调用模型，也不会自动切换连接。
- 新对话在发送第一条消息时创建。历史对话支持打开、重命名和删除；删除需再次确认。切换到曲库后，正在发送的请求和未发送的输入仍保留在当前登录会话中。
- 对话显示生成阶段、部分回复、Markdown 段落、强调、表格和来源链接。支持多行输入；助手页的 `⌘ Return` 用于发送，其他页面仍用于播放/暂停。
- 发送失败保留输入并显示错误；请求超时时先恢复服务端已保存的消息，避免把已收到的消息直接重发。服务端正在处理时禁用重复提交。
- 本地检索结果可以直接播放。模型生成的草案从回复进入预览；歌单草案显示真实曲目、顺序及依据，支持试听和确认保存。更新已有歌单会提示替换名称和曲目顺序。
- 保存走服务端 `accept` 接口，携带所查看的版本、预览摘要和幂等键；只有服务端返回 `applied` 才显示已保存。已批准但未应用的旧草案也有独立入口。
- 封面、歌词、元数据等非歌单草案目前只展示摘要和依据，完整差异与应用仍在网页版完成。

2026-10-31 本轮验证：共享 Swift 包测试、6 项 Mac 助手状态回归、6 项后端草案应用回归；本机 Debug 重编译重启后登录恢复，真实服务器本地检索、结果播放、已配置模型查询、切页后会话保留和已有歌单草案预览。新的歌单保存请求由客户端契约测试与后端原子应用/幂等回归覆盖，未在真实服务器新增测试歌单。尚未覆盖 macOS 14 实机、正式签名安装包或发布。

## 每日推荐与歌曲操作

每日推荐使用与曲库一致的歌曲行，展示封面、艺人、专辑和当前播放状态。右键可安排下一首播放、加入播放队列、加入已有／新建歌单、预览歌词，以及收藏或调整推荐偏好。点「挑选歌曲」可以选择多首，按列表顺序一次加入队列或歌单，保留当前歌曲的播放进度和暂停状态。歌词预览不会切歌；全局播放条仍可打开当前歌曲的歌词与队列。

2026-10-31 每日推荐验证：Debug 编译通过；共享包 52 项播放与 84 项网络测试、迁移后默认 `make macos-test` 的 6 项助手回归通过；本机真实账号检查右键菜单、歌词预览和两首歌曲的歌单面板，未向服务器写入测试歌单。三端交互与验证边界见[每日推荐与个人播放清单](../../docs/product/daily-recommendation-actions.md)。

## 账号与服务器

点击侧栏底部账号卡片可切换已保存的服务器，或连接另一个服务器。有效会话直接恢复，无需先退出当前服务器；需要重新登录时保留当前连接，验证成功后才切换。连接失败或取消新增服务器窗口时，当前播放与连接保持可用。

服务器的登录状态、曲库选择、队列及暂停位置分别保留。切换会停止原服务器的播放，并以暂停状态恢复目标服务器队列。账号菜单与设置中的退出入口均需二次确认；确认后仅退出当前服务器，不清除其他服务器会话。

2026-11-04 本轮验证：Debug 编译、24 项 Mac 回归及共享包 68 项播放／90 项网络测试通过。隔离会话与内存数据库测试覆盖双服务器队列往返恢复、登录失败／会话过期保留当前连接，以及退出仅清除当前服务器会话。原有瞬时缓冲断言在未修改的基线上同样失败，已改为核对媒体装载与显式暂停，避免依赖 AVPlayer 的瞬时状态。本机浅深色实测助手、队列、倍速及退出确认；实际双服务器切换、macOS 14 实机和正式签名包尚未验收。

## 构建

本机仓库位于 `~/Developer/wildstring`。从此目录执行以下命令；移动前含旧绝对路径的环境与编译缓存保留在 `artifacts/*-before-directory-move`。

```sh
make macos-build MACOS_CONFIGURATION=Debug
make macos-build
make macos-dmg
make ios-test
make macos-test
```

DMG 在 `artifacts/WildString-macOS.dmg`。GitHub Actions 的 macOS 工作流会在相关路径变更时编译并上传 DMG；发版时挂到 Release。

有付费开发者账号时，在仓库 Secrets 中配置后才会签名和公证：

- `APPLE_CERTIFICATE_P12_BASE64`
- `APPLE_CERTIFICATE_PASSWORD`
- `APPLE_SIGNING_IDENTITY`（Developer ID Application）
- `APPLE_NOTARY_APPLE_ID`
- `APPLE_NOTARY_PASSWORD`
- `APPLE_TEAM_ID`

没有这些密钥时仍会打出 DMG。macOS 会拦截未公证的应用，需要在访达里右键打开，或到系统设置里放行。

Release 本地编译是临时签名，使用钥匙串时访问控制绑的是这一次二进制的签名哈希，所以每次重新编译可能会再要一次登录钥匙串密码。同一份编译结果在对话框里选「始终允许」后，不重新编译再打开就不会再问。Debug 构建使用上面的独立开发会话存储。图标和 iOS 用同一张。
